# Zephyr 源码阅读指南

> 本指南带你系统性地阅读 Zephyr RTOS 源代码，从整体架构到关键子系统，逐步深入。

## 为什么需要源码导读？

Zephyr 是一个庞大的嵌入式实时操作系统，代码库包含数十万行 C 代码。直接阅读源码容易迷失在细节中。本指南提供**结构化的阅读路径**，帮助你：

- 建立整体架构认知
- 理解关键子系统的设计
- 掌握代码组织规律
- 为自定义开发打下基础

## 阅读路径建议

```
入门 → 内核架构 → 调度器 → 内存管理 → 驱动模型 → 构建系统 → 子系统
```
