.. _usb_guidelines:

USB 测试与示例的通用准则
###########################################

概述
********

总体而言，所有 USB 示例和测试都是平台无关的，不应依赖
平台特定的 overlay。尽管树中可能已存在例外，但
目标是避免使用平台特定的 overlay。USB 示例或
USB 测试没有义务支持某个特定平台。

板级配置
*************

默认 USB 设备控制器与主机控制器
======================================

USB 支持使用 ``zephyr_udc0`` 节点标签来分配默认的 USB 设备控制器，
使用 ``zephyr_uhc0`` 节点标签来分配默认的 USB 主机控制器。根据
板级支持情况，必须分配这些节点标签，才能运行树中的
示例和测试。

板级元数据支持的特性
=========================================

板级元数据文件只有两个支持的特性，
Twister 使用它们来选择示例或测试。对于支持设备模式
USB 控制器的板级，特性为 ``usbd``；对于支持主机模式
USB 控制器的板级，特性为 ``usbh``。

更多细节请参见 :ref:`twister_board_configuration`。

已废弃的特性
-------------------

特性 ``usb_device`` 不应再使用。该特性属于已废弃的
旧版 USB 设备栈，后续将被移除。

Twister 测试配置
***************************

USB 测试可能需要额外的硬件或软件配置。这些测试应使用
下表所述的 :ref:`fixtures <twister_fixtures>`。

+-----------------------------+-------------------------------------------------------------+
| Fixture                     | 使用场景                                                    |
+=============================+=============================================================+
| ``usb_host_connected``      | 测试实现了 USB 设备功能，需要一台 USB 主机                 |
|                             | 连接到被测板级。                                            |
+-----------------------------+-------------------------------------------------------------+
| ``usb_device_connected``    | 测试实现了 USB 主机功能，需要一个 USB 设备                 |
|                             | 连接到被测板级。                                            |
+-----------------------------+-------------------------------------------------------------+
