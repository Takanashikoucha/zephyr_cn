USB 厂商 ID 与产品 ID
**********************************

Zephyr 项目的 USB 厂商 ID 为 ``0x2FE3``。当厂商将 Zephyr USB 设备支持集成到自有产品时，
不得使用 Zephyr 的 USB 厂商 ID。

每个 USB :zephyr:code-sample-category:`sample<usb>` 都有各自唯一的产品 ID。
USB 维护者（如果已指派），否则由 Zephyr 技术指导委员会，可以根据有充分依据
且有文档说明的申请，分配其他 USB 产品 ID。
