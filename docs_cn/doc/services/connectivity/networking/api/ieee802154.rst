IEEE 802.15.4
#############

.. contents::
    :local:
    :depth: 2

简介
****

IEEE 802.15.4 是一项技术标准，定义了低速率无线个人局域网（LR-WPAN）的运行方式。有关该标准的更详细说明，请参阅 `IEEE 802.15.4 维基百科文章
<https://en.wikipedia.org/wiki/IEEE_802.15.4>`_。

该标准的最新版本可通过 `IEEE GET 计划
<https://ieeexplore.ieee.org/browse/standards/get-program/page/series?id=68>`_ 获取。
您需要创建一个免费的 IEEE 账户，然后即可下载。

目前我们遵循 IEEE 802.15.4-2020 规范。该版本与 IEEE 802.15.4-2015 向后兼容，Thread 协议栈中包含了 2015 版本的部分内容。2020 版本还包含此前已纳入标准的扩展，即 IEEE 802.15.4g（SUN FSK）和 IEEE 802.15.4e（TSCH），它们与工业物联网和自动化相关。有关 UWB 测距技术的最新进展，请参阅 IEEE 802.15.4z，该扩展尚未纳入标准主线。

文档中引用标准的章节时，均指 IEEE 802.15.4-2020 的章节、表格和图编号——除非另有说明。

Zephyr 同时支持原生 IEEE 802.15.4 和 6LoWPAN 上的 Thread。Zephyr 的
:ref:`thread_protocol_interface` 实现基于 `OpenThread
<https://openthread.io/>`_。原生 IEEE 802.15.4 使用 6LoWPAN 中的 IPv6 报头压缩。

.. _ieee802154_mgmt_api:

IEEE 802.15.4 管理 API
===========================

这是面向 IEEE 802.15.4 **应用程序开发者**的主要子系统专用 API，因为它允许在运行时配置 IEEE 802.15.4 子系统。对应用程序开发者而言，其他相关接口是典型的 shell、socket、Kconfig 和 devicetree API，可通过 Zephyr 的通用子系统无关文档访问。请注意查找其中的 IEEE802154/ieee802154 前缀。

.. doxygengroup:: ieee802154_mgmt

========================

这是面向 IEEE 802.15.4 **驱动程序开发者**的主要 API。

.. doxygengroup:: ieee802154_driver


.. _ieee802154_l2_api:

IEEE 802.15.4 L2 / 原生协议栈 API
==================================

本文档描述 IEEE 802.15.4 L2 原生协议栈，应用程序和驱动程序都不会直接访问它。它由 Zephyr 的上层网络层（L3+）、其套接字和网络上下文抽象在内部调用。因此，该 API 仅面向 IEEE 802.15.4 **子系统贡献者**。

.. doxygengroup:: ieee802154_l2

OpenThread L2 适配层 API
==================================

Zephyr 的 OpenThread L2 平台适配层将外部的 OpenThread 协议栈与 Zephyr 的与协议无关的 IEEE 802.15.4 驱动程序 API 粘合在一起。该 API 仅面向 OpenThread L2 **子系统贡献者**。

OpenThread API 是 :ref:`thread_protocol_interface` 子系统的一部分，并在该子系统中进行了文档说明。
