操作码聚合器服务器
#########################

操作码聚合器服务器模型是蓝牙 Mesh 规范定义的基础模型。该模型为可选项，
通过 :kconfig:option:`CONFIG_BT_MESH_OP_AGG_SRV` 选项启用。

操作码聚合器服务器模型在蓝牙 Mesh 协议规范 1.1 版中引入，用于支持处理
一系列访问层消息的功能。

操作码聚合器服务器模型接受使用节点 device key 或 application key 加密的消息。

如果存在，操作码聚合器服务器模型只能实例化在主元素上。

目标服务器模型应绑定到用于加密发送至操作码聚合器服务器的一系列访问层消息的
同一个 application key。

操作码聚合器服务器处理聚合后的消息，并将其分发到相应模型及其消息处理函数。
当前实现假定响应从与接收消息相同的执行上下文发出，并且不允许延迟发送响应，
例如从工作队列中发送。
