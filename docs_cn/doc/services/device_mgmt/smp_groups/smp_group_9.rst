Shell 管理
################

Shell 管理允许通过 SMP 协议向 shell 子系统传递命令。

Shell 管理组定义了以下命令：

.. table::
    :align: center

    +-------------------+-----------------------------------------------+
    | ``Command ID``    | 命令描述                                        |
    +===================+===============================================+
    | ``0``             | 执行 Shell 命令行（Shell command line execute） |
    +-------------------+-----------------------------------------------+

执行 Shell 命令行
**************************

该命令允许执行命令行，方式类似于在 shell 中键入，但请求和响应都通过 SMP 传输。

执行 Shell 命令行请求
=================================

执行命令请求头：

.. table::
    :align: center

    +--------+--------------+----------------+
    | ``OP`` | ``Group ID`` | ``Command ID`` |
    +========+==============+================+
    | ``2``  | ``9``        |  ``0``         |
    +--------+--------------+----------------+

请求的 CBOR 数据：

.. code-block:: none

    {
        (str)"argv"     : [
            (str)<cmd>
            (str,opt)<arg>
            ...
        ]
    }

其中：

.. table::
    :align: center

    +-----------------------+---------------------------------------------------+
    | "argv"                | 由字符串组成的数组，表示命令及其参数。            |
    +-----------------------+---------------------------------------------------+
    | <cmd>                 | 要执行的命令。                                    |
    +-----------------------+---------------------------------------------------+
    | <arg>                 | 命令的可选参数。                                  |
    +-----------------------+---------------------------------------------------+

执行 Shell 命令行响应
==================================

命令行执行响应头字段：

.. table::
    :align: center

    +--------+--------------+----------------+
    | ``OP`` | ``Group ID`` | ``Command ID`` |
    +========+==============+================+
    | ``3``  | ``9``        |  ``0``         |
    +--------+--------------+----------------+

成功响应的 CBOR 数据：

.. code-block:: none

    {
        (str)"o"            : (str)
        (str)"ret"          : (int)
    }

出现错误时，CBOR 数据的形式为：

.. tabs::

   .. group-tab:: SMP version 2

      .. code-block:: none

          {
              (str)"err" : {
                  (str)"group"    : (uint)
                  (str)"rc"       : (uint)
              }
          }

   .. group-tab:: SMP version 1 (and non-group SMP version 2)

      .. code-block:: none

          {
              (str)"rc"       : (int)
          }

其中：

.. table::
    :align: center

    +------------------+-------------------------------------------------------------------------+
    | "o"              | 命令输出。                                                                |
    +------------------+-------------------------------------------------------------------------+
    | "ret"            | shell 命令执行的返回码。                                                  |
    +------------------+-------------------------------------------------------------------------+
    | "err" -> "group" | :c:enum:`mcumgr_group_t` 基于组的错误码所属的组。仅在使用 SMP version 2  |
    |                  | 且返回错误时出现。                                                       |
    +------------------+-------------------------------------------------------------------------+
    | "err" -> "rc"    | 包含基于组的错误码的索引。仅在使用 SMP version 2 且非零（出错状态）时    |
    |                  | 出现。                                                                   |
    +------------------+-------------------------------------------------------------------------+
    | "rc"             | :c:enum:`mcumgr_err_t` 仅在使用 SMP version 1 且非零（出错状态）时出现， |
    |                  | 或在使用 SMP version 2 且为 SMP 错误时出现。                             |
    +------------------+-------------------------------------------------------------------------+

.. note::
    在 Zephyr 的早期版本中，"rc" 同时用于 mcumgr 状态码和 shell 命令执行的返回码。
    通过启用 :kconfig:option:`CONFIG_MCUMGR_GRP_SHELL_LEGACY_RC_RETURN_CODE` 可以恢复
    这一旧版行为。
