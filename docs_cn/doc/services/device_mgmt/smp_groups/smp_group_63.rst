Zephyr 管理组
#######################

Zephyr 管理组定义了以下命令：

.. table::
    :align: center

    +----------------+------------------------------+
    | ``Command ID`` | 命令描述                       |
    +================+==============================+
    | ``0``          | 擦除存储（Erase storage）       |
    +----------------+------------------------------+

擦除存储命令
*********************

擦除存储命令允许清除设备上的 ``storage_partition`` 闪存分区。通常在切换到新的应用构建时使用该命令，前提是应用使用了应当被清除的存储（视应用而定）。

擦除存储请求
=====================

擦除存储请求头字段：

.. table::
    :align: center

    +--------+--------------+----------------+
    | ``OP`` | ``Group ID`` | ``Command ID`` |
    +========+==============+================+
    | ``2``  | ``63``       | ``0``          |
    +--------+--------------+----------------+

该命令发送一个空的 CBOR 映射作为数据。

擦除存储响应
=====================

读取设置响应头字段：

.. table::
    :align: center

    +--------+--------------+----------------+
    | ``OP`` | ``Group ID`` | ``Command ID`` |
    +========+==============+================+
    | ``3``  | ``63``       | ``0``          |
    +--------+--------------+----------------+

如果成功，该命令发送一个空的 CBOR 映射作为数据。出现错误时，CBOR 数据的形式为：

.. tabs::

   .. group-tab:: SMP version 2

      .. code-block:: none

          {
              (str)"err" : {
                  (str)"group"    : (uint)
                  (str)"rc"       : (uint)
              }
          }

   .. group-tab:: SMP version 1

      .. code-block:: none

          {
              (str)"rc"       : (int)
          }

其中：

.. table::
    :align: center

    +------------------+-------------------------------------------------------------------------+
    | "err" -> "group" | :c:enum:`mcumgr_group_t` 基于组的错误码所属的组。仅在使用 SMP version 2  |
    |                  | 且返回错误时出现。                                                       |
    +------------------+-------------------------------------------------------------------------+
    | "err" -> "rc"    | 包含基于组的错误码的索引。仅在使用 SMP version 2 且非零（出错状态）时    |
    |                  | 出现。                                                                   |
    +------------------+-------------------------------------------------------------------------+
    | "rc"             | :c:enum:`mcumgr_err_t` 仅在使用 SMP version 1 且非零（出错状态）时出现， |
    |                  | 或在使用 SMP version 2 且为 SMP 错误时出现。                             |
    +------------------+-------------------------------------------------------------------------+
