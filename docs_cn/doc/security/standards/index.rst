安全标准与 Zephyr
#############################

历史上，各组织独立管理网络安全，自行定义评估与响应协议。如今，各国政府正通过新法规和
安全标准对该领域实施越来越多的监管。这些标准为联网产品定义了具体的指南和合规要求。

本节评估这些安全标准对 Zephyr 项目本身以及下游产品开发者的影响。其目标是向开发者提供
使用 Zephyr 构建可认证、合规产品所需的信息。
