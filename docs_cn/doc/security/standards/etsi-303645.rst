ETSI 303-645
############


**ETSI EN 303 645**，又称"消费者物联网网络安全：
基本要求"，是由欧洲电信标准协会（ETSI）制定的标准。

该标准包含安全软件更新、数据保护、安全通信
以及最小化暴露攻击面等方面的规定。它是应对
物联网设备相关挑战和风险的更广泛努力的一部分。

标准全文可在此处找到
`here <https://www.etsi.org/deliver/etsi_en/303600_303699/303645/02.01.01_60/en_303645v020101p.pdf>`_。


术语
***********

.. list-table:: ETSI 303645 术语
    :widths: 17 43

    * - administrator
      - 具有设备用户最高可能权限级别的用户，
        这意味着他们可以更改与预期功能
        相关的任何配置。

    * - associated services
      - 与设备一起构成完整消费者物联网产品的
        数字服务，通常用于提供产品的
        预期功能。

    * - authentication mechanism
      - 用于证明实体真实性的方法。

    * - authentication value
      - 认证机制使用的属性的单个值。

    * - best practice cryptography
      - 适用于相应用例且没有迹象表明
        使用当前现成技术可实施攻击的
        密码学。

    * - constrained device
      - 由于预期用途产生的限制，在数据处理
        能力、数据通信能力、数据存储能力
        或用户交互能力方面存在物理限制
        的设备。

    * - consumer
      - 出于其贸易、业务、工艺或职业之外
        目的行事的自然人。

    * - consumer IoT device
      - 与关联服务有关系并由消费者通常在
        家中或作为电子可穿戴设备使用的
        联网（且可联网）设备。

    * - critical security parameter
      - 其泄露或修改可能危及安全模块安全的
        与安全相关的机密信息。

    * - debug interface
      - 制造商在开发期间用于与设备通信
        或对设备问题进行分诊的物理接口，
        不作为面向消费者功能的一部分使用

    * - defined support period
      - 制造商将提供安全更新的最低时长，
        以时间段或结束日期表示。

    * - device manufacturer
      - 创建组装完成的最终消费者物联网产品
        的实体，该产品很可能包含许多
        其他供应商的产品和组件。

    * - factory default
      - 设备在工厂重置后或最终
        生产/组装后的状态。

    * - initialization
      - 激活设备网络连接以进行运行并
        可选地为用户或网络访问设置
        认证功能的过程。

    * - initialized state
      - 设备在初始化后的状态。

    * - IoT product
      - 消费者物联网设备及其关联服务。

    * - isolable
      - 能够从其连接的网络中移除，且由此
        造成的任何功能损失仅与该连接
        相关而非其主要功能；或者，
        能够被放置到与其他设备自包含
        的环境中，前提是仅当该环境中
        设备的完整性可得到保证时

    * - logical interface
      - 利用网络接口通过通道或端口
        进行网络通信的软件实现。

    * - manufacturer
      - 供应链中相关的经济运营商
        （包括设备制造商）。

    * - network interface
      - 可用于通过网络访问消费者物联网
        功能的物理接口。

    * - owner
      - 拥有或购买设备的用户。

    * - personal data
      - 与已识别或可识别的自然人相关的
        任何信息。

    * - physical interface
      - 用于在物理层与设备通信的物理端口
        或空口接口（如无线电、音频或
        光学）。

    * - public security parameter
      - 其修改可能危及安全模块安全的
        与安全相关的公开信息。

    * - remotely accessible
      - 旨在可从本地网络外部访问。

    * - security module
      - 实现安全功能的硬件、软件和/或
        固件集合。

    * - security update
      - 处理由制造商发现或报告的
        安全漏洞的软件更新。

    * - sensitive security parameters
      - 关键安全参数和公开安全参数。

    * - software service
      - 用于支持功能的设备软件组件。

    * - telemetry
      - 可提供信息以帮助制造商识别问题
        或与设备使用相关的信息的
        设备数据。

    * - unique per device
      - 对于给定产品类别或类型的
        每个单独设备都是唯一的。

    * - user
      - 自然人或组织。

规定评估
*********************

  下表是使用 ETSI EN 303 645 的表 B.1
  进行的自我评估，特别关注 Zephyr RTOS
  作为物联网产品中的组件。

  根据 ETSI 303 645，表 B.1 提供了一种
  机制来提供关于标准中所述规定实施
  情况的信息。Zephyr 采用了标准中
  使用的以下符号：

.. list-table:: ETSI 303645 表 B.1 符号
    :widths: 17 43

    * - M
      - 该规定是强制要求

    * - R
      - 该规定是建议

    * - M C
      - 该规定是强制要求且有条件的

    * - R C
      - 该规定是建议且有条件的

    * - Y
      - Zephyr 支持该规定

    * - N
      - Zephyr 不支持该规定

    * - N/A
      - 该规定不适用于 Zephyr 或属于
        产品制造商的责任
