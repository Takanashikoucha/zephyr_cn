CVE-2017
########

:cve:`2017-14199`
-----------------

:code:`getaddrinfo()` 中的缓冲区溢出。

- `Zephyr 项目缺陷跟踪器 ZEPSEC-12
  <https://zephyrprojectsec.atlassian.net/browse/ZEPSEC-12>`_

- `PR6158 针对 1.11.0 的修复
  <https://github.com/zephyrproject-rtos/zephyr/pull/6158>`_

:cve:`2017-14201`
-----------------

Shell 的 DNS 命令由于误用栈变量可能导致不可预测的结果。

Zephyr shell 中的释放后使用（Use After Free）漏洞允许通过串口或 telnet 连接的用户
造成拒绝服务，甚至可能导致远程代码执行。

此问题已在 v1.14.0 版本中修复。

- `Zephyr 项目缺陷跟踪器 ZEPSEC-17
  <https://zephyrprojectsec.atlassian.net/browse/ZEPSEC-17>`_

- `PR13260 针对 v1.14.0 的修复
  <https://github.com/zephyrproject-rtos/zephyr/pull/13260>`_

:cve:`2017-14202`
-----------------

Shell 实现未防范缓冲区溢出，导致不可预测的行为。

Zephyr shell 组件中的内存缓冲区操作边界限制不当漏洞允许通过串口或 telnet 连接的用户
造成系统崩溃，甚至可能执行任意代码。

此问题已在 v1.14.0 版本中修复。

- `Zephyr 项目缺陷跟踪器 ZEPSEC-18
  <https://zephyrprojectsec.atlassian.net/browse/ZEPSEC-18>`_

- `PR13048 针对 v1.14.0 的修复
  <https://github.com/zephyrproject-rtos/zephyr/pull/13048>`_
