CVE-2019
########

:cve:`2019-9506`
----------------

蓝牙 BR/EDR 规范直至 5.1 版本允许足够短的加密密钥长度，且无法阻止攻击者
影响密钥长度协商。这使得实际的暴力破解攻击（又称 "KNOB"）成为可能，
攻击者可解密流量并注入任意密文，而受害者毫无察觉。
