----------------

Bluetooth：当已知 bond 的身份地址时，可能在密钥分发阶段覆盖已有的 bond

在分发身份地址信息过程中，我们未检查是否存在具有相同身份地址的
已有 bond。这意味着将在 RAM 中创建重复条目，而最新条目将覆盖
持久化存储中的已有条目。

此问题已在 v2.6.0 的 main 分支中修复

- `Zephyr 项目缺陷跟踪器 GHSA-j76f-35mc-4h63

  <https://github.com/zephyrproject-rtos/zephyr/pull/33266>`_

:cve:`2021-3510`
----------------

Zephyr JSON 解码器错误解码数组的数组

当使用 JSON_OBJ_DESCR_ARRAY_ARRAY 时，子数组具有
JSON_TOK_LIST_START 类型的 token，但随后赋值给联合体中的对象部分。
arr_parse 随后取数组对象的偏移量（与列表无关），将其视为相对于
父对象的偏移，并将子数组的长度存储在其中。

此问题已在 v2.7.0 的 main 分支中修复

- `Zephyr 项目缺陷跟踪器 GHSA-289f-7mw3-2qf4
  <https://github.com/zephyrproject-rtos/zephyr/security/advisories/GHSA-289f-7mw3-2qf4>`_

- `PR 36340 针对 main 的修复
  <https://github.com/zephyrproject-rtos/zephyr/pull/36340>`_

- `PR 37816 针对 2.6 的修复
  <https://github.com/zephyrproject-rtos/zephyr/pull/37816>`_

:cve:`2021-3581`
----------------

HCI 数据未正确检查导致蓝牙协议栈内存溢出

在通过 HCI 命令设置 SCAN_RSP 的过程中，Zephyr 蓝牙协议栈
未有效检查传入 HCI 数据的长度。导致内存溢出，随后内存中的
数据被覆盖，甚至可能导致任意代码执行。

此问题已在 v2.6.0 的 main 分支中修复
