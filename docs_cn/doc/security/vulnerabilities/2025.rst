:cve:`2025-7403`
----------------

Bluetooth：bt_conn_tx_processor 的不安全处理

bt_conn_tx_processor 中的不安全处理导致释放后使用（use-after-free），
进而引发先写后零（write-before-zero）。写入的 4 字节
由攻击者控制，可实现精确的内存破坏。

- `Zephyr 项目缺陷跟踪器 GHSA-9r46-cqqw-6j2j
  <https://github.com/zephyrproject-rtos/zephyr/security/advisories/GHSA-9r46-cqqw-6j2j>`_

该问题已在 main 分支修复，将随 v4.2.0 发布

- `PR 90975 main 分支修复
  <https://github.com/zephyrproject-rtos/zephyr/pull/90975>`_

:cve:`2025-10456`
-----------------

Bluetooth：可半任意地使 BLE 目标设备发送断连请求

在 Bluetooth Low Energy（BLE）固定信道（如 SMP 或 ATT）
的处理过程中发现一个漏洞。具体而言，攻击者可利用
一个缺陷使 BLE 目标（即被攻击设备）尝试断开一个
固定信道，而这在 Bluetooth 规范中是不被允许的。
这将导致未定义行为，包括潜在的断言失败、崩溃
或内存破坏。

- `Zephyr 项目缺陷跟踪器 GHSA-hcc8-3qr7-c9m8
  <https://github.com/zephyrproject-rtos/zephyr/security/advisories/GHSA-hcc8-3qr7-c9m8>`_

该问题已在 main 分支修复，将随 v4.2.0 发布

- `PR 93576 main 分支修复
  <https://github.com/zephyrproject-rtos/zephyr/pull/93576>`_

- `PR 100474 3.7 分支修复
  <https://github.com/zephyrproject-rtos/zephyr/pull/100474>`_

:cve:`2025-12890`
-----------------

Bluetooth：peripheral：对畸形连接请求的不当处理

对 interval 被设为 1（本应非法）且 chM 为 0x7CFFFFFFFF
的畸形 Connection Request 的不当处理会触发崩溃。
此后 peripheral 将不可再连接。

:cve:`2025-12899`
-----------------

net: icmp：越界内存读取

Zephyr 网络栈中的一个缺陷使包含 ICMP 类型 128 的 IPv4 报文
被错误分类为 ICMPv6 Echo Request。这导致越界内存读取，
并在网络子系统中形成潜在的信息泄露漏洞。


- `Zephyr 项目缺陷跟踪器 GHSA-c2vg-hj83-c2vg
  <https://github.com/zephyrproject-rtos/zephyr/security/advisories/GHSA-c2vg-hj83-c2vg>`_
