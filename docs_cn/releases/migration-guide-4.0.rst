Migration
guide
to
Zephyr
v4.0.0
################################

这
个
document
describe
migrating
你
的
application
从
Zephyr
v3.7.0
到
Zephyr
v4.0.0
required
的
changes。

其他
changes
（不
directly
related
to
migrating
applications）
可以
found
在
:ref:`release
notes<zephyr_4.0>`。

.. contents::
    :local:
    :depth:
    2

Build
System
************

*
Removed
deprecated
的
:kconfig:option:`CONFIG_MCUBOOT_CMAKE_WEST_SIGN_PARAMS`
Kconfig
option
因为
``west
sign``
不
再
被
build
system
called
当
signing
images
for
MCUboot
时。

*
``west
sign``
的
imgtool
part
被
deprecated
options
要
supplied
到
imgtool
当
signing
时
应该
在
:kconfig:option:`CONFIG_MCUBOOT_EXTRA_IMGTOOL_ARGS`
中
被
set
instead。

Kernel
******

*
Removed
deprecated
的
:kconfig:option:`CONFIG_MP_NUM_CPUS`
application
应该
被
updated
用于
use
:kconfig:option:`CONFIG_MP_MAX_NUM_CPUS`
instead。

Boards
******

*
``native_posix``
被
deprecated
in
favor
of
:zephyr:board:`native_sim<native_sim>`
(:github:`76898`)。
*
Nordic
nRF53
和
nRF91
based
的
boards
可以
use
common
的
devicetree
overlays
在
``dts/common/nordic``
中
用于
define
default
的
flash
和
ram
partitioning
based
on
TF
M。
