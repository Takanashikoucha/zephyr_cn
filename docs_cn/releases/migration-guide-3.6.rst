Migration
guide
to
Zephyr
v3.6.0
################################

这
个
document
describe
migrating
你
的
application
从
Zephyr
v3.5.0
到
Zephyr
v3.6.0
required
的
changes。

其他
changes
（不
directly
related
to
migrating
applications）
可以
found
在
:ref:`release
notes<zephyr_3.6>`。

.. contents::
    :local:
    :depth:
    2

Build
System
************

*
Deprecated
的
``prj_<board>.conf``
Kconfig
file
support
被
removed
projects
use
这
个
的
应该
switch
到
use
board
Kconfig
fragments
instead
（``boards/<board>.conf``）。

*
Until
now
``_POSIX_C_SOURCE``、
``_XOPEN_SOURCE``、
和
``_XOPEN_SOURCE_EXTENDED``
在
building
for
native
（``ARCH_POSIX``）
targets
时
被
globally
defined
且
``_POSIX_C_SOURCE``
在
building
with
PicolibC
时
被
defined。
Since
这
个
release
这些
只
为
需要
它们
的
files
被
set。
如果
你
的
library
或
application
需要
这
个
你
可能
start
get
一
个
"implicit
declaration"
warning
对
functions
它们
的
prototypes
只
在
one
of
these
被
defined
时
exposed。
如果
这样
你
可以
fix
它
通过
在
你
的
C
source
file
中
在
任何
include
之前
define
corresponding
的
macro
或
通过
add
``target_compile_definitions(app
PRIVATE
_POSIX_C_SOURCE=200809L)``
的
equivalent
到
你
的
application
或
``zephyr_library_compile_definitions(_POSIX_C_SOURCE=200809L)``
到
你
的
library。

*
通过
set
``CONF_FILE``
到
``prj_<build>.conf``
的
Build
type
now
被
deprecated
users
应该
instead
use
new
的
``-DFILE_SUFFIX``
feature
:ref:`application-file-suffixes`。

Kernel
******

*
System
heap
的
size
和
它
的
availability
now
由
``K_HEAP_MEM_POOL_SIZE``
determined
