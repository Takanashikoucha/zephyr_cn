Zephyr
4.3.0
############

我们
pleased
to
announce
Zephyr
version
4.3.0
的
release。

这
个
release
的
Major
enhancements
包括：

**USB
Device
"Next"
stack
is
now
the
default**
   The
   new
   :ref:`USB
   device
   stack
   <usb_device_stack_next>`
   built
   on
   the
   modern
   UDC
   （USB
   Device
   Controller）
   API
   replaces
   the
   legacy
   stack
   并
   brings
   support
   for
   multiple
   simultaneous
   controllers、
   runtime
   configuration、
   和
   overall
   better
   architecture。
   The
   legacy
   stack
   is
   now
   deprecated
   且
   将
   在
   Zephyr
   4.5
   中
   被
   removed。
