Zephyr
2.5.0
#############

我们
pleased
to
announce
Zephyr
RTOS
version
2.5.0
的
release。

这
个
release
的
Major
enhancements
包括：

*
Introduced
support
for
the
SPARC
processor
architecture
和
LEON
processor
implementation。
*
Added
Thread
Local
Storage
（TLS）
support
*
Added
support
for
per
thread
的
runtime
statistics
*
Added
support
for
building
with
LLVM
on
X86
*
Added
new
的
synchronization
mechanisms
using
Condition
Variables
*
Add
support
for
demand
paging
initial
的
support
on
X86。

以下
sections
provide
detailed
的
lists
of
changes
by
component。
