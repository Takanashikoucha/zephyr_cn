Releases
########

Zephyr
被
distributed
作为
source
code
和
build
scripts
而
不
是
binary
image。
Use
:ref:`west`
:ref:`get
the
code
<get_the_code>`
用于
specific

`GitHub

当前

https://docs.zephyrproject.org/
（use
version
selector

你
的
release
