Zephyr
3.6.0
############

我们
pleased
to
announce
Zephyr
version
3.6.0
的
release。

这
个
release
的
Major
enhancements
包括：

*
New
的
:ref:`GNSS
subsystem
<gnss_api>`
被
added
enabling
geo
awareness
in
Zephyr
applications。
*
New
的
API
和
drivers
被
introduced
用于
interface
with
:ref:`keyboard
matrices
<gpio
kbd>`。
*
New
的
socket
和
CoAP
service
libraries
streamlining
the
implementation
of
socket
和
CoAP
servers
respectively
while
also
optimizing
the
use
of
resources。
*
Integrated
Trusted
Firmware
M
（TF
M）
2.0
包括
一
个
update
to
Mbed
TLS
3.5.2。
*
Improved
的
LLEXT
tooling
simplifying
module
creation
in
the
Zephyr
build
system。
*
Userspace
support
被
extended
to
Xtensa
architecture。
*
Build
system
now
support
Link
Time
Optimization
（LTO）
reducing
the
size
of
the
final
image。
*
Bluetooth
Mesh
protocol
1.1
now
被
supported
by
default。
*
Major
的
updates
to
the
documentation
of
the
:zephyr:board:`native
simulator
<native_sim>`
clarifying
supported
的
peripherals
和
how
to
use
them。
*
Over
30
new
的
supported
boards
spanning
all
Zephyr
supported
的
architectures。

一
个
overview
of
changes
required
或
recommended
when
migrating
你
的
application
from
Zephyr
v3.5.0
to
Zephyr
v3.6.0
可以
found
in
separate
的
:ref:`migration
guide<migration_3.6>`。

以下
sections
provide
detailed
的
lists
of
changes
by
component。
