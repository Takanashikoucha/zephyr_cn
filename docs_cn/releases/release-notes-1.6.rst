Zephyr
Kernel
1.6.0
####################

我们

Zephyr
kernel

1.6.0
的
release。
这

release
introduce
unified
的
Kernel
replacing
separate
的
nano
和
micro
kernels
并
simplify
overall
的
Zephyr
architecture
和
programming

Support
for
the
ARM
Cortex
M0/M0+
family
被
added
且
Cortex
M
的
board
support
被
expanded。
Additionally
这
个
release
add
many
的
improvements
for
documentation、
build
infrastructure、
和
testing。

Release
中
included
的
Major
enhancements:

*
Introduced
the
Unified
Kernel
nano
和
micro
kernel
被
removed。
*
Legacy
的
API
仍
被
supported
但
被
deprecated。
*
Legacy
的
tests
和
samples
被
moved
到
tests/legacy
和
samples/legacy。
*
Unified
kernel
的
documentation
被
added
且
legacy
的
nanokernel/microkernel
documentation
被
removed。
*
Added
support
for
several
ARM
Cortex
M
boards
*
Added
support
for
USB
mass
storage
和
access
到
filesystem。
*
Added
native
的
Bluetooth
Controller
support。
当前
nRF51
&
nRF52
被

以来
