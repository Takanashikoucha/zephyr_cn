Zephyr
3.7.0
############

我们
pleased
to
announce
Zephyr
version
3.7.0
的
release。

这
个
release
是
last
个
non
maintenance
的
3.x
release
且
as
such
将
be
next
:ref:`Long
Term
Support
（LTS）
release
<release_process_lts>`。

这
个
release
的
Major
enhancements
包括：

*
一
个
new
的
completely
:ref:`overhauled
hardware
model
<hw_model_v2>`
被
introduced。
它
changes
the
way
both
SoCs
和
boards
被
named、
defined
和
constructed
in
Zephyr。
Additional
的
information
可以
found
in
the
:ref:`board_porting_guide`。
*
一
个
long
awaited
的
:ref:`HTTP
Server
<http_server_interface>`
library
和
associated
的
service
API
allow
easily
implement
HTTP/1.1
和
HTTP/2
servers
in
Zephyr。
Resources
可以
be
registered
statically
或
dynamically
且
WebSocket
support
被
included。
*
:ref:`POSIX
support
<posix_support>`
被
extended
with
most
Options
of
the
IEEE
1003
2017
:ref:`System
Interfaces
<posix_system_interfaces_required>`
receiving
support
as
well
as
most
Options
和
Option
groups
required
for
:ref:`PSE51
<posix_aep_pse51>`、
:ref:`PSE52
<posix_aep_pse52>`、
和
:ref:`PSE53
<posix_aep_pse53>`。
*
Bluetooth
Host
被
extended
with
support
for
the
Nordic
UART
Service
（NUS）、
Hands
free
Audio
Gateway
（AG）、
Advanced
Audio
Distribution
Profile
（A2DP）、
和
Audio/Video
Distribution
Transport
Protocol
（AVDTP）。
*
Sensor
abstraction
model
被
overhauled
用于
adopt
一
个
:ref:`read
then
decode
approach
<sensor
read
and
decode>`
它
enable
more
types
of
sensors
和
data
flows
than
the
previous
fetch/get
APIs。
*
一
个
new
的
:ref:`LLEXT
Extension
Developer
Kit
（EDK）
<llext_build_edk>`
make
it
easier
to
develop
和
integrate
custom
extensions
into
Zephyr
including
outside
of
the
Zephyr
tree。
*
:zephyr:board:`Native
simulator
<native_sim>`
now
support
leveraging
the
native
host
networking
stack
without
having
to
rely
on
一
个
complex
的
setup
of
the
host
environment。
*
Trusted
Firmware
M
（TF
M）
2.1.0
和
Mbed
TLS
3.6.0
被
integrated
into
Zephyr。
Both
of
these
versions
是
LTS
releases。
What's
more
:ref:`psa_crypto`
被
adopted
作为
TinyCrypt
的
replacement
且
provide
enhanced
的
security
和
performance。
*
一
个
new
的
experimental
的
implementation
of
the
:ref:`Precision
Time
Protocol
<ptp_interface>`
（PTP、
IEEE
1588）
allow
synchronize
time
across
devices
with
sub
microsecond
的
accuracy。
*
New
的
documentation
pages
被
introduced
用于
help
developers
setup
their
local
development
