Zephyr
4.0.0
############

我们
pleased
to
announce
Zephyr
version
4.0.0
的
release。

这
个
release
的
Major
enhancements
包括：

*
**Secure
Storage
Subsystem**:
一
个
newly
introduced
的
:ref:`secure
storage<secure_storage>`
subsystem
allow
the
use
of
the
PSA
Secure
Storage
API
和
of
persistent
keys
in
the
PSA
Crypto
API
on
*all*
board
targets。
它
now
是
standard
的
way
to
provide
device
specific
的
protection
to
data
at
rest。
(:github:`76222`)

*
**ZMS
（Zephyr
Memory
Storage）
Subsystem**:
:ref:`ZMS
<zms_api>`
是
一
个
new
的
key
value
storage
subsystem
compatible
with
all
non
volatile
storage
types
including
traditional
NOR
flash
和
advanced
的
technologies
like
RRAM
和
MRAM
它们
support
write
without
erasure。

*
**Analog
Comparators**:
一
个
new
的
:ref:`comparator<comparator_api>`
device
driver
subsystem
for
analog
comparators
被
added
complete
with
shell
support。
它
support
initial
的
configuration
through
Devicetree
和
runtime
的
configuration
through
vendor
specific
的
APIs。
Initially
the
:dtcompatible:`nordic,nrf
comp`、
:dtcompatible:`nordic,nrf
lpcomp`
和
:dtcompatible:`nxp,kinetis
acmp`
被
supported。

*
**Stepper
Motors**:
它
now
possible
to
interact
with
stepper
motors
using
一
个
standard
API
thanks
to
the
new
:ref:`stepper<stepper_api>`
device
driver
subsystem
它
也
come
with
shell
support。
Initially
implemented
的
drivers
包括
一
个
simple
的
:dtcompatible:`zephyr,gpio
steppers`
和
一
个
complex
的
sensor
less
的
stall
detection
capable
with
integrated
ramp
controller
的
:dtcompatible:`adi,tmc5041`。

*
**Haptics**:
一
个
new
的
:ref:`haptics_api`
device
driver
subsystem
allow
unified
的
access
to
haptic
controllers
enabling
users
to
add
haptic
feedback
to
their
applications。

*
**Multimedia
Capabilities**
Zephyr's
audio
和
video
capabilities
被
expanded
with
support
for
new
的
image
sensors、
video
interfaces、
audio
interfaces、
和
codecs
being
supported。
