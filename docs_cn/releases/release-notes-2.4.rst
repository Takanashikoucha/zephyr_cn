Zephyr
2.4.0
############

我们

Zephyr
RTOS
version
2.4.0
的
release。

这

release
的
Major

*
Introduced
initial
的
support
for
virtual
memory
management。

*
Added
Bluetooth
host

periodic
advertisement
和

*
Enabled
new
的
TCP
stack
TCP2
by
default。
这
个
stack
在
Zephyr
v2.1.0
中
被
introduced
用于
improve
network
protocol
testability
with
open
source
的
tools。

*
Introduced
一
个
new
的
toolchain
abstraction
带
initial
的
implementations
for
GCC
和
LLVM/Clang
且
groundwork
for
future
的
support
of
commercial
toolchains。

*
Moved
到
use
C99
的
integer
types
且
deprecate
Zephyr
的
integer
types。
Zephyr
的
types
可以
用
Kconfig
DEPRECATED_ZEPHYR_INT_TYPES
option
被
enabled。

以下
sections
provide
detailed
的
lists
of
changes
by
component。
