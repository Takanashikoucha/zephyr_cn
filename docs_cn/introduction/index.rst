Zephyr 入门
##########

Zephyr 操作系统基于一个小型内核设计，专为资源受限和嵌入式系统打造：从简单的嵌入式环境传感器、LED 可穿戴设备，到复杂的嵌入式控制器、智能手表和物联网无线应用。

Zephyr 内核支持多种架构，包括：

 - ARCv2（EM 和 HS）和 ARCv3（HS6X）
 - ARMv6-M、ARMv7-M 和 ARMv8-M（Cortex-M）
 - ARMv7-A 和 ARMv8-A（Cortex-A，32 位和 64 位）
 - ARMv7-R、ARMv8-R（Cortex-R，32 位和 64 位）
 - Qualcomm Hexagon
 - Intel x86（32 位和 64 位）
 - MIPS（MIPS32 Release 1 规范）
 - OpenRISC（32 位）
 - Renesas RX
 - RISC-V（32 位和 64 位）
 - SPARC V8
 - Tensilica Xtensa
 - TriCore（TC1.6.2 和 TC1.8）

基于这些架构的完整支持板卡列表可在 :ref:`此处 <boards>` 找到。

在 Zephyr 操作系统的语境中，:term:`子系统` 指操作系统中逻辑上独立的部分，负责处理特定功能或提供特定服务。子系统可以包括网络、文件系统、设备驱动类、电源管理和通信协议等组件。每个子系统都设计为模块化的，可以配置、定制和扩展，以满足不同嵌入式应用的需求。

特色功能
********

Zephyr 提供大量且不断增长的功能，包括：

**丰富的内核服务套件**
   Zephyr 为开发提供了一系列熟悉的服务：

   * *多线程服务*：支持协作式、基于优先级的、
     非抢占式和抢占式线程，可选时间片轮转。
     包含 POSIX pthreads 兼容 API 支持。

   * *中断服务*：支持编译时注册中断处理程序。

   * *内存分配服务*：支持固定大小或可变大小
     内存块的动态分配和释放。

   * *线程间同步服务*：支持二元信号量、
     计数信号量和互斥信号量。

   * *线程间数据传递服务*：支持基础消息队列、
     增强消息队列和字节流。

   * *电源管理服务*：包括全局的、应用或策略定义的
     系统电源管理，以及细粒度的、驱动定义的
     设备电源管理。

**多种调度算法**
   Zephyr 提供全面的线程调度选择：

   * 协作式和抢占式调度
   * 最早截止日期优先（EDF）
   * 实现"中断下半部"或"tasklet"行为的
     元中断调度
   * 时间片：在同等优先级的可抢占线程之间
     启用时间片轮转
   * 多种排队策略：

     * 简单链表就绪队列
     * 红黑树就绪队列
     * 传统多队列就绪队列

.. _zephyr_intro_configurability:

**高度可配置 / 模块化以提供灵活性**
   允许应用*仅*在其需要时纳入所需的功能，
   并指定其数量和大小。

**跨架构**
   支持多种 :ref:`支持板卡<boards>`，涵盖不同的 CPU
   架构和开发工具。社区贡献不断增加对
   SoC、平台和驱动的支持。

**内存保护**
   实现可配置的架构特定栈溢出保护、
   内核对象和设备驱动权限跟踪，以及在 x86、ARC 和 ARM 架构上的
   线程隔离（线程级内存保护）、用户空间和内存域。

   对于没有 MMU/MPU 的资源和内存受限设备，
   支持将应用特定代码与自定义内核结合，
   创建加载到系统硬件上执行的整体镜像。
   应用代码和内核代码在单个共享地址空间中执行。

**编译时资源定义**
   允许在编译时定义系统资源，
   从而减少代码大小并提高资源受限系统的性能。

**优化的设备驱动模型**
   为平台/系统中的驱动提供一致的设备模型，
   为初始化系统中配置的所有驱动提供一致的模型，
   并允许在具有共同设备/IP 块的跨平台间复用驱动。

**设备树支持**
   使用 :ref:`设备树 <dt-guide>` 描述硬件。
   设备树中的信息用于创建应用镜像。

**原生网络栈，支持多种协议**
   网络支持功能完整且经过优化，
   包括 LwM2M 和 BSD sockets 兼容支持。
   还提供 OpenThread 支持（在 Nordic 芯片上）——
   一种设计用于安全、可靠地连接家中数百个产品的网状网络。

**蓝牙低功耗 5.0 支持**
   符合 Bluetooth 5.0（ESR10）规范，
   并提供蓝牙低功耗控制器支持（LE 链路层）。
   包括蓝牙 Mesh 和通过蓝牙认证的蓝牙控制器。

   * 通用访问配置文件（GAP），支持所有 LE 角色
   * 通用属性配置文件（GATT）
   * 配对支持，包括 Bluetooth 4.2 的安全连接功能
   * 干净的 HCI 驱动抽象
   * 原始 HCI 接口，可将 Zephyr 作为控制器运行
     而非完整主机栈
   * 已通过多种流行控制器验证
   * 高度可配置

   Mesh 支持：

   * 中继、好友节点、低功耗节点（LPN）和 GATT 代理功能
   * 支持两种配置承载（PB-ADV 和 PB-GATT）
   * 高度可配置，可适配至少 16k RAM 的设备

**原生 Linux、macOS 和 Windows 开发**
   命令行 CMake 构建环境运行于主流开发操作系统。
   原生移植（:zephyr:board:`native_sim <native_sim>`）
   允许将 Zephyr 作为原生应用构建和运行于 Linux，
   辅助开发和测试。

**虚拟文件系统接口，支持 ext2、FatFs 和 LittleFS**
   支持 ext2、LittleFS 和 FatFS；
   FCB（Flash 循环缓冲区）适用于内存受限应用。

**强大的多后端日志框架**
   支持日志过滤、对象转储、恐慌模式、
   多种后端（内存、网络、文件系统、控制台等）
   以及与 shell 子系统的集成。

**用户友好且功能完整的 Shell 接口**
   多实例 shell 子系统，具备用户友好功能，
   如自动补全、通配符、颜色、元键（方向键、退格、ctrl+u 等）
   和历史记录。支持静态命令和动态子命令。

**非易失性存储上的设置**
   settings 子系统为模块提供存储每设备持久配置
   和运行时状态的方式。设置项以键值对字符串存储。

**非易失性存储（NVS）**
   NVS 允许存储二进制块、字符串、整数、长整数
   及它们的任意组合。

**原生移植**
   :zephyr:board:`Native sim <native_sim>` 允许将 Zephyr
   作为 Linux 应用运行，支持各种子系统和网络。
