应用版本管理
******************************

Zephyr 支持围绕 Zephyr 用于其自身版本系统管理的系统的应用版本管理系统。
这允许应用定义版本文件，并有应用（或模块）代码包含自动生成的文件并能够访问它，
就像它们可以用内核版本一样。这个版本信息从多个作用域可用，包括：

* 代码（C/C++）
* Kconfig
* CMake
* Shell

这使它成为应用生命周期管理的非常通用的系统。
此外，它可以在构建目标受支持引导加载器（例如 MCUboot）的应用时使用，
允许镜像自动用正确的应用版本签名 - 不需要手动签名步骤。

VERSION 文件
=============

应用版本信息按应用基础在名为 :file:`VERSION` 的文件中设置，
它必须放在应用的基础目录中，:file:`CMakeLists.txt` 文件位于的地方。
这是一个简单的文本文件，包含各种版本信息字段，每个在新行上。
基础 ``VERSION`` 文件有以下结构：

.. code-block:: cfg

   VERSION_MAJOR =
   VERSION_MINOR =
   PATCHLEVEL =
   VERSION_TWEAK =
   EXTRAVERSION =

每个字段和它支持的值在下面描述。Zephyr 将每个数值字段的值限制为单个字节
（注意根据版本的用途可能有进一步限制，例如引导加载器可能只支持这些字段的某些
或可能对字段的最大值放限制）：

+---------------+-------------------------------------------------------+---------------+
| 字段          | 数据类型                                              |   必需        |
+---------------+-------------------------------------------------------+---------------+
| VERSION_MAJOR | 数值（0-255）                                         |       X       |
+---------------+-------------------------------------------------------+---------------+
| VERSION_MINOR | 数值（0-255）                                         |       X       |
+---------------+-------------------------------------------------------+---------------+
| PATCHLEVEL    | 数值（0-255）                                         |       X       |
+---------------+-------------------------------------------------------+---------------+
| VERSION_TWEAK | 数值（0-255）                                         |       X       |
+---------------+-------------------------------------------------------+---------------+
| EXTRAVERSION  | 字母数字（小写 a-z 和 0-9）和 "." 或 "-"             |               |
+---------------+-------------------------------------------------------+---------------+

当应用用 CMake 配置时，版本文件将自动处理，
并每次版本更改时自动检查，因此对这个文件的更改不需要手动重新运行 CMake。

对于下面的章节，为以下 :file:`VERSION` 文件提供示例：

.. code-block:: cfg

   VERSION_MAJOR = 1
   VERSION_MINOR = 2
   PATCHLEVEL = 3
   VERSION_TWEAK = 4
   EXTRAVERSION = unstable.5

在代码中使用
=============

要在应用代码中使用版本信息，必须包含版本文件，然后字段可以自由使用。
包含文件名是 :file:`app_version.h`（使用 ``#include <zephyr/app_version.h>``），
以下定义可用：

+-----------------------------+-------------------+------------------------------------------------------+---------------------------+
| 定义                      | 类型              | 字段(s)                                              | 示例                    |
+-----------------------------+-------------------+------------------------------------------------------+---------------------------+
| APPVERSION                  | 数值              | ``VERSION_MAJOR``（左移 24 位），|br|             | 0x1020304                 |
|                             |                   | ``VERSION_MINOR``（左移 16 位），|br|             |                           |
|                             |                   | ``PATCHLEVEL``（左移 8 位），|br|                |                           |
|                             |                   | ``VERSION_TWEAK``                                    |                           |
+-----------------------------+-------------------+------------------------------------------------------+---------------------------+
| APP_VERSION_NUMBER          | 数值              | ``VERSION_MAJOR``（左移 16 位），|br|             | 0x10203                   |
|                             |                   | ``VERSION_MINOR``（左移 8 位），|br|              |                           |
|                             |                   | ``PATCHLEVEL``                                       |                           |
+-----------------------------+-------------------+------------------------------------------------------+---------------------------+
| APP_VERSION_MAJOR           | 数值              | ``VERSION_MAJOR``                                    | 1                         |
+-----------------------------+-------------------+------------------------------------------------------+---------------------------+
| APP_VERSION_MINOR           | 数值              | ``VERSION_MINOR``                                    | 2                         |
+-----------------------------+-------------------+------------------------------------------------------+---------------------------+
| APP_PATCHLEVEL              | 数值              | ``PATCHLEVEL``                                       | 3                         |
+-----------------------------+-------------------+------------------------------------------------------+---------------------------+
| APP_TWEAK                   | 数值              | ``VERSION_TWEAK``                                    | 4                         |
+-----------------------------+-------------------+------------------------------------------------------+---------------------------+
| APP_EXTRAVERSION            | 字符串（无引号）  | ``EXTRAVERSION``                                     | unstable.5                |
+-----------------------------+-------------------+------------------------------------------------------+---------------------------+
| APP_VERSION_STRING          | 字符串（带引号）  | ``VERSION_MAJOR``，|br|                              | "1.2.3-unstable.5"        |
|                             |                   | ``VERSION_MINOR``，|br|                              |                           |
|                             |                   | ``PATCHLEVEL``，|br|                                 |                           |
|                             |                   | ``EXTRAVERSION`` |br|                                |                           |
+-----------------------------+-------------------+------------------------------------------------------+---------------------------+
| APP_VERSION_EXTENDED_STRING | 字符串（带引号）  | ``VERSION_MAJOR``，|br|                              | "1.2.3-unstable.5+4"      |
|                             |                   | ``VERSION_MINOR``，|br|                              |                           |
|                             |                   | ``PATCHLEVEL``，|br|                                 |                           |
|                             |                   | ``EXTRAVERSION`` |br|                                |                           |
|                             |                   | ``VERSION_TWEAK`` |br|                               |                           |
+-----------------------------+-------------------+------------------------------------------------------+---------------------------+
| APP_VERSION_TWEAK_STRING    | 字符串（带引号）  | ``VERSION_MAJOR``，|br|                              | "1.2.3+4"                 |
|                             |                   | ``VERSION_MINOR``，|br|                              |                           |
|                             |                   | ``PATCHLEVEL``，|br|                                 |                           |
|                             |                   | ``VERSION_TWEAK`` |br|                               |                           |
+-----------------------------+-------------------+------------------------------------------------------+---------------------------+
| APP_BUILD_VERSION           | 字符串（无引号）  | 无（来自应用仓库的                                 | v3.3.0-18-g2c85d9224fca   |
|                             |                   | ``git describe --abbrev=12 --always`` 值）          |                           |
+-----------------------------+-------------------+------------------------------------------------------+---------------------------+

在 MCUboot 支持的应用中使用
=====================================

只要目标应用配置为支持 MCUboot 且生成签名镜像，
就不需要对目标应用做额外配置，版本信息将自动包含在镜像数据中。

在 Shell 中使用
==============

当配置了 shell 接口时，以下命令可用于获取应用版本信息：

+----------------------+-----------------------------+-------------------------+
| 命令              | 变量                    | 示例                 |
+----------------------+-----------------------------+-------------------------+
| app version          | APP_VERSION_STRING          | 1.2.3-unstable.5        |
+----------------------+-----------------------------+-------------------------+
| app version-extended | APP_VERSION_EXTENDED_STRING | 1.2.3-unstable.5+4      |
+----------------------+-----------------------------+-------------------------+
| app build-version    | APP_BUILD_VERSION           | v3.3.0-18-g2c85d9224fca |
+----------------------+-----------------------------+-------------------------+
