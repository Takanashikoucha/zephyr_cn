.. _app-version-details:

应用
版本
管理
******************************

Zephyr
支持
围绕
Zephyr 用于
其
自己
版本
系统
管理
的
系统
的
应用
版本
管理
系统。
这
允许
应用
定义
版本
文件
并
有
应用
（或
模块）
代码
包含
自动
生成
的
文件
并
能够
访问
它，
就像
它们
可以
用
内核
版本
一样。
这个
版本
信息
从
多个
作用域
可用，
包括：

* 代码
  （C/C++）
* Kconfig
* CMake
* Shell

这
使
它
成为
应用
生命周期
管理
的
非常
通用
的
系统。
此外，
它
可以
在
构建
目标
受
支持
引导
加载器
（例如
MCUboot）
的
应用
时
使用，
允许
镜像
自动
用
正确
的
应用
版本
签名
- 不
需要
手动
签名
步骤。

VERSION 文件
=============

应用
版本
信息
按
应用
基础
在
名为
:file:`VERSION` 的
文件
中
设置，
它
必须
放在
应用
的
基础
目录
中，
:file:`CMakeLists.txt` 文件
位于
的
地方。
这
是
一个
简单
的
文本
文件，
包含
各种
版本
信息
字段，
每个
在
新
行
上。
基础
``VERSION`` 文件
有
以下
结构：

.. code-block:: cfg

   VERSION_MAJOR =
   VERSION_MINOR =
   PATCHLEVEL =
   VERSION_TWEAK =
   EXTRAVERSION =

每个
字段
和
它
支持
的
值
在
下面
描述。
Zephyr
将
每个
数值
字段
的
值
限制
为
单个
字节
（注意
根据
版本
的
用途
可能
有
进一步
限制，
例如
引导
加载器
可能
只
支持
这些
字段
的
某些
或
可能
对
字段
的
最大
值
放
限制）：

+---------------+-------------------------------------------------------+---------------+
| 字段          | 数据类型                                              |   必需        |
+---------------+-------------------------------------------------------+---------------+
| VERSION_MAJOR | 数值
  （0-255）                                         |       X       |
+---------------+-------------------------------------------------------+---------------+
| VERSION_MINOR | 数值
  （0-255）                                         |       X       |
+---------------+-------------------------------------------------------+---------------+
| PATCHLEVEL    | 数值
  （0-255）                                         |       X       |
+---------------+-------------------------------------------------------+---------------+
| VERSION_TWEAK | 数值
  （0-255）                                         |       X       |
+---------------+-------------------------------------------------------+---------------+
| EXTRAVERSION  | 字母
  数字
  （小写
  a-z 和
  0-9）
  和
  "." 或
  "-"   |               |
+---------------+-------------------------------------------------------+---------------+

当
应用
用
CMake 配置
时，
版本
文件
将
自动
处理，
并
每次
版本
更改
时
自动
检查，
因此
对
这个
文件
的
更改
不
需要
手动
重新
运行
CMake。

对于
下面
的
章节，
为
以下
:file:`VERSION` 文件
提供
示例：

.. code-block:: cfg

   VERSION_MAJOR = 1
   VERSION_MINOR = 2
   PATCHLEVEL = 3
   VERSION_TWEAK = 4
   EXTRAVERSION = unstable.5

在
代码
中
使用
=============

要
在
应用
代码
中
使用
版本
信息，
必须
包含
版本
文件，
然后
字段
可以
自由
使用。
包含
文件
名
是
:file:`app_version.h`（使用
``#include <zephyr/app_version.h>``），
以下
定义
可用：

+-----------------------------+-------------------+------------------------------------------------------+---------------------------+
| 定义                      | 类型              | 字段(s)                                              | 示例                    |
+-----------------------------+-------------------+------------------------------------------------------+---------------------------+
| APPVERSION                  | 数值            | ``VERSION_MAJOR``（左移
  24 位），|br|    | 0x1020304                 |
|                             |                   | ``VERSION_MINOR``（左移
  16 位），|br|    |                           |
|                             |                   | ``PATCHLEVEL``（左移
  8 位），|br|        |                           |
|                             |                   | ``VERSION_TWEAK``                                    |                           |
+-----------------------------+-------------------+------------------------------------------------------+---------------------------+
| APP_VERSION_NUMBER          | 数值            | ``VERSION_MAJOR``（左移
  16 位），|br|    | 0x10203                   |
|                             |                   | ``VERSION_MINOR``（左移
  8 位），|br|     |                           |
|                             |                   | ``PATCHLEVEL``                                       |                           |
+-----------------------------+-------------------+------------------------------------------------------+---------------------------+
| APP_VERSION_MAJOR           | 数值            | ``VERSION_MAJOR``                                    | 1                         |
+-----------------------------+-------------------+------------------------------------------------------+---------------------------+
| APP_VERSION_MINOR           | 数值            | ``VERSION_MINOR``                                    | 2                         |
+-----------------------------+-------------------+------------------------------------------------------+---------------------------+
| APP_PATCHLEVEL              | 数值            | ``PATCHLEVEL``                                       | 3                         |
+-----------------------------+-------------------+------------------------------------------------------+---------------------------+
| APP_TWEAK                   | 数值            | ``VERSION_TWEAK``                                    | 4                         |
+-----------------------------+-------------------+------------------------------------------------------+---------------------------+
| APP_EXTRAVERSION            | 字符串
  （无
  引号）| ``EXTRAVERSION``                                     | unstable.5                |
+-----------------------------+-------------------+------------------------------------------------------+---------------------------+
| APP_VERSION_STRING          | 字符串
  （带
  引号）| ``VERSION_MAJOR``，|br|                              | "1.2.3-unstable.5"        |
|                             |                   | ``VERSION_MINOR``，|br|                              |                           |
|                             |                   | ``PATCHLEVEL``，|br|                                 |                           |
|                             |                   | ``EXTRAVERSION`` |br|                                |                           |
+-----------------------------+-------------------+------------------------------------------------------+---------------------------+
| APP_VERSION_EXTENDED_STRING | 字符串
  （带
  引号）| ``VERSION_MAJOR``，|br|                              | "1.2.3-unstable.5+4"      |
|                             |                   | ``VERSION_MINOR``，|br|                              |                           |
|                             |                   | ``PATCHLEVEL``，|br|                                 |                           |
|                             |                   | ``EXTRAVERSION`` |br|                                |                           |
|                             |                   | ``VERSION_TWEAK`` |br|                               |                           |
+-----------------------------+-------------------+------------------------------------------------------+---------------------------+
| APP_VERSION_TWEAK_STRING    | 字符串
  （带
  引号）| ``VERSION_MAJOR``，|br|                              | "1.2.3+4"                 |
|                             |                   | ``VERSION_MINOR``，|br|                              |                           |
|                             |                   | ``PATCHLEVEL``，|br|                                 |                           |
|                             |                   | ``VERSION_TWEAK`` |br|                               |                           |
+-----------------------------+-------------------+------------------------------------------------------+---------------------------+
| APP_BUILD_VERSION           | 字符串
  （无
  引号）| 无
  （来自
  应用
  仓库
  的
  ``git describe --abbrev=12 --always`` 值）| v3.3.0-18-g2c85d9224fca   |
+-----------------------------+-------------------+------------------------------------------------------+---------------------------+

在
Kconfig 中
使用
=============

以下
变量
可用
于
Kconfig 文件
中
使用：

+--------------------------------+-----------+--------------------------+--------------------+
| 变量                       | 类型      | 字段(s)                 | 示例            |
+--------------------------------+-----------+--------------------------+--------------------+
| $(VERSION_MAJOR)               | 数值      | ``VERSION_MAJOR``        | 1                  |
+--------------------------------+-----------+--------------------------+--------------------+
| $(VERSION_MINOR)               | 数值      | ``VERSION_MINOR``        | 2                  |
+--------------------------------+-----------+--------------------------+--------------------+
| $(PATCHLEVEL)                  | 数值      | ``PATCHLEVEL``           | 3                  |
+--------------------------------+-----------+--------------------------+--------------------+
| $(VERSION_TWEAK)               | 数值      | ``VERSION_TWEAK``        | 4                  |
+--------------------------------+-----------+--------------------------+--------------------+
| $(EXTRAVERSION)                | 字符串    | ``EXTRAVERSION``         | unstable.5         |
+--------------------------------+-----------+--------------------------+--------------------+
| $(APPVERSION)                  | 字符串    | ``VERSION_MAJOR``，|br|  | 1.2.3-unstable.5   |
|                                |           | ``VERSION_MINOR``，|br|  |                    |
|                                |           | ``PATCHLEVEL``，|br|     |                    |
|                                |           | ``EXTRAVERSION``         |                    |
+--------------------------------+-----------+--------------------------+--------------------+
| $(APP_VERSION_EXTENDED_STRING) | 字符串    | ``VERSION_MAJOR``，|br|  | 1.2.3-unstable.5+4 |
|                                |           | ``VERSION_MINOR``，|br|  |                    |
|                                |           | ``PATCHLEVEL``，|br|     |                    |
|                                |           | ``EXTRAVERSION``，|br|   |                    |
|                                |           | ``VERSION_TWEAK``        |                    |
+--------------------------------+-----------+--------------------------+--------------------+
| $(APP_VERSION_TWEAK_STRING)    | 字符串    | ``VERSION_MAJOR``，|br|  | 1.2.3+4            |
|                                |           | ``VERSION_MINOR``，|br|  |                    |
|                                |           | ``PATCHLEVEL``，|br|     |                    |
|                                |           | ``VERSION_TWEAK``        |                    |
+--------------------------------+-----------+--------------------------+--------------------+

在
MCUboot
支持
的
应用
中
使用
=====================================

只要
目标
应用
配置
为
支持
MCUboot 且
生成
签名
镜像，
就
不
需要
对
目标
应用
做
额外
配置，
版本
信息
将
自动
包含
在
镜像
数据
中。

在
Shell 中
使用
============

当
配置
了
shell
接口
时，
以下
命令
可用
于
获取
应用
版本
信息：

+----------------------+-----------------------------+-------------------------+
| 命令              | 变量                    | 示例                 |
+----------------------+-----------------------------+-------------------------+
| app version          | APP_VERSION_STRING          | 1.2.3-unstable.5        |
+----------------------+-----------------------------+-------------------------+
| app version-extended | APP_VERSION_EXTENDED_STRING | 1.2.3-unstable.5+4      |
+----------------------+-----------------------------+-------------------------+
| app build-version    | APP_BUILD_VERSION           | v3.3.0-18-g2c85d9224fca |
+----------------------+-----------------------------+-------------------------+
