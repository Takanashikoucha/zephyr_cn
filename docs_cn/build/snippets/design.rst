片段
设计
###############

本页
记录
片段
功能
的
设计
目标。
更多
信息
可以
在
`Issue #51834`_ 中
找到。

.. _Issue #51834: https://github.com/zephyrproject-rtos/zephyr/issues/51834

- **可
  扩展**：
  例如，
  不
  修改
  zephyr
  仓库
  就
  可以
  为
  现有
  内置
  片段
  添加
  开发板
  支持

- **可
  组合**：
  可以
  一次
  使用
  多个
  片段，
  例如
  使用：

  .. code-block:: console

     west build -S <snippet1> -S <snippet2> ...

- **能
  组合
  多种
  类型
  的
  配置**：
  片段
  使
  你
  可以
  在
  一个
  地方
  存储
  多种
  不同
  类型
  的
  构建
  系统
  设置，
  并
  一起
  应用
  它们

- **可
  特化**：
  例如，
  可以
  为
  特定
  开发板
  或
  开发板
  修订
  版本
  自定义
  片段
  的
  行为

- **面向
  未来
  且
  向后
  兼容**：
  片段
  功能
  的
  任意
  未来
  更改
  都
  可以
  实现
  而
  不
  破坏
  旧
  片段
  的
  向后
  兼容性

- **适用
  于
  纯
  "软件"
  更改**：
  与
  shield
  功能
  不同，
  片段
  不
  假设
  存在
  "子
  开发板"、"shield"、"hat"
  或
  任何
  其他
  类型
  的
  连接
  到
  主
  开发板
  的
  外部
  组件

- **DRY**
  （不要
  重复
  自己）：
  片段
  允许
  你
  跳过
  不必要
  的
  重复；
  例如，
  你
  可以
  通过
  将
  ``/(foo|bar)/`` 指定
  为
  设置
  的
  正则
  表达式
  将
  相同
  的
  开发板
  特定
  配置
  应用
  到
  开发板
  ``foo`` 和
  ``bar``，
  它
  然后
  应用
  到
  两个
  开发板
