片段设计
###############

本页记录片段功能的设计目标。
更多信息可在 `Issue #51834`_ 中找到。

.. _Issue #51834: https://github.com/zephyrproject-rtos/zephyr/issues/51834

- **可扩展**：例如，可以不修改 zephyr 仓库就为现有内置片段添加开发板支持

- **可组合**：可以一次使用多个片段，例如使用：

  .. code-block:: console

     west build -S <snippet1> -S <snippet2> ...

- **能组合多种类型的配置**：片段使你可以
  在一个地方存储多种不同类型的构建系统设置，并一起应用它们

- **可特化**：例如，可以为特定开发板或开发板修订版本自定义片段的行为

- **面向未来且向后兼容**：片段功能的任意未来更改都可以实现而不破坏旧片段的向后兼容性

- **适用于纯"软件"更改**：与 shield 功能不同，
  片段不假设存在"子开发板"、"shield"、"hat" 或任何
  其他类型连接到主开发板的外部组件

- **DRY**（不要重复自己）：片段允许你跳过不必要的重复；
  例如，你可以通过将 ``/(foo|bar)/`` 指定为设置的
  正则表达式，将相同的开发板特定配置应用到开发板 ``foo`` 和 ``bar``，
  它随后会应用到这两个开发板
