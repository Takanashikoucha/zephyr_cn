信号量
##########

:dfn:`信号量`是一种实现传统计数信号量的内核对象。

.. contents::
    :local:
    :depth: 2

概念
********

可以定义任意数量的信号量（仅受可用 RAM 限制）。
每个信号量由其内存地址引用。

信号量具有以下关键属性：

* 一个**计数**，指示信号量可被获取的次数。
  计数为零表示信号量不可用。

* 一个**上限**，指示信号量计数可达到的最大值。

信号量在使用之前必须被初始化。
其计数必须被设为一个不超过其上限的非负值。

信号量可以被线程或 ISR **给予**。
给予信号量会增加其计数，
除非计数已等于上限。

信号量可以被线程**获取**。
获取信号量会减少其计数，
除非信号量不可用（即为零）。
当信号量不可用时，
线程可以选择等待其被给予。
任意数量的线程可以同时等待
一个不可用的信号量。
当信号量被给予时，
它被等待时间最长的
最高优先级线程获取。

.. note::
    你可以初始化一个"满"信号量
    （计数等于上限）来限制
    能同时执行关键区的线程数量。
    你也可以初始化一个空信号量
    （计数等于 0，上限大于 0）
    来创建一个闸门，
    在信号量被递增之前
    没有任何等待线程可以通过。
    通用信号量的所有标准
    用例都受支持。

.. note::
    内核确实允许 ISR 获取信号量，
    但如果信号量不可用，
    ISR 不得尝试等待。

实现
**************

定义信号量
==================

信号量使用 :c:struct:`k_sem`
类型的变量来定义。
然后必须通过调用
:c:func:`k_sem_init`
进行初始化。

下面的代码定义一个信号量，
然后通过将其计数设为 0、
上限设为 1 将其配置为
二进制信号量。

.. code-block:: c

    struct k_sem my_sem;

    k_sem_init(&my_sem, 0, 1);

或者，可以通过调用
:c:macro:`K_SEM_DEFINE`
在编译时定义并初始化
一个信号量。

下面的代码与上面代码段
效果相同。

.. code-block:: c

    K_SEM_DEFINE(my_sem, 0, 1);

给予信号量
==================

信号量通过调用 :c:func:`k_sem_give`
来给予。

下面的代码基于上面的示例，
给予信号量以指示
有一个数据单元可供
消费者线程处理。

.. code-block:: c

    void input_data_interrupt_handler(void *arg)
    {
        /* notify thread that data is available */
        k_sem_give(&my_sem);

        ...
    }

获取信号量
==================

信号量通过调用 :c:func:`k_sem_take`
来获取。

下面的代码基于上面的示例，
最多等待 50 毫秒
让信号量被给予。
如果信号量没有在
时限内被获取，
则发出警告。

.. code-block:: c

    void consumer_thread(void)
    {
        ...

        if (k_sem_take(&my_sem, K_MSEC(50)) != 0) {
            printk("Input data not available!");
        } else {
            /* fetch available data */
            ...
        }
        ...
    }

建议用法
**************

使用信号量控制
多个线程
对一组资源的访问。

使用信号量同步
生产线程与消费线程
或 ISR 之间的处理。

配置选项
*********************

相关配置选项：

* 无。

*********************************

启用时，作为用户模式
线程的计数信号量工作。

:c:struct:`sys_sem` 的行为
与 :c:struct:`k_sem` 相同。
