系统线程
##############

.. contents::
    :local:
    :depth: 2

:dfn:`系统线程`是内核在系统初始化期间
自动生成的线程。

内核生成以下系统线程：

**主线程**
    此线程执行内核初始化，然后调用应用的
    :c:func:`main` 函数（如果有定义）。

    默认情况下，主线程使用配置的最高可抢占线程
    优先级（即 0）。如果内核未配置为支持可抢占
    线程，主线程使用配置的最低协同线程
    优先级（即 -1）。

    主线程在执行内核初始化或执行应用的 :c:func:`main` 函数期间
    是基本线程；
    这意味着如果线程中止将引发致命系统错误。如果
    未定义 :c:func:`main`，或它执行后正常
    返回，主线程正常终止且不引发错误。

**空闲线程**
    当系统没有其他工作时，此线程执行。
    如果可能，空闲线程激活板卡的电源管理支持
    以节省电力；否则，空闲线程只是执行"空操作"
    循环。空闲线程在系统运行期间始终存在
    且从不终止。

    空闲线程始终使用配置的最低线程优先级。

    空闲线程是基本线程，这意味着如果线程
    中止将引发致命系统错误。

根据应用指定的内核
和板配置选项，还可能生成额外的系统线程。例如，
启用系统工作队列会生成一个系统线程
来处理提交给它的工作项。（请参阅 :ref:`workqueues_v2`。）

实现
**************

编写 main() 函数
=========================

应用提供的 ``main()`` 函数在
内核初始化完成后开始执行。内核不向该函数
传递任何参数，除非选择了 ``CONFIG_BOOTARGS``。在这种情况下
内核向它传递参数，可以使用 ``main(int, char **)``。

以下代码概述了一个简单的 ``main(void)`` 函数。
实际应用使用的函数可以
根据需要复杂。

.. code-block:: c

    int main(void)
    {
        /* initialize a semaphore */
	...

	/* register an ISR that gives the semaphore */
	...

	/* monitor the semaphore forever */
	while (1) {
	    /* wait for the semaphore to be given by the ISR */
	    ...
	    /* do whatever processing is now needed */
	    ...
	}
    }

建议用途
**************

使用主线程在只需要单个线程的应用中
执行基于线程的处理，而不是定义额外的
应用特定线程。
