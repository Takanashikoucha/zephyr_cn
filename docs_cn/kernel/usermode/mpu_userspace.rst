.. _mpu_userspace:

MPU 支持的用户空间
####################

MPU
支持
的
用户
空间
实现
需要
创建
第二
套
栈。
这些
栈
与
系统
中
定义
的
每个
线程
栈
存在
1:1
关系。
特权
栈
作为
构建
过程
的
一部分
创建。

构建
后
脚本
:ref:`gen_kobject_list.py`
扫描
生成
的
ELF
文件
并
找到
所有
线程
栈
对象。
创建
一组
特权
栈、
查找
表
和
一组
辅助
函数，
并
添加
到
镜像
中。

在
将
线程
降级
到
用户
模式
的
过程
中，
特权
栈
信息
被
填充，
然后
由
切换
和
系统
调用
基础设施
使用，
为
线程
栈
和
保护
（如果
适用）
正确
配置
MPU
区域。

在
系统
调用
期间，
用户
模式
线程
对
系统
调用
和
传入
参数
的
访问
都
被
验证。
然后
用户
模式
线程
被
提升
到
特权
模式，
栈
切换
为
使用
特权
栈，
并
调用
指定
的
内核
API。
在
从
内核
API
返回
时，
线程
被
设置
回
用户
模式，
栈
恢复
为
用户
栈。
