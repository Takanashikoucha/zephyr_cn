基于 MPU 的用户空间
####################

基于 MPU 的用户空间实现需要创建第二组栈。
这些栈与系统中定义的每个线程栈以一一对应关系存在。
特权（privileged）栈作为构建过程的一部分创建。

构建后脚本 :ref:`gen_kobject_list.py` 扫描生成的 ELF 文件
并找到所有线程栈对象。
一组特权栈、一个查找表（lookup table）和一组辅助函数
会被创建并添加到镜像中。

在线程降级到用户模式的过程中，特权栈信息被填充，
随后由上下文切换（swap）和系统调用基础设施
用来为线程栈和栈保护（如适用）正确配置 MPU 区域。

在系统调用期间，用户模式线程对系统调用本身
以及传入参数的访问都会被验证。
然后用户模式线程被提升到特权模式，
栈切换到使用特权栈，并调用指定的内核 API。
从内核 API 返回时，线程被设置回用户模式，
栈恢复为用户栈。
