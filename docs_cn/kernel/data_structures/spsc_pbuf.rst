单生产者单消费者数据包缓冲
=============================================

:dfn:`单生产者单消费者数据包缓冲（SPSC_PBUF）`是一种环形
缓冲，其内容按先进先出顺序存储。缓冲区中存储
变长数据包。数据包缓冲基于这样的假设：
有一个上下文产生数据包，有一个上下文
消费数据。

实现专注于性能和内存占用。

使用 :c:func:`spsc_pbuf_write` 将数据包添加到缓冲区，
它将数据拷贝到缓冲区中。如果缓冲区已满则返回错误。

使用 :c:func:`spsc_pbuf_read` 将数据包从缓冲区拷贝出来。
