.. _spsc_pbuf:

单生产者单消费者数据包缓冲区
=============================================

:dfn:`单生产者单消费者数据包缓冲区（Single Producer Single Consumer Packet Buffer, SPSC_PBUF）`是一种环形缓冲区，其内容按先进先出顺序存储。可变大小的数据包存储在缓冲区中。数据包缓冲区基于如下假设工作：存在单个产生数据包上下文，以及单个消费数据的上下文。

实现专注于性能和内存占用。

数据包用 :c:func:`spsc_pbuf_write` 添加到缓冲区，它会将数据复制到缓冲区中。如果缓冲区已满，则返回错误。

数据包用 :c:func:`spsc_pbuf_read` 从缓冲区复制出来。
