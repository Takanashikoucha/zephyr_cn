.. _data_structures:

数据结构
###########

Zephyr 提供了一组通用的基础数据结构库，
在内核内部使用，同时也适用于一般的应用代码。
这些数据结构包括用于存储有序数据的链表和平衡树结构，
以及用于以整洁方式管理"字节流"数据的环形缓冲区。

请注意，这些集合通常以"侵入式"（intrusive）
数据结构的方式实现。库代码唯一使用的结构体是"节点"数据，
它不存储指向用户数据的指针或其他元数据，
也不表明该节点"拥有"哪些用户数据。
相反，设计预期是节点本身嵌入在用户定义的结构体中。
宏被提供用于以整洁的方式从嵌入式节点指针
获取用户结构体的地址。这一设计的目的
是允许这些集合在禁止动态分配的场景中使用
（即无需分配节点对象，因为内存由用户提供）。

也请注意，这些库通常是无同步的；
默认情况下对它们的访问不是线程安全的。
它们是数据结构，而非同步原语。
预期任何所需的锁都由用户自行提供。
部分提供的数据结构在特定使用场景下是线程安全的
（参见 :ref:`spsc_lockfree` 和 :ref:`mpsc_lockfree`）。
