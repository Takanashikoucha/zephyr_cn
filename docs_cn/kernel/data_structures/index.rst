数据结构
########

Zephyr 内核提供一组经过优化的基础数据结构，
用于高效的线程间通信和内核内部状态管理。
这些数据结构针对嵌入式环境的资源约束进行了优化，
避免动态内存分配，提供确定性的性能。

单链表（slist）
**************

单链表是 Zephyr 中最简单的链表实现，
每个节点仅包含一个指向下一个节点的指针。
适用于 FIFO 队列和简单列表场景。

双链表（dlist）
**************

双链表允许向前和向后遍历，
每个节点包含前驱和后继指针。
适用于需要双向遍历的场景。

环形缓冲区
***********

环形缓冲区是固定大小的先进先出队列，
使用环形索引实现无锁的读写操作。
适用于中断上下文和线程间的数据传递。

环形队列（ringq）
******************

ringq 是 Zephyr 的无锁环形队列实现，
支持单生产者单消费者（SPSC）和
多生产者多消费者（MPMC）模式。

最小堆（min_heap）
******************

最小堆是一种优先级队列实现，
支持按优先级快速提取最小元素。
用于 Zephyr 的线程调度器。

红黑树（rbtree）
*****************

红黑树是一种自平衡二叉搜索树，
支持 O(log n) 的查找、插入和删除操作。
用于 Zephyr 的线程调度器（可选）。

无锁多生产者单消费者（mpsc_lockfree）
*************************************

mpsc_lockfree 是一种无锁队列实现，
支持多个生产者和单个消费者。
适用于高并发场景下的数据传递。
