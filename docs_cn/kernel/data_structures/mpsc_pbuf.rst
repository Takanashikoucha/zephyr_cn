多生产者单消费者数据包缓冲
============================================

:dfn:`多生产者单消费者数据包缓冲（MPSC_PBUF）`是一种环形
缓冲，其内容按先进先出顺序存储。缓冲区中存储变长
数据包。数据包缓冲基于这样的假设：只有一个上下文
消费数据。但可能出现另一个上下文介入以冲刷数据且
不再回来的情况（panic 情形）。
数据包的产生分两步：首先分配所请求的数据量，
生产者填充数据并提交它。消费数据包也分两步：
消费者认领（claim）数据包，获取其指针和长度，
之后再释放该数据包。这种方法减少了内存拷贝。

:dfn:`MPSC 数据包缓冲`具有以下关键特性：

* 数据包产生使用"分配、提交"（allocate, commit）方案。
* 数据包消费使用"认领、释放"（claim, free）方案。
* 分配器确保分配所请求长度的连续内存。
* 当所请求的空间无法分配时，可以应用以下策略：

  * **覆盖（Overwrite）**——丢弃最旧的条目，直到能够
    分配所请求量的内存。每丢弃一个数据包都会调用用户回调。
  * **不覆盖（No overwrite）**——当所请求量的空间
    无法分配时，分配失败。
* 用于存储短数据包的专用、优化 API。
* 带超时的分配。

内部实现
---------

缓冲区中的每个数据包都包含一个用于内部管理的
``MPSC_PBUF`` 专用头。该头由 2 个位标志组成。为了
优化内存使用，头可以叠加在用户头之上，使用
:c:macro:`MPSC_PBUF_HDR` 添加，第一个字中剩余的位
可以是应用专用的。头由以下标志组成：

* valid——当数据包包含有效用户数据包时置 1 的位
* busy——当数据包正在被消费时（已认领但未释放）置位的位

头状态：

+-------+------+----------------------+
| valid | busy | 描述                  |
+-------+------+----------------------+
| 0     | 0    | 空间空闲              |
+-------+------+----------------------+
| 1     | 0    | 有效数据包            |
+-------+------+----------------------+
| 1     | 1    | 已认领的有效数据包    |
+-------+------+----------------------+
| 0     | 1    | 内部跳过（skip）数据包 |
+-------+------+----------------------+

数据包缓冲空间包含空闲空间、有效用户数据包和内部
跳过数据包。内部跳过数据包表示填充（padding），
例如位于缓冲区末尾处。

分配
^^^^^^^^^^

通过读写索引对来确定可用空间。如果
空间可以分配，则移动临时写索引，并返回缓冲区内部
指向该空间的指针。数据包头被重置。如果分配
需要回绕写索引，则在缓冲区末尾添加一个跳过数据包。
如果空间无法分配且禁用了覆盖，则返回
``NULL`` 指针，或者如果分配带超时则上下文阻塞。

带覆盖的分配
^^^^^^^^^^^^^^^^^^^^^

如果启用了覆盖，则丢弃最旧的数据包，直到能够
分配所请求量的空间。丢弃数据包时检查头中的
``busy`` 标志，以确保当前正在消费的数据包不被覆盖。
在这种情况下，在 busy 数据包之前添加一个跳过数据包，
并丢弃 busy 数据包之后的数据包。当 busy 数据包
被释放时，会检测到这种情况，并将该数据包转换为
跳过数据包以避免重复处理。

使用
-----

数据包头定义
^^^^^^^^^^^^^^^^^^^^^^

数据包头详情见 :zephyr_file:`include/zephyr/sys/mpsc_packet.h`。
API 函数见 :zephyr_file:`include/zephyr/sys/mpsc_pbuf.h`。
头文件被拆分以避免声明数据包时产生包含泛滥
（include spam）。

用户头结构体必须以内部头开头：

.. code-block:: c

   #include <zephyr/sys/mpsc_packet.h>

   struct foo_header {
           MPSC_PBUF_HDR;
           uint32_t length: 32 - MPSC_PBUF_HDR_BITS;
   };

数据包缓冲配置
^^^^^^^^^^^^^^^^^^^^^^

配置结构体包含缓冲区详情、配置标志和
回调。数据包缓冲使用以下回调：

* 丢弃通知——每当数据包因覆盖而被丢弃时调用的回调
* 获取数据包长度——用于确定数据包长度的回调

数据包产生
^^^^^^^^^^^^^^

标准的两步方法：

.. code-block:: c

   foo_packet *packet = mpsc_pbuf_alloc(buffer, len, K_NO_WAIT);

   fill_data(packet);

   mpsc_pbuf_commit(buffer, packet);

性能优化的短数据包存储：

* 32 位字数据包
* 32 位字加指针数据包

注意，由于数据包按值写入，其头中应已
置位 ``valid`` 位。

.. code-block:: c

   mpsc_pbuf_put_word(buffer, data);
   mpsc_pbuf_put_word_ext(buffer, data, ptr);

数据包消费
^^^^^^^^^^^^^^

两步方法：

.. code-block:: c

   foo_packet *packet = mpsc_pbuf_claim(buffer);

   process(packet);

   mpsc_pbuf_free(buffer, packet);
