内存管理
########

以下内容涵盖内存管理的各种主题。

Zephyr 提供多种内存管理方案，
从简单的静态内存池到完整的虚拟内存支持，
开发者可根据应用需求选择合适的方案。

堆（Heap）
**********

Zephyr 提供动态内存分配接口，
允许在运行时分配和释放内存。
堆管理器支持多种分配策略，
包括首次适应、最佳适应和最坏适应。

共享多堆
**********

共享多堆允许在多个子系统之间
共享内存池，提高内存利用效率。

内存块（Slabs）
**************

slab 分配器是一种固定大小内存块分配器，
适用于频繁分配和释放相同大小内存块的场景。
它避免了通用堆分配器的碎片化问题，
提供确定性的分配性能。

系统内存块
***********

系统内存块是 Zephyr 中最基本的内存分配单元，
用于内核内部的小对象分配。

按需分页
**********

按需分页（demand paging）是 Zephyr 的
虚拟内存特性，允许在需要时才将
物理内存页调入地址空间。

虚拟内存
**********

Zephyr 支持基于 MMU 的虚拟内存，
提供地址空间隔离和内存保护。
在支持 MMU 的架构上，
每个线程可以拥有独立的虚拟地址空间。
