Sensor
Device
Threat
Model
##########################

This
document
describes
a
threat
model
for
an
IoT
sensor
device。
Spelling
out
a
threat
model
helps
direct
development
effort
and
can
be
used
to
help
prioritize
these
efforts
as
well。

This
device
contains
a
sensor
of
some
type
（for
example
temperature、
or
a
pressure
in
a
pipe）
which
sends
this
data
to
an
SoC
running
a
microcontroller。
This
microcontroller
connects
to
a
cloud
service
and
relays
this
sensor
data
to
this
service。
The
cloud
service
is
also
able
to
send
configuration
data
to
the
device
as
well
as
software
update
images。
A
general
diagram
can
be
seen
in
Figure
1:

.. figure::
   media/sensor
   model.svg

   Figure
   1.
   Sensor
   General
   Diagram

In
this
sensor
device
the
sensor
connects
with
the
SoC
via
an
SPI
bus
and
the
SoC
has
a
network
interface
that
it
uses
to
communicate
with
the
cloud
service。
The
particulars
of
these
interfaces
can
impact
the
threat
model
in
unexpected
ways
and
variants
on
this
will
need
to
be
considered
（for
example
using
a
separate
network
interface
SoC
connected
via
some
type
of
bus）。

This
model
also
focuses
on
communicating
via
the
MQTT
over
TLS
protocol
as
this
seems
to
be
in
wide
use
[1]_。

of

model
to
consider
are
assets
involved
in
the

enumerates
the
assets
included

device
flash
that
is
the
first
code
to
run。

order
to
establish
a
root
of
trust
this
image
must
be
immutable。
