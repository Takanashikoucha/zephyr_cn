Security 标准与 Zephyr
#############################

历史上，各组织独立管理网络安全，自行定义评估和响应协议。如今，各国政府正通过新的法令和安全标准对该领域进行越来越多的监管。这些标准为联网产品定义了具体的指南和合规要求。

本节评估这些安全标准对 Zephyr 项目本身以及下游产品开发者的影响。目标是为开发者提供使用 Zephyr 构建可认证、合规产品所需的信息。
