ETSI 303-645
############


**ETSI EN 303 645**，又称"消费者物联网网络安全：基本要求"，是由欧洲电信标准协会（ETSI）制定的标准。

该标准包括关于安全软件更新、数据保护、安全通信以及最小化暴露攻击面等方面的规定。它是更广泛努力的一部分，旨在应对与物联网设备相关的挑战和风险。

该标准的完整版本可在 `此处 <https://www.etsi.org/deliver/etsi_en/303600_303699/303645/02.01.01_60/en_303645v020101p.pdf>`_ 找到。


术语
***********

.. list-table:: ETSI 303645 术语
    :widths: 17 43

    * - 管理员
      - 拥有设备用户可能拥有的最高权限级别的用户，这可能意味着他们能够更改与预期功能相关的任何配置。

    * - 关联服务
      - 与设备一起构成整体消费者物联网产品，且通常提供产品预期功能所需的数字服务。

    * - 认证机制
      - 用于证明实体真实性的方法。

    * - 认证值
      - 认证机制使用的属性的单个值。

    * - 最佳实践密码学
      - 适用于相应用例且没有表明使用当前易得技术可行攻击的密码学。

    * - 受限设备
      - 由于由其预期用途产生的限制，在数据处理能力、数据通信能力、数据存储能力或与用户交互能力方面存在物理限制的设备。

    * - 消费者
      - 为与其贸易、业务、工艺或职业无关的目的而行为的自然人。

    * - 消费者物联网设备
      - 网络连接（且可网络连接）的设备，与关联服务有关系，由消费者通常在家中或作为电子穿戴设备使用。

    * - 关键安全参数
      - 其泄露或修改可能危及安全模块安全性的安全相关秘密信息。

    * - 调试接口
      - 制造商在开发期间与设备通信或对设备问题进行分诊时使用的物理接口，且不作为面向消费者功能的一部分使用。

    * - 定义支持期
      - 制造商将提供安全更新的最短时间长度，以时间段或结束日期表示。

    * - 设备制造商
      - 创建组装的最终消费者物联网产品的实体，该产品可能包含许多其他供应商的产品和组件。

    * - 出厂默认
      - 设备在工厂重置后或最终生产/组装后的状态。

    * - 初始化
      - 激活设备网络连接以进行操作的过程，并可选地为用户或网络访问设置认证功能。

    * - 初始化状态
      - 设备在初始化后的状态。

    * - 物联网产品
      - 消费者物联网设备及其关联服务。

    * - 可隔离
      - 能够从其连接的网络中移除，其中任何功能损失仅与该连接相关而非与其主要功能相关；或者，能够与其他设备一起放置在自包含环境中，当且仅当该环境中设备的完整性能够得到保证时。

    * - 逻辑接口
      - 利用网络接口通过通道或端口通过网络通信的软件实现。

    * - 制造商
      - 供应链中相关的经济运营商（包括设备制造商）。

    * - 网络接口
      - 可通过网络访问消费者物联网功能的物理接口。

    * - 所有者
      - 拥有或购买了设备的用户。

    * - 个人数据
      - 与已识别或可识别自然人相关的任何信息。

    * - 物理接口
      - 在物理层与设备通信使用的物理端口或空口（如无线电、音频或光）。

    * - 公共安全参数
      - 其修改可能危及安全模块安全性的安全相关公共信息。

    * - 远程可访问
      - 旨在从本地网络外部可访问。

    * - 安全模块
      - 实现安全功能的硬件、软件和/或固件集合。

    * - 安全更新
      - 解决由制造商发现或报告的安全漏洞的软件更新。

    * - 敏感安全参数
      - 关键安全参数和公共安全参数。

    * - 软件服务
      - 用于支持功能的设备软件组件。

    * - 遥测
      - 来自设备的数据，可提供信息帮助制造商识别问题或与设备使用相关的信息。

    * - 每设备唯一
      - 对于给定产品类别或类型的每个单独设备唯一。

    * - 用户
      - 自然人或组织。

    * - R C
      - 该规定是建议且有条件

    * - Y
      - Zephyr 支持该规定

    * - N
      - Zephyr 不支持该规定

    * - N/A
      - 该规定不适用于 Zephyr 或是产品制造商的责任
