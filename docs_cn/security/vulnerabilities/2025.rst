:cve:`2025-10456`
-----------------

蓝牙：使 BLE 目标发送断开
连接请求的半任意能力

在蓝牙低功耗
（BLE）固定通道（如 SMP 或 ATT）的处理中识别出一个漏洞。具体来说，攻击者
可以利用一个缺陷使 BLE 目标（即受攻击设备）
尝试断开固定通道，而蓝牙规范不允许这样做。这导致未定义
行为，包括潜在的断言失败、崩溃或内存
破坏。

- `Zephyr 项目缺陷跟踪器 GHSA-hcc8-3qr7-c9m8
  <https://github.com/zephyrproject-rtos/zephyr/security/advisories/GHSA-hcc8-3qr7-c9m8>`_

该问题已在 main 分支修复，将随 v4.2.0 发布

- `PR 93576 main 分支修复
  <https://github.com/zephyrproject-rtos/zephyr/pull/93576>`_

- `PR 100474 3.7 分支修复
  <https://github.com/zephyrproject-rtos/zephyr/pull/100474>`_

:cve:`2025-12899`
-----------------

net: icmp：越界内存读取

为 ICMPv6 回声请求。这导致越界内存读取，并在网络子系统中创建潜在的
信息泄露漏洞。
