:cve:`2021-3436`
----------------

Bluetooth: 当已知绑定（bond）的身份地址时，在密钥分发阶段可能覆盖现有绑定

在分发身份地址信息的过程中，我们不检查是否具有相同身份地址的现有绑定。这意味着将在 RAM 中创建一个重复条目，而最新条目将覆盖持久存储中的现有条目。

此问题已在 main 分支（v2.6.0）中修复

- `Zephyr 项目 bug 跟踪器 GHSA-j76f-35mc-4h63
  <https://github.com/zephyrproject-rtos/zephyr/security/advisories/GHSA-j76f-35mc-4h63>`_

- `PR 33266 修复 main
  <https://github.com/zephyrproject-rtos/zephyr/pull/33266>`_

:cve:`2021-3510`
----------------

Zephyr JSON 解码器错误解码数组的数组

当使用 JSON_OBJ_DESCR_ARRAY_ARRAY 时，子数组具有令牌类型 JSON_TOK_LIST_START，但随后赋值给联合体的对象部分。arr_parse 然后获取数组对象的偏移量（与列表无关），将其视为相对于父对象，并将子数组的长度存储在其中。

此问题已在 main 分支（v2.7.0）中修复

- `Zephyr 项目 bug 跟踪器 GHSA-289f-7mw3-2qf4
  <https://github.com/zephyrproject-rtos/zephyr/security/advisories/GHSA-289f-7mw3-2qf4>`_

- `PR 36340 修复 main
  <https://github.com/zephyrproject-rtos/zephyr/pull/36340>`_

:cve:`2021-3581`
----------------

HCI 数据未正确检查导致蓝牙协议栈内存溢出

在通过 HCI 命令设置 SCAN_RSP 的过程中，Zephyr 蓝牙协议栈未有效检查传入 HCI 数据的长度。导致内存溢出，随后内存中的数据被覆盖，甚至可能导致任意代码执行。
