CVE-2017
########

:cve:`2017-14199`
-----------------

:code:`getaddrinfo()` 中的缓冲区溢出。

- `Zephyr 项目 bug 跟踪器 ZEPSEC-12
  <https://zephyrprojectsec.atlassian.net/browse/ZEPSEC-12>`_

- `PR6158 修复 1.11.0
  <https://github.com/zephyrproject-rtos/zephyr/pull/6158>`_

:cve:`2017-14201`
-----------------

Shell DNS 命令可能因误用栈变量而导致不可预测的结果。

Zephyr shell 中的释放后使用（Use After Free）漏洞允许通过串口或 telnet 连接的用户造成拒绝服务，并可能导致远程代码执行。

此问题已在 v1.14.0 版本中修复。

- `Zephyr 项目 bug 跟踪器 ZEPSEC-17
  <https://zephyrprojectsec.atlassian.net/browse/ZEPSEC-17>`_

- `PR13260 修复 v1.14.0
  <https://github.com/zephyrproject-rtos/zephyr/pull/13260>`_

:cve:`2017-14202`
-----------------

Shell 实现未对缓冲区溢出进行保护，导致不可预测的行为。

Zephyr shell 组件中的内存缓冲区边界内操作限制不当（Improper Restriction of Operations within the Bounds of a Memory Buffer）漏洞允许通过串口或 telnet 连接的用户导致崩溃，并可能伴随任意代码执行。

此问题已在 v1.14.0 版本中修复。

- `Zephyr 项目 bug 跟踪器 ZEPSEC-18
  <https://zephyrprojectsec.atlassian.net/browse/ZEPSEC-18>`_

- `PR13048 修复 v1.14.0
  <https://github.com/zephyrproject-rtos/zephyr/pull/13048>`_
