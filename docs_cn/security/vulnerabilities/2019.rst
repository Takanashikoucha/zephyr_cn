CVE-2019
########

:cve:`2019-9506`
----------------

蓝牙 BR/EDR 规范（包括 5.1 版本及更早版本）允许足够低的加密密钥长度，并且不阻止攻击者影响密钥长度协商。这使得实际的暴力破解攻击（又称"KNOB"）成为可能，攻击者可以解密流量并注入任意密文，而受害者不会察觉。

  <https://zephyrprojectsec.atlassian.net/browse/ZEPSEC-20>`_
