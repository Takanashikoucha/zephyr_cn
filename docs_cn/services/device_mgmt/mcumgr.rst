.. _mcu_mgr:

MCUmgr
#######

概述
********

管理子系统允许远程管理基于 Zephyr 的设备。
可用的管理操作如下：

* :ref:`OS 管理<mcumgr_smp_group_0>`
* :ref:`映像管理<mcumgr_smp_group_1>`
* :ref:`统计管理<mcumgr_smp_group_2>`
* :ref:`设置（配置）管理<mcumgr_smp_group_3>`
* :ref:`文件系统管理<mcumgr_smp_group_8>`
* :ref:`shell 管理<mcumgr_smp_group_9>`
* :ref:`枚举管理<mcumgr_smp_group_10>`
* :ref:`传输管理<mcumgr_smp_group_11>`
* :ref:`Zephyr 基础管理<mcumgr_smp_group_63>`

管理子系统基于 `MCUmgr`_ 提供的简单管理协议（SMP），
它是一个开源项目，提供一个
可移植到多个实时操作系统的
管理子系统。

管理子系统位于 Zephyr 树内的 :zephyr_file:`subsys/mgmt/`。

另外，还有一个 :zephyr:code-sample:`sample <smp-svr>` 服务器，提供
基于 Bluetooth LE 和串口的
管理功能。

fork Zephyr 仓库。

.. _mcumgr_jlink_ob_virtual_msd:

J-Link 虚拟 MSD 交互说明
***********************************

在存在 J-Link OB 的板卡上，如果该 J-Link OB 同时具有 CDC 和 MSC（虚拟
大容量存储设备，也称为拖放）支持，MSD
功能可能
由于 J-Link 固件中 USB
端点的配置方式（例如在
:zephyr:board:`nrf52840dk` 板卡上），由于
限制了最大数据包大小（最可能在使用
映像
管理命令更新固件时发生），而使
CDC UART 端口上的 MCUmgr 命令无法工作。此问题
可通过禁用 J-Link 设备上的 MSD 功能解决，按照
:ref:`nordic_segger_msd` 的
说明禁用 MSD 支持。

引导加载程序集成
**********************

:ref:`dfu` 子系统将管理子系统与
引导加载程序集成，提供向
设备发送并升级 Zephyr 映像的能力。

当前仅支持 MCUboot 引导加载程序。更多信息参见 :ref:`mcuboot`。
