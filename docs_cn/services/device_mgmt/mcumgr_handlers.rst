MCUmgr

Zephyr

management

group

Group
ID

SMP

identify

group

一
个
8

command

该
group
要
execute
的
function
-
参考
:ref:`mcumgr_smp_protocol_specification`
获取
SMP
protocol
和
header
的
details。
每个
unique
的
ID
只
能
有
一
个
registered

   none

   <dir>/grp/<grp_name>_mgmt/

   CMakeLists.txt
   ├──
   Kconfig
   ├──
   include
   ├────
   <grp_name>_mgmt.h
   ├────
   <grp_name>_mgmt_callbacks.h
   ├──
   src
   └────
   <grp_name>_mgmt.c

Zephyr
MCUmgr

``zephyr/include/zephyr/mgmt/mcumgr/grp/<grp_name>_mgmt``
