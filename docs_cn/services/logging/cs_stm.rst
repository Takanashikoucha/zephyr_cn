Multi
domain
logging
using
ARM
Coresight
STM
############################################

Arm
CoreSight
SoC
400
是
一
个
comprehensive
的
components
library
用于
在
system
中
create
debug
和
trace
functionality。
STM
（System
Trace
Macrocell）
是
一
个
trace
source
它
被
integrated
到
CoreSight
system
中
primarily
designed
用于
对
embedded
在
software
中
的
instrumentation
的
high
bandwidth
的
trace。
这
个
instrumentation
consist
of
对
STMESP
（STM
Extended
Stimulus
Port）
peripheral
registers
的
memory
mapped
writes。
Multiple
cores
可以
shared
并
directly
access
STM
而
不
aware
彼此。
每个
core
有
65536
个
stimulus
ports
（identical
的
register
sets）
它们
可以
independently
accessed
因此
当
不同
的
contexts
想
log
data
时
不
需要
locking。

STM
Extended
Stimulus
Port
（STMESP）
***********************************

Local
domain
（每个
core）
可以
access
它
自己
的
STMESP
peripherals
set。
每个
set
有
registers
用于
write
data
（带
或
不
带
timestamp
和
带
或
不
带
marking）
和
write
一
个
flag。
每个
对
STMESP
register
的
write
result
在
user
data
被
encoded
到
MIPI
System
Trace
Protocol
v2
（STPv2）
中。
Hardware
manage
来自
不同
STMESP
register
sets
和
不同
cores
的
data
的
multiplexing
在
necessary
时
向
stream
add
Major
和
Channel
opcodes。
Timestamp
（来自
所有
cores
的
common
source）
和
synchronization
opcodes
被
STM
autonomously
added。

STM
generated
的
data
stream
可以
end
up
在
各种
sinks
中。
例如
它
可以
directly
send
到
TPIU
（Trace
Port
Interface
Unit）
或
saved
在
RAM
Circular
Buffer
中
它
被
called
ETR
（Embedded
Trace
Router）。
TPIU
是
一
个
5
pin
的
interface
（4
data
pins
和
clock）
且
需要
external
的
tool
capture
data
（例如
J
Trace
PRO）。
当
ETR
被
used
时
system
中
一
个
core
负责
process
该
data
例如
通过
UART
dump
它
到
host。

ARM
Coresight
Embedded
Trace
Router
（ETR）
*****************************************

ETR
是
一
个
circular
RAM
buffer
tracing
data
被
saved
到
那里。
因为
它
可能
contain
来自
各种
sources
的
data
additional
的
wrapping
protocol
被
used
用于
multiplex
它们。
``Coresight
Trace
Formatter``
被
used
用于
这
个。
Data
被
encoded
到
16
bytes
的
frames
中
它们
hold
up
to
15
byte
的
data。
Circular
RAM
buffer
的
size
被
limited
到
4k
因此
有
data
overflow
的
risk。
如果
overflow
发生
则
data
被
lost
但
由于
STPv2
data
stream
中
synchronization
opcodes
的
presence
synchronization
可以
被
restored。

ETR
的
data
在
device
上
被
handled。
它
可以
as
is
被
forwarded
到
host
（例如
用
UART）
