Formatted

Applications

Zephyr

用于
format
values
用于

Standard

C99

``*printf()``

streaming
output

或
memory

systems

不

streamed
的
data
且
可能
没有
available
的
memory

formatted
的

Internal
的
Zephyr
API

为
:c:func:`printk`
和
Zephyr

minimal

这
个
但
用

Logging、

和

build
options

这些
APIs
或
standard
的
libc

:c:func:`cbprintf`
public
APIs

C99
的
format
strings
和
arguments
provide
output
它
一
个
character

个
地
产生
通过
一
个
callback

原始
的
internal
functions
并
provide
support
用于
almost
所有

C99
format

Zephyr
中

的
``s*printf()``

libraries

converted

:c:func:`snprintfcb()`

in

Several

被

features

memory

*
:kconfig:option:`CONFIG_CBPRINTF_FULL_INTEGRAL`

:kconfig:option:`CONFIG_CBPRINTF_REDUCED_INTEGRAL`
*
:kconfig:option:`CONFIG_CBPRINTF_FP_SUPPORT`
*
:kconfig:option:`CONFIG_CBPRINTF_FP_A_SUPPORT`
*
:kconfig:option:`CONFIG_CBPRINTF_FP_ALWAYS_A`
*
:kconfig:option:`CONFIG_CBPRINTF_N_SPECIFIER`

:kconfig:option:`CONFIG_CBPRINTF_LIBC_SUBSTS`

cbprintf

Additionally
:kconfig:option:`CONFIG_CBPRINTF_NANO`
可

back

space
optimized
但
limited

formatter
它
被
used
用于
:c:func:`printk`
