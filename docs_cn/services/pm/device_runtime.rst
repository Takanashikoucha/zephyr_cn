Device
Runtime
Power
Management
###############################

Introduction
************

Device
runtime
power
management
（PM）
framework
是
一
个
active
的
power
management
mechanism
它
通过
suspend
idle
的
或
不
被
used
的
devices
independently
于
system
state
reduced
overall
的
system
power
consumption。
它
可以
通过
set
:kconfig:option:`CONFIG_PM_DEVICE_RUNTIME`
被
enabled。
在
这
个
model
中
device
driver
负责
indicate
它
何时
需要
device
以及
何时
不
需要。
这
个
information
被
used
用于
determine
何时
基于
usage
count
suspend
或
resume
一
个
device。

当
device
runtime
power
management
在
一
个
device
上
被
enabled
它
的
state
initially
被
set
到
:c:enumerator:`PM_DEVICE_STATE_SUSPENDED`
indicate
它
不
被
used。
在
first
个
device
request
时
它
被
resumed
并
因此
被
put
到
:c:enumerator:`PM_DEVICE_STATE_ACTIVE`
state。
Device
将
保持
在
这
个
state
直到
它
不再
被
used。
在
这
个
point
device
被
suspended
直到
next
个
device
request。
如果
suspension
被
synchronously
performed
device
立即
被
put
到
:c:enumerator:`PM_DEVICE_STATE_SUSPENDED`
state
而如果
它
被
asynchronously
performed
它
first
被
put
到
:c:enumerator:`PM_DEVICE_STATE_SUSPENDING`
state
然后
在
action
被
run
时
被
put
到
:c:enumerator:`PM_DEVICE_STATE_SUSPENDED`
state。

对
在
power
domain
上
的
devices
（通过
devicetree
的
'power-domains'
property）
device
runtime
power
management
automatically
attempt
request
和
release
dependent
的
domain
响应
child
device
上
的
:c:func:`pm_device_runtime_get`
和
:c:func:`pm_device_runtime_put`
calls。

为
了
previous
automatically
control
power
domain
state
device
runtime
PM
必须
在
power
domain
device
上
被
enabled。
要
globally
enable
device
runtime
PM
enable
:kconfig:option:`CONFIG_PM_DEVICE_RUNTIME_DEFAULT_ENABLE`。
要
只
为
select
的
devices
enable
device
runtime
PM
set
``zephyr,pm-device-runtime-auto``
devicetree
property
或
对
select
的
devices
use
:c:func:`pm_device_runtime_enable`。
