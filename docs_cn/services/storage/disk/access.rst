Disk
Access
###########

Overview
********

Disk
access
API
provide
access
到
storage
devices。

Initializing
Disks
******************

因为
many
disk
devices
（such
as
SD
cards）
是
hotpluggable
的
disk
access
API
provide
IOCTLs
用于
initialize
和
de
initialize
disk。
它们
是
如下：

*
:c:macro:`DISK_IOCTL_CTRL_INIT`：
Initialize
disk。
必须
在
additional
的
I/O
operations
可以
在
disk
device
上
run
之前
被
called。
Equivalent
于
call
legacy
的
function
:c:func:`disk_access_init`。

*
:c:macro:`DISK_IOCTL_CTRL_DEINIT`：
De
initialize
disk。
一
旦
这
个
IOCTL
被
issued
:c:macro:`DISK_IOCTL_CTRL_INIT`
必须
在
disk
可以
被
used
用于
addition
的
I/O
operations
之前
被
issued。

Init/deinit
IOCTL
calls
是
balanced
的
所以
一
个
disk
将
不
de
initialize
直到
相同
数量
的
deinit
IOCTLs
被
issued
如
init
IOCTLs
那样。

也
可以
force
一
个
disk
de
initialization
通过
passing
一
个
pointer
到
一
个
boolean
set
到
``true``
作为
parameter
到
:c:macro:`DISK_IOCTL_CTRL_DEINIT`
IOCTL。
这
是
一
个
unsafe
的
operation
每个
disk
driver
可能
handle
它
不同
但
它
始终
return
一
个
indicate
success
的
value。

Note
de
initializing
一
个
disk
是
一
个
low
level
的
operation
typically
de
initialization
和
initialization
calls
应该
被
left
到
filesystem
implementation
且
user
application
不
应该
需要
manually
de
initialize
disk
而
可以
instead
call
:c:func:`fs_unmount`
