.. _nvmem:

Non
Volatile
Memory
（NVMEM）
###########################

NVMEM
subsystem
provide
一
个
generic
的
interface
用于
access
non
volatile
的
memory
devices。
它
abstract
underlying
的
hardware
并
provide
一
个
unified
的
API
用于
read
和
write
data。

Key
Concepts
************

NVMEM
Provider
==============

一
个
NVMEM
provider
是
一
个
driver
它
expose
NVMEM
cells。
例如
一
个
EEPROM
driver
可以
是
一
个
NVMEM
provider。
NVMEM
provider
负责
read
和
write
data
到
underlying
的
hardware。

NVMEM
Cell
==========

一
个
NVMEM
cell
是
一
个
region
of
non
volatile
的
memory。
它
在
devicetree
中
defined
且
有
properties
like
offset、
size、
和
read
only
status。

NVMEM
Consumer
==============

一
个
NVMEM
consumer
是
一
个
driver
或
application
它
use
NVMEM
cells
用于
store
或
retrieve
data。

Configuration
*************

*
:kconfig:option:`CONFIG_NVMEM`：
Enable
NVMEM
subsystem。
*
:kconfig:option:`CONFIG_NVMEM_BBRAM`：
Enable
NVMEM
support
用于
Battery
Backed
RAM。
*
:kconfig:option:`CONFIG_NVMEM_EEPROM`：
Enable
NVMEM
support
用于
EEPROM
devices。
*
:kconfig:option-regex:`CONFIG_NVMEM_FLASH.*`：
Configure
NVMEM
support
用于
flash
devices。
*
:kconfig:option-regex:`CONFIG_NVMEM_OTP.*`：
Configure
NVMEM
support
用于
OTP
devices。
