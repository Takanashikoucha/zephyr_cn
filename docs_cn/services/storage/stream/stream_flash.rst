Stream Flash
############

Stream Flash 模块将数据流（例如来自无线电数据包）中的连续片段聚合到用户提供的缓冲区中，当缓冲区填满（或数据流结束）时将其写入原始 flash 分区。它支持将回读缓冲区提供给客户端，用于验证已持久化的流内容。

流写入操作的一个典型用途是在 DFU 操作过程中接收新的固件镜像。

之所以希望使用带缓冲的写入而不是在数据可用时直接写入，原因有以下几点。一些设备存在硬件限制，不允许将 flash 写入与其他操作（例如无线电 RX 和 TX）并行执行。此外，更少的写入操作还能带来应用侧观察到的更快响应时间。

持久化流写入进度
********************************

一些流写入操作（例如 DFU 操作）可能运行很长时间。在执行这类长时间运行的操作时，能够把流写入进度保存到持久化存储中会非常有用，这样在发生意外中断后，操作可以从相同的位置继续执行。

Stream Flash 模块提供了一组 API，用于使用 :ref:`Settings <settings_api>` 模块将流写入进度加载、保存和清除到持久化存储中。该 API 可通过 :kconfig:option:`CONFIG_STREAM_FLASH_PROGRESS` 启用。
