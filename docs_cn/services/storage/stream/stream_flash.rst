Stream
Flash
############

Stream
Flash
module
take
contiguous
的
fragments
of
一
个
stream
of
data
（e.g.
从
radio
packets）
将
它们
aggregated
到
user
provided
的
buffer
中
然后
当
buffer
fills
（或
stream
ends）
时
将
它
written
到
raw
的
flash
partition。
它
support
provide
read
back
的
buffer
到
client
用于
validate
persisted
的
stream
content。

Stream
write
operation
的
一
个
typical
的
use
是在
receiving
新
的
firmware
image
用于
DFU
operation
时。

有
several
reasons
为什么
可能
想
use
buffered
的
writes
而
不
是
当
data
made
available
时
directly
write
它。
Some
devices
有
hardware
limitations
它
不
allow
flash
writes
与
其他
operations
such
as
radio
RX
和
TX
parallel
地
performed。
Also
fewer
的
write
operations
result
在
从
application
seen
的
faster
的
response
times。

Persistent
stream
write
progress
********************************
Some
stream
write
operations
such
as
DFU
operations
可能
run
very
long
的
time。
当
perform
such
long
running
的
operations
时
可以
useful
将
stream
write
progress
save
到
persistent
storage
使
operation
可以
在
unexpected
的
interruption
后
从
相同
的
point
resume。

Stream
Flash
module
offer
一
个
API
用于
load、
save、
和
clear
stream
write
progress
到
persistent
storage
用
:ref:`Settings
<settings_api>`
module。
API
可以
用
:kconfig:option:`CONFIG_STREAM_FLASH_PROGRESS`
被
enabled。
