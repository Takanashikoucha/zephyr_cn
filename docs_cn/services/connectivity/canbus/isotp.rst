Road
vehicles
-
Diagnostic
communication
over
Controller
Area
Network
（DoCAN）。
Part2:
Transport

network

如
其

它

并
仍

road

over
Controller
Area
Networks。

road

或

这

classical
CAN
（8

CAN

（64

此外

ISO-TP

这些

（PCI）。

Classical

七
bytes

（SF）。
它们

大于

FF

Receiving

（FC）

FC

的
conditions

block
size
（BS）

（STmin）。
Block
size
define
sender

allowed

多
少

在

wait
另
一
个
FC
之前。
