Modem
modules
#############

这
个
service
提供
与
modems
communicate
所需
的
modules。

Modems
是
self
contained
的
devices
它们
implement
perform
RF
（Radio
Frequency）
communication
所需
的
hardware
和
software
包括
GNSS、
Cellular、
WiFi
等。

Modem
modules
通过
data
in/data
out
pipes
被
dynamically
inter
connected
使
它们
independently
testable
并
highly
flexible
确保
stability
和
scalability。

Modem
pipe
**********

这
个
module
被
used
来
abstract
data
in/data
out
communication
over
多
种
mechanisms
如
UART
和
CMUX
DLCI
channels
以
thread
safe
的
方式。

一
个
modem
backend
将
internally
contain
一
个
modem
pipe
structure
的
instance
同时
还有
任何
buffers
和
额外
的
structures
所需
来
abstract
away
它
的
underlying
mechanism。

.. image::
   images/modem_pipes.svg
   :alt:
   Modem
   pipes
   :align:
   center

Modem
backend
在
initialized
时
将
return
一
个
pointer
到
它
的
internal
modem
pipe
structure
它
将
被
used
来
通过
modem
pipe
API
与
backend
交互。

   modem_pipe
