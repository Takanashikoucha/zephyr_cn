Zephyr

个

的

stack
它

Zephyr
OS。
它

Network

Network

Network

:ref:`BSD

<bsd_sockets_interface>`

个

Application

:ref:`network

并

相关

network
link
options、
start
一
个
scan
（当
applicable

listen
network
configuration
events
等。
:ref:`network
interface
API
<net_if_interface>`
可
被
used

set
IP
address

network
interface、
take
network
interface
down
等。
