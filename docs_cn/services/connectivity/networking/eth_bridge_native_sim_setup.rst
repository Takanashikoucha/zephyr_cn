.. contents::
    :local:
    :depth:
    2

这

一
个
bridged
的
Ethernet
network
在
（Linux）
host
和

在
:zephyr:board:`native_sim
<native_sim>`
board
中
的
Zephyr
application

这
个
setup
在
testing
Ethernet
bridging
feature
时

该
feature

:kconfig:option:`CONFIG_NET_ETHERNET_BRIDGE`

在

net

两

host

``zeth0``

``zeth1``

它们

Zephyr
的
:zephyr:board:`native_sim
<native_sim>`
application。

首先

host
interfaces。
在
这
个
example
中
两
个
interfaces

.. code-block::
   console

   cd
   $ZEPHYR_BASE/../tools/net-tools
   ./net-setup.sh
   -c
   zeth-multiface.conf
   -i
   zeth0
   -t
   2

``-c``
告诉
use
哪个
configuration
file
其中
``zeth-multiface.conf``
被
tailored
用于
generate
多
个
network
interfaces
在
host
中。
``-i``
option
告诉
first
的
host
interface
name
是什么。
``-t``
告诉
create
多
少
network
interfaces。
