User
#############################

    :local:

这
个
page
intended
作为
一
个
starting
point
用于
任何
对
use
QEMU
SLIRP

Zephyr
感兴趣

人。

Introduction
*************

SLIRP
是
一
个
network
backend
它
provide
完整
的
TCP/IP
stack
在
QEMU
内
并
use
该
stack
implement
一
个
virtual
的
NAT'd
network。
因为
没有
对
host
的
dependencies
SLIRP
set
up
简单。

Default
下
QEMU
use
``10.0.2.X/24``
network
并
run
一
个
gateway
在
``10.0.2.2``。
所有
intended
给
host
network
的
traffic
必须
通过
这
个
gateway
travel
它
将
根据
QEMU
command
line
parameters
filter
out
packets。
这
个
gateway
也
作为
所有
GOS
的
DHCP
server
function
允许
它们
被
automatically
assigned
从
``10.0.2.15``
start
的
IP
address。

关于
User
Networking
的
更多
details
可
从
这里
获得：
https://wiki.qemu.org/Documentation/Networking#User_Networking_.28SLIRP.29

Using
SLIRP
with
Zephyr
************************

要
use
SLIRP
与
Zephyr
user
必须
set
Kconfig
option
enable
User
Networking。

.. code-block::
   cfg

   CONFIG_NET_QEMU_USER=y

一
旦
这
个
configuration
option
被
enabled
所有
的
QEMU
launches
将
use
SLIRP。
