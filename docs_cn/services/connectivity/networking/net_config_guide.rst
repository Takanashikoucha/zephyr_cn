Network
Buffer
Configuration
Options
************************************

Network
buffer
configuration
options
control
我们
能
同时
send
或
receive
多
少
data。

:kconfig:option:`CONFIG_NET_PKT_RX_COUNT`
   我们
能
同时
receive
的
maximum
数量
的
network
packets。

:kconfig:option:`CONFIG_NET_PKT_TX_COUNT`
   同时
pending
的
maximum
数量
的
network
packet
sends。

:kconfig:option:`CONFIG_NET_BUF_RX_COUNT`
   多
少
network
buffers
被
allocated
用于
receiving
data。
每个
net_buf
contain
一
个
small
的
header
和
要么
fixed
要么
variable
length
的
data
buffer。
:kconfig:option:`CONFIG_NET_BUF_DATA_SIZE`
在
:kconfig:option:`CONFIG_NET_BUF_FIXED_DATA_SIZE`
被
set
时
被
used。
这
是
default
的
setting。
Buffer
的
default
size
是
128
bytes。

   :kconfig:option:`CONFIG_NET_BUF_VARIABLE_DATA_SIZE`
   是
一
个
experimental
的
setting。
那里
每个
net_buf
的
data
part
从
一
个
memory
pool
被
allocated
并
可以
是
我们
从
network
received
的
data
数量。
当
data
从
network
received
时
它
被
placed
到
net_buf
的
data
part。
根据
device
resources
和
desired
的
network
usage
user
可以
tweak
fixed
buffer
的
size
通过
set
:kconfig:option:`CONFIG_NET_BUF_DATA_SIZE`
以及
data
pool
的
size
通过
set
:kconfig:option:`CONFIG_NET_PKT_BUF_RX_DATA_POOL_SIZE`
和
:kconfig:option:`CONFIG_NET_PKT_BUF_TX_DATA_POOL_SIZE`
如果
variable
size
的
buffers
被
used。
