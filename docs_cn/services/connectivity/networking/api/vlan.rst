Virtual
LAN
（VLAN）
Support
##########################

.. contents::
    :local:
    :depth:
    2

Overview
********

`Virtual
LAN
<https://wikipedia.org/wiki/Virtual_LAN>`_
（VLAN）
是
一
个
partitioned
和
isolated
的
computer
network
在
data
link
layer
（OSI
layer
2）
上。
对于
ethernet
network
这
refer
到
`IEEE
802.1Q
<https://en.wikipedia.org/wiki/IEEE_802.1Q>`_

在
Zephyr
中
每个
individual
的
VLAN
被
modelled
作为
一
个
virtual
network
interface。
这
意味着
有
一
个
ethernet
network
interface
它
corresponds
到
system
中
真实
的
physical
ethernet
port。
每个
VLAN
create
一
个
virtual
network
interface
这
个
virtual
network
interface
connect
到
真实
的
network
interface。
这
与
Linux
如何
implement
VLANs
相似。
*eth0*
是
真实
的
network
interface
*vlan0*
是
一
个
virtual
network
interface
它
run
在
*eth0*
上面。

VLAN
support
必须
在
compile
time
通过
set
option
:kconfig:option:`CONFIG_NET_VLAN`
和
:kconfig:option:`CONFIG_NET_VLAN_COUNT`
被
enabled
以
reflect
system
中
将
有
多
少
network
interfaces。
例如
如果
有
一
个
不
带
VLAN
support
的
network
interface
和
两
个
带
VLAN
support
的
:kconfig:option:`CONFIG_NET_VLAN_COUNT`
option
应该
被
set
到
3。

即使
VLAN
在
:file:`prj.conf`
file
中
被
enabled
VLAN
也
需要
被
application
在
runtime
activated。
VLAN
API
提供
一
个
:c:func:`net_eth_vlan_enable`
function
用于
做
这
个。
Application
需要
给
出
network
interface
和
desired
的
VLAN
tag
作为
该
function
的
parameter。
给定
network
interface
的
VLAN
tagging
可以
被
:c:func:`net_eth_vlan_disable`
function
disabled。
Application
需要
自己
configure
VLAN
network
interface
如
set
IP
address
等。

也
参考
:zephyr:code-sample:`VLAN
sample
application
<vlan>`
获取
API
usage
