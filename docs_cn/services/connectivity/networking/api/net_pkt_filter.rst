Overview
********

Network
Packet
Filtering
facility
提供
infrastructure
用于
construct
custom
的
rules
用于
accept
和/或
deny
packet
transmission
和
reception。
它
也
允许
modify
incoming
network
packets
的
priority。
这
可以
用
来
create
一
个
basic
的
firewall、
control
network
traffic
等。

必须
set
:kconfig:option:`CONFIG_NET_PKT_FILTER`
才能
enable
相关
的
APIs。

两
个
transmission
和
reception
paths
都
可能
有
一
个
filter
rules
的
list。
每个
rule
由
一
组
conditions
和
一
个
packet
outcome
组成。
每个
packet
被
subjected
到
attached
到
一
个
rule
的
conditions。
当
给定
rule
的
所有
conditions
都
true
时
packet
outcome
被
immediately
determined
如
current
rule
specified
的
并
不
再
consider
更多
的
rules。
如果
一
个
condition
false
那么
list
中
的
next
rule
被
considered。

Packet
outcome
要么
是
``NET_OK``
accept
packet、
``NET_DROP``
drop
它
或
``NET_CONTINUE``
on
the
fly
modify
它
的
priority。

当
outcome
是
``NET_CONTINUE``
时
priority
被
updated
但
final
outcome
还
没
被
determined
processing
继续。
如果
多
个
rules
的
所有
conditions
都
true
那么
packet
get
last
considered
的
rule
的
priority。

一
个
rule
由
一
个
:c:struct:`npf_rule`
object
represented。
它
可以
用
:c:func:`npf_insert_rule()`、
:c:func:`npf_append_rule()`、
和
:c:func:`npf_remove_rule()`
被
inserted
到、
appended
到
或
removed
from
包含
在
:c:struct:`npf_rule_list`
object
中
的
rule
list。
