Overview
********

这
个
gPTP
stack
support
在
`IEEE
802.1AS-2011
standard`_
（Timing
and
Synchronization
for
Time
Sensitive
Applications
in
Bridged
Local
Area
Networks）
中
defined
的
protocol
和
procedures。

Supported
features
*******************

Stack
handle
在
`IEEE
802.1AS-2011
standard`_
中
defined
的
communications
和
state
machines。
Full
duplex
的
point
to
point
link
endpoint
的
mandatory
requirements
如
standard
的
Annex
A
中
defined
的
被
supported。

Stack
在
principle
上
能
handle
多
个
network
interfaces
（也
在
standard
中
defined
为
"ports"）
上
的
communications
并
因此
act
作为
一
个
802.1AS
bridge。
不过
这
个
mode
of
operation
未
在
Zephyr
OS
上
被
validated。

Stack
也
可以
operate
作为
一
个
statically
configured
的
time
receiver
在
follow
IEEE
802.1AS
automotive
profile
的
networks
上
那里
没有
Announce
messages
被
exchanged。
参考
下面
的
`Static
timeReceiver
operation`_。

Supported
hardware
******************

尽管
stack
本身
是
hardware
independent
的
Ethernet
frame
timestamping
support
必须
在
ethernet
drivers
中
被
enabled。
