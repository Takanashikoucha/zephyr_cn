Overview
********

Zephyr
提供
一
个
generic
的
**Datagram
Packetization
Layer
Path
MTU
Discovery**
（DPLPMTUD）
implementation
based
on
:rfc:`8899`。
它
intended
用于
UDP
based
的
transports
（QUIC、
CoAP
over
UDP、
custom
protocols）
它们
必须
discover
多
大
的
datagram
payload
可以
被
send
而
不
rely
on
local
IP
fragmentation。

该
subsystem
将
responsibilities
split
如下：

**Generic
stack**
（``subsys/net/ip/dplpmtud.c``）

*
Per
destination
的
search
state：
validated
PLPMTU、
probe
size、
retry
count、
bounds
*
Base
PLPMTU
（1200
bytes）
和
path
ceiling
之间
的
binary
search
*
与
现有
的
PMTU
destination
cache
的
integration
（ICMP
PTB
in、
validated
size
out）
*
当
PMTU
cache
report
一
个
低于
base
PLPMTU
的
MTU
时
的
black
hole
handling

**Transport
consumer**

*
Construct
probe
datagrams
在
:c:func:`net_dplpmtud_get_path_probe_size()`
returned
的
size
*
Send
probes
带
don't
fragment
enabled
（参考
:ref:`ip_socket_options`
和
:c:macro:`ZSOCK_IP_DONTFRAG`
/
:c:macro:`ZSOCK_IPV6_DONTFRAG`）
*
将
transport
ACK/loss
map
到
:c:func:`net_dplpmtud_on_path_probe_acked()`
和
:c:func:`net_dplpmtud_on_path_probe_lost()`

:ref:`QUIC
<quic_dplpmtud>`
是
in
tree
的
first
consumer。
其他
transports
可以
use
相同
的
API
而
不
duplicate
RFC
8899
的
state
machine。
