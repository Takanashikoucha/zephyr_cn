Overview
********

MQTT-SN
是
well
known
的
MQTT
protocol
的
一
个
variant
-
参考
:ref:`mqtt_socket_interface`。

与
MQTT
不同
MQTT-SN
不
需要
TCP
transport
而是
designed
用于
use
在
任何
message
based
的
transport
上。
原始
它
主要
created
with
ZigBee
in
mind
但
其他
如
Bluetooth、
UDP
甚至
UART
也
可以
同样
被
used。

Zephyr
提供
一
个
MQTT-SN
client
library
它
build
在
BSD
sockets
API
上面。
Library
可
用
:kconfig:option:`CONFIG_MQTT_SN_LIB`
Kconfig
option
enable
并
可
在
per
client
basis
configured
support
MQTT-SN
version
1.2。
Zephyr
MQTT-SN
implementation
可以
用
任何
message
based
的
transport
但
UDP
的
support
已
built
in。

MQTT-SN
clients
需要
一
个
MQTT-SN
gateway
connect
到。
这些
gateways
在
MQTT-SN
和
MQTT
之间
translate。
Eclipse
Paho
project
offer
一
个
MQTT-SN
gateway
的
implementation
但
其他
的
也
available。
https://www.eclipse.org/paho/index.php?page=components/mqtt-sn-transparent-gateway/index.php

MQTT-SN
spec
v1.2
可
在
这里
找到：
https://www.oasis-open.org/committees/download.php/66091/MQTT-SN_spec_v1.2.pdf
