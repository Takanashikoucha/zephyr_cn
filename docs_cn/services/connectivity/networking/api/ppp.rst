Overview
********

`Point
to
Point
Protocol
<https://en.wikipedia.org/wiki/Point-to-Point_Protocol>`_
（PPP）
是
一
个
data
link
layer
（layer
2）
communications
protocol
用于
establish
两
个
nodes
之间
的
direct
connection。
PPP
被
used
在
很
多
type
的
serial
links
上
因为
IP
packets
不
能
单独
通过
modem
line
被
transmitted
没有
某些
data
link
protocol
的
话。

在
Zephyr
中
每个
individual
的
PPP
link
被
modelled
作为
一
个
network
interface。
这
与
Linux
如何
implement
PPP
相似。

PPP
support
必须
在
compile
time
通过
set
option
:kconfig:option:`CONFIG_NET_L2_PPP`
被
enabled。
PPP
implementation
只
support
这些
protocols：

*
LCP
（Link
Control
Protocol
:rfc:`1661`）
*
HDLC
（High
level
data
link
control
:rfc:`1662`）
*
IPCP
（IP
Control
Protocol
:rfc:`1332`）
*
IPV6CP
（IPv6
Control
Protocol
:rfc:`5072`）

参考
:zephyr:code-sample:`cellular-modem`
sample
获取
关于
用
cellular
modem
使用
PPP
的
额外
information。
