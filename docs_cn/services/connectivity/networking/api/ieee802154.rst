IEEE 802.15.4
#############

.. contents::
    :local:
    :depth: 2

Introduction
************

IEEE 802.15.4 是定义 low-rate wireless personal area networks（LR-WPANs）操作的 technical standard。此 standard 更详细的概述参见 `IEEE 802.15.4 Wikipedia article <https://en.wikipedia.org/wiki/IEEE_802.15.4>`_。

Standard 的最新版本可通过 `IEEE GET Program <https://ieeexplore.ieee.org/browse/standards/get-program/page/series?id=68>`_ 获取。您需创建免费 IEEE account（然后可下载。

我们当前遵循 IEEE 802.15.4-2020 specification。此版本向后兼容 IEEE 802.15.4-2015（其部分包含在 Thread protocol stack 中。2020 版本还包含已被接受到 standard 中的先前 extensions（即 IEEE 802.15.4g（SUN FSK）和 IEEE 802.15.4e（TSCH）（其与 industrial IoT 和 automation 相关。UWB ranging technology 的最新发展参见 IEEE 802.15.4z（其尚未集成到 standard 的 mainline 中。

文档中引用 standard 的 sections 时（除非另有指定（其指 IEEE 802.15.4-2020 的 section、table 和 figure 编号。

Zephyr 同时支持 native IEEE 802.15.4 和带 6LoWPAN 的 Thread。Zephyr 的 :ref:`thread_protocol_interface` 实现基于 `OpenThread <https://openthread.io/>`_。6LoWPAN 中的 IPv6 header compression 用于 native IEEE 802.15.4。

IEEE 802.15.4 Management API
============================

这是 IEEE 802.15.4 **application developers** 关注的主要 subsystem-specific API（其允许在 runtime 配置 IEEE 802.15.4 subsystem。Application developers 的其他相关 interfaces 为典型的 shell、socket、Kconfig 和 devicetree APIs（可通过 Zephyr 的 generic subsystem-independent 文档访问。在其中留意 IEEE802154/ieee802154 前缀。

.. doxygengroup:: ieee802154_driver


.. _ieee802154_l2_api:

IEEE 802.15.4 L2 / Native Stack API
===================================

此文档记录 IEEE 802.15.4 L2 native stack（applications 和 drivers 均从不直接访问。其由 Zephyr 的上层 network layers（L3+）及其 socket 和 network context abstractions 内部调用。因此此 API 仅对 IEEE 802.15.4 **subsystem contributors** 有用。

.. doxygengroup:: ieee802154_l2

OpenThread L2 Adaptation Layer API
==================================

Zephyr 的 OpenThread L2 platform adaptation layer 将外部 OpenThread stack 与 Zephyr 的 IEEE 802.15.4 protocol agnostic driver API 粘合在一起。此 API 仅对 OpenThread L2 **subsystem contributors** 有用。

OpenThread API 为 :ref:`thread_protocol_interface` subsystem 的一部分（并在那里文档化。
