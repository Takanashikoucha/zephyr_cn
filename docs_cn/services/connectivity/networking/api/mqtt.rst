Overview
********

MQTT
（Message
Queuing
Telemetry
Transport）
是
一
个
application
layer
protocol
它
work
在
TCP/IP
stack
上面。
它
是
一
个
lightweight
的
publish/subscribe
messaging
transport
用于
machine
to
machine
的
communication。
关于
protocol
本身
的
更多
information
参考
https://mqtt.org/。

Zephyr
提供
一
个
MQTT
client
library
它
build
在
BSD
sockets
API
上面。
Library
可
用
:kconfig:option:`CONFIG_MQTT_LIB`
Kconfig
option
enable
并
可
在
per
client
basis
configured
support
MQTT
versions
3.1.0、
3.1.1
和
5.0。
Zephyr
MQTT
implementation
可以
用
plain
的
sockets
通过
TCP
communicate
或
用
secure
的
sockets
通过
TLS
communicate。
参考
:ref:`bsd_sockets_interface`
获取
关于
Zephyr
sockets
的
更多
information。

MQTT
clients
需要
一
个
MQTT
server
connect
到。
这样
一
个
server
被
called
MQTT
Broker
它
负责
manage
client
subscriptions
并
distribute
由
clients
published
的
messages。
有
很
多
MQTT
brokers
的
implementations
其中
一
个
是
Eclipse
Mosquitto。
参考
https://mosquitto.org/
获取
关于
Eclipse
Mosquitto
project
的
更多
information。

usage

create
一
个
MQTT
client
需要
define
一
个
client
context
structure
和
buffers：

   /*
