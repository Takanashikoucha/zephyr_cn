Wi
Fi
feature
到
crypto
的
mapping
###############################

这
个
page
将
Zephyr
中
supported
的
Wi
Fi
features
（通过
hostap
based
的
wpa
supplicant）
map
到
底层
的
MbedTLS
crypto
primitives。
用
它
看
哪些
features
需要
bignum、
ECDH、
TLS
等
以及
当
:kconfig:option:`CONFIG_WIFI_NM_WPA_SUPPLICANT_CRYPTO_MBEDTLS_PSA`
被
enabled
时
哪些
code
paths
use
**Legacy
crypto**
（MbedTLS
legacy
APIs）
vs
**PSA
crypto**
（Platform
Security
Architecture
APIs）。

Implementation
在
hostap
module
中：
``crypto_mbedtls_alt.c``
（generic
crypto）
和
``tls_mbedtls_alt.c``
（TLS/EAP）。
只
consider
MbedTLS
backend。

Feature
set
（来自
hostap
Kconfig）
*********************************

Features
被
Kconfig
gated。
相关
的
options
包括：

*
:kconfig:option:`CONFIG_WIFI_NM_WPA_SUPPLICANT_WEP`
—
WEP
（legacy）
*
:kconfig:option:`CONFIG_WIFI_NM_WPA_SUPPLICANT_WPA3_COMMON`
—
WPA3-SAE
当
Internal
或
External
被
selected
（``WIFI_NM_WPA_SUPPLICANT_WPA3_IMPLEMENTATION``
default
Internal）。
:kconfig:option:`CONFIG_WIFI_NM_WPA_SUPPLICANT_WPA3`
是
promptless
的
并
在
Internal
被
chosen
时
turn
on
internal
的
bignum
SAE
path
（在
``prj.conf``
中
set
implementation
choice
而
不
是
这
个
symbol）。
*
:kconfig:option:`CONFIG_WIFI_NM_WPA_SUPPLICANT_DPP`
—
Wi
Fi
Easy
Connect
（DPP）
*
:kconfig:option:`CONFIG_WIFI_NM_WPA_SUPPLICANT_WPS`
—
Wi
Fi
Protected
Setup
*
:kconfig:option:`CONFIG_WIFI_NM_WPA_SUPPLICANT_P2P`
—
P2P
/
Wi
Fi
Direct
（imply
WPS）
*
:kconfig:option:`CONFIG_WIFI_NM_WPA_SUPPLICANT_CRYPTO_ENTERPRISE`
—
EAP
（EAP-TLS、
EAP-TTLS-MSCHAPV2、
EAP-PEAP-MSCHAPV2、
EAP-PEAP-GTC、
EAP-PEAP-TLS）

只要
crypto
不
被
set
到
``CRYPTO_NONE``
WPA2-PSK
和
WPA2-PSK-256
就
available。
