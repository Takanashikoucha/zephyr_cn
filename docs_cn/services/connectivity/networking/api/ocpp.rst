Overview
********

Open
Charge
Point
Protocol
（OCPP）
是
一
个
application
protocol
用于
Charge
Points
（Electric
vehicle
（EV）
charging
stations）
和
central
management
system
之间
的
communication
也
known
作为
charging
station
network。
OCPP
是
由
The
Open
Charge
Alliance
defined
的
`standard
<https://openchargealliance.org/protocols/open-charge-point-protocol/>`_
goal
是
offer
一
个
uniform
的
solution
用于
charge
point
和
central
system
之间
的
communication
method。
用
这
个
protocol
可以
connect
任何
central
system
与
任何
charge
point
不管
vendor
如何。

Zephyr
提供
一
个
OCPP
Charge
Point
（CP）
library
它
build
在
websocket
API
上面
payload
用
json
format。
Library
可
用
:kconfig:option:`CONFIG_OCPP`
Kconfig
option
enable。
当前
OCPP
1.6
带
basic
core
profile
被
supported。

OCPP
charge
point
（CP）
需要
一
个
Central
System
（CS）
server
connect
一
个
open
source
的
SteVe
server
应该
被
setup
locally
用于
development
purpose
参考
`SteVe
server
<https://github.com/steve-community/steve/blob/master/README.md>`_
获取
关于
setup
的
更多
information。

Zephyr
OCPP
CP
library
implement
以下
items：

*
engine
用于
process
socket
connectivity
和
events
*
OCPP
core
functions
用于
frame/parse
payload、
OCPP
events
的
user
notification、
heartbeat
notification

usage
