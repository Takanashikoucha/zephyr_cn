Service

    :local:

Overview
********

提供
network
based
的
latency
monitoring
所需
的
functionality
包括
socket
management、
client
server
communication、
和
与
运行
在
System
Under
Test
（SUT）
上
的
Latmus
service
的
data
exchange。

Latmon
network
service
负责
establish
并
manage
Latmon
application
（运行
在
Zephyr
based
的
board
上）
和
Latmus
service
（运行
在
SUT
上）
之间
的
network
communication。

它
use
TCP
sockets
用于
reliable
的
communication
并
use
UDP
sockets
用于
broadcast
Latmon
device
的
IP
address。

Reference

.. doxygengroup::

Features
********

-
**Socket
Management**：
Create
并
manage
用于
communication
的
TCP
和
UDP
sockets。
-
**Client
Server
Communication**：
Handle
来自
Latmus
service
的
incoming
connections。
-
**Data
Exchange**：
Send
latency
metrics
和
histogram
data
到
Latmus
service。
-
**IP
Address
Broadcasting**：
Broadcast
Latmon
device
的
IP
address
以
facilitate
Latmus
service
的
discovery。
-
**Thread
Safe
Design**：
Use
Zephyr
的
kernel
primitives
（例如
message
queues
和
semaphores）
用于
synchronization。
