Thread
protocol
###############

.. contents::
    :local:
    :depth:
    2

Overview
********
Thread
是
一
个
low
power
的
mesh
networking
technology
它
specifically
designed
用于
home
automation
applications。
它
是
一
个
IPv6
based
的
standard
它
use
6LoWPAN
technology
over
IEEE
802.15.4
protocol。
IP
connectivity
让你
轻松
connect
Thread
mesh
network
到
internet
通过
一
个
Thread
Border
Router。

Thread
specification
提供
高
level
的
network
security。
用
Thread
built
的
mesh
networks
是
secure
的
-
只
有
authenticated
的
devices
可以
join
network
并
mesh
内
所有
的
communications
被
encrypted。
关于
Thread
protocol
的
更多
information
可
在
`Thread
Group
website
<https://www.threadgroup.org>`_
找到。

Zephyr
integrate
一
个
open
source
的
Thread
protocol
implementation
called
OpenThread
它
在
`OpenThread
website
<https://openthread.io/>`_
上
documented。

Internet
connectivity
*********************

需要
一
个
Thread
Border
Router
connect
mesh
network
到
internet。
一
个
open
source
的
Thread
Border
Router
implementation
由
OpenThread
community
provided。
参考
`OpenThread
Border
Router
guide
<https://openthread.io/guides/border-router>`_
获取
关于
如何
set
up
一
个
Border
Router
的
instructions。

Sample
usage
************

你
可以
尝试
用
Zephyr
Echo
server
和
Echo
client
samples
使用
OpenThread
它们
提供
OpenThread
的
out
of
the
box
的
configuration。
要
在
这些
samples
中
enable
OpenThread
support
用
``overlay-ot.conf``
overlay
config
file
build
它们。
