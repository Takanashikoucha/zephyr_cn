HTTP
Server
###########

.. contents::
    :local:
    :depth:
    2

Overview
********

Zephyr
提供
一
个
HTTP
server
library
它
允许
register
HTTP
services
和
与
那些
services
相关
的
HTTP
resources。
Server
为
每个
registered
的
service
create
一
个
listening
socket
并
handle
incoming
的
client
connections。
可以
通过
plain
TCP
socket
（HTTP）
或
TLS
socket
（HTTPS）
communicate。
HTTP/1.1
（:rfc:`2616`）、
HTTP/2
（:rfc:`9113`）
和
HTTP/3
（:rfc:`9114`）
protocol
versions
被
supported。

Server
operation
通常
对
application
是
transparent
的
在
一
个
background
thread
中
running。
Application
可以
用
对应
的
API
functions
control
server
activity。

某些
resource
types
（例如
dynamic
resource）
提供
resource
specific
的
application
callbacks
允许
server
与
application
交互
（例如
provide
resource
content
或
process
request
payload）。

当前
以下
resource
types
被
supported：

*
Static
resources
-
content
在
compile
time
defined
不能
在
runtime
被
modified
（:c:enumerator:`HTTP_RESOURCE_TYPE_STATIC`）。

*
Static
file
system
resources
-
filesystem
被
mounted
的
path
和
filesystem
被
made
available
的
URL
在
build
time
fixed
但
filesystem
内
的
content
可以
dynamically
被
changed。
这
意味着
files
可以
被
HTTP
server
外面
的
其他
code
created、
modified
或
deleted
（:c:enumerator:`HTTP_RESOURCE_TYPE_STATIC_FS`）。

*
Dynamic
resources
-
content
在
runtime
由
对应
的
application
callback
provided
（:c:enumerator:`HTTP_RESOURCE_TYPE_DYNAMIC`）。
