Overview

Socket

每个

UDP

相反
一
个
thread

created
它

data

多
个
listening

这

memory
因为
在
这
个
情况
下
只
需要
在
system
中

一
个
thread。

参考
:zephyr:code-sample:`sockets-service-echo`
sample
application

如何
用
sockets
service
API

一
个
简单
的
BSD
socket
based
的
server
application。
这
个
sample
application

source

可
在
以下
位置
找到：
:zephyr_file:`samples/net/sockets/echo_service`。

:c:macro:`NET_SOCKET_SERVICE_SYNC_DEFINE`

   C

   Define
   一
   个
   带
   static
   scope
   的
   network
   socket
   service。
   这
   个
   socket
   service
   只
   可以
   在
   一
   个
   C
   source
   file
   内
   被
   used。

*
:c:func:`net_socket_service_register`
