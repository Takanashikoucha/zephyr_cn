Wi
Fi
credentials
Library
#########################

.. contents::
   :local:
   :depth:
   2

Wi
Fi
credentials
library
提供
means
load
和
store
Wi
Fi
network
credentials。

Overview
********

这
个
library
use
Zephyr
的
settings
subsystem
或
Platform
Security
Architecture
（PSA）
Internal
Trusted
Storage
（ITS）
store
credentials。
它
也
hold
一
个
SSIDs
的
list
在
RAM
中
用于
提供
dictionary
like
的
access
use
SSIDs
作为
keys。

Configuration
*************

要
use
Wi
Fi
credentials
library
enable
:kconfig:option:`CONFIG_WIFI_CREDENTIALS`
Kconfig
option。

你
可以
用
以下
options
pick
backend：

*
:kconfig:option:`CONFIG_WIFI_CREDENTIALS_BACKEND_PSA`
-
non
secure
targets
的
Default
option
它
包括
一
个
TF
M
partition
（non
minimal
的
TF
M
profile
type）。
*
:kconfig:option:`CONFIG_WIFI_CREDENTIALS_BACKEND_SETTINGS`
-
secure
targets
的
Default
option。

要
configure
networks
的
maximum
数量
use
:kconfig:option:`CONFIG_WIFI_CREDENTIALS_MAX_ENTRIES`
Kconfig
option。

IEEE
802.11
standard
不
specify
SAE
passwords
的
maximum
length。
要
change
default
use
:kconfig:option:`CONFIG_WIFI_CREDENTIALS_SAE_PASSWORD_LENGTH`
Kconfig
option。

Adding
credentials
******************

你
可以
用
:c:func:`wifi_credentials_set_personal`
和
:c:func:`wifi_credentials_set_personal_struct`
functions

credentials。
前者
将
从
given
的
fields
build
内部
used
的
struct
后者
直接
take
struct。
如果
你
两
次
add
带
相同
SSID
的
credentials
较
old
的
entry
将
被
overwritten。
