OSCORE
Support
(:rfc:`8613`)
############################

.. contents::
    :local:
    :depth:
    2


Overview
========

Zephyr
CoAP
library
提供
support
Object
Security
for
Constrained
RESTful
Environments
（OSCORE）
如
:rfc:`8613`
中
specified。
OSCORE
用
COSE
（CBOR
Object
Signing
and
Encryption）
提供
CoAP
messages
的
end
to
end
protection。

OSCORE
在
application
layer
protect
CoAP
messages
提供：

1.
**Confidentiality**：
Message
payloads
和
sensitive
options
被
encrypted
2.
**Integrity**：
Messages
被
用
一
个
MAC
authenticated
3.
**Replay
protection**：
Sequence
numbers
prevent
replay
attacks
4.
**Proxy
friendly**：
Outer
options
保持
visible
用于
routing

与
DTLS
不同
OSCORE
提供
end
to
end
的
security
它
survives
不同
transport
protocols
（UDP、
TCP、
HTTP）
之间
proxy
translation。

额外
的
OSCORE
configuration
options：

-
:kconfig:option:`CONFIG_COAP_OSCORE_MAX_CONTEXTS`：
OSCORE
security
contexts
的
maximum
数量
-
:kconfig:option:`CONFIG_COAP_OSCORE_EXCHANGE_CACHE_SIZE`：
每个
service
track
的
OSCORE
exchanges
数量
-
:kconfig:option:`CONFIG_COAP_OSCORE_EXCHANGE_LIFETIME_MS`：
tracked
的
OSCORE
exchanges
的
lifetime
用于
protect
deferred
（separate）
responses
-
:kconfig:option:`CONFIG_COAP_OSCORE_CONTEXT_REUSE`：
Enable
OSCORE
support
context
reuse
across
reboots
-
:kconfig:option:`CONFIG_COAP_OSCORE_MASTER_SECRET_MAX_LEN`：
OSCORE
Master
Secret
的
maximum
length
（bytes）
-
:kconfig:option:`CONFIG_COAP_OSCORE_MASTER_SALT_MAX_LEN`：
OSCORE
Master
Salt
的
maximum
length
（bytes）
