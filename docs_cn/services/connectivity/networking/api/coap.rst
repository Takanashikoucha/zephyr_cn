Overview
********

Constrained
Application
Protocol
（CoAP）
是
一
个
specialized
的
web
transfer
protocol
用于
constrained
的
nodes
和
constrained
的
（e.g.
low
power、
lossy）
networks。
它
提供
便利
的
API
用于
support
CoAP
features
的
RESTful
Web
services。
关于
protocol
本身
的
更多
information
参考
:rfc:`7252`。

Zephyr
提供
一
个
CoAP
library
它
support
client
和
server
roles。
该
library
可
用
:kconfig:option:`CONFIG_COAP`
Kconfig
option
enable
并
可
根据
user
needs
configured。
Zephyr
CoAP
library
用
plain
buffers
implemented。
API
的
users
create
sockets
用于
communication
并
将
buffer
pass
到
library
用于
parsing
和
其他
purposes。
Library
本身
不
为
users
create
任何
sockets。

在
CoAP
上面
Zephyr
有
support
LwM2M
"Lightweight
Machine
2
Machine"
protocol
一
个
简单、
low
cost
的
remote
management
和
service
enablement
mechanism。
参考
:ref:`lwm2m_interface`
获取
更多
information。
