.. contents::

Overview
********

Link layer addresses 为 network interfaces 设置（使 L2 connectivity 在 network stack 中正确工作。通常 link layer addresses 为 6 bytes 长（如 Ethernet（但 IEEE 802.15.4 的 link layer address 长度为 8 bytes。
