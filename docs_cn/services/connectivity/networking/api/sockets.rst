Overview

Zephyr

这

以下

BSD

*
有
minimal

overhead
与
其他
Zephyr

*

``close()``

它们

libc

:kconfig:option:`CONFIG_POSIX_API`

BSD

:kconfig:option:`CONFIG_NET_SOCKETS`

``socket()``、
``close()``、
``recv()``、
``recvfrom()``、
``send()``、
``sendto()``、
``connect()``、
``bind()``、
``listen()``、
``accept()``、
``fcntl()``

``getsockopt()``、
``setsockopt()``、
``poll()``、
``select()``、
``getaddrinfo()``、

根据

``zsock_``

:c:func:`zsock_socket`

:c:func:`zsock_close`。
如果

:kconfig:option:`CONFIG_POSIX_API`
