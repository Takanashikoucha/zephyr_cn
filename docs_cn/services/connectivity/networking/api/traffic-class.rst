Traffic
Classification
#######################

Overview
********

`Traffic
classification
<https://en.wikipedia.org/wiki/Traffic_classification>`_
是
一
个
automated
的
process
它
根据
各种
parameters
categorize
computer
network
traffic。
对于
Zephyr
VLAN
priority
code
point
（PCP）
被
used
用于
classify
两
个
received
和
sent
的
network
packets。
参考
`IEEE
802.1Q
<https://en.wikipedia.org/wiki/IEEE_802.1Q>`_
获取
关于
VLAN
priority
的
更多
information。

Default
下
所有
的
network
traffic
在
Zephyr
中
被
treated
equal。
如果
desired
option
:kconfig:option:`CONFIG_NET_TC_TX_COUNT`
可
被
used
用于
set
transmit
queues
的
数量。
Option
:kconfig:option:`CONFIG_NET_TC_RX_COUNT`
可
被
used
用于
set
receive
queues
的
数量。
每个
traffic
class
queue
corresponds
到
特定
的
kernel
work
queue。
每个
kernel
work
queue
有
一
个
priority。
VLAN
priority
根据
在
`IEEE
802.1Q
spec`_
chapter
I.3、
chapter
8.6.6
table
8-4、
和
chapter
34.5
table
34-1
中
specified
的
rules
被
mapped
到
特定
的
traffic
class。
每个
traffic
class
然后
被
mapped
到
特定
的
kernel
work
queue。
两
个
Rx
和
Tx
的
traffic
classes
的
maximum
数量
是
8。

参考
:zephyr_file:`subsys/net/ip/net_tc.c`
获取
关于
各种
mappings
如何
done
的
details。

.. _IEEE
802.1Q
spec:
   https://ieeexplore.ieee.org/document/6991462/
