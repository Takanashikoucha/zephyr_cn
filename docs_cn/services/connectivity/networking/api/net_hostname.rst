Hostname
Configuration
######################

.. contents::
    :local:
    :depth:
    2

Overview
********

一
个
networked
的
device
可能
需要
一
个
hostname
例如
如果
device
被
configured
作为
一
个
mDNS
responder
（参考
:ref:`dns_resolve_interface`
获取
details）
并
需要
respond
``<hostname>.local``
DNS
queries。

必须
set
:kconfig:option:`CONFIG_NET_HOSTNAME_ENABLE`
才能
store
hostname
并
enable
相关
的
APIs。
如果
该
option
被
enabled
那么
default
的
hostname
被
set
为
``zephyr``
由
:kconfig:option:`CONFIG_NET_HOSTNAME`
option。

如果
相同
的
firmware
image
被
used
来
flash
多
个
boards
那么
在
所有
的
boards
中
use
相同
的
hostname
不
practical。
在
那
个
情况
下
一
个
可以
enable
:kconfig:option:`CONFIG_NET_HOSTNAME_UNIQUE`
它
将
添加
一
个
unique
的
postfix
到
hostname。
Default
下
first
network
interface
的
link
local
address
被
used
作为
postfix。
在
Ethernet
networks
中
link
local
address
refer
到
MAC
address。
例如
如果
link
local
address
是
``01:02:03:04:05:06``
那么
unique
的
hostname
可能
是
``zephyr010203040506``。
如果
你
想
自己
set
prefix
那么
在
network
interfaces
被
created
之前
call
``net_hostname_set_postfix_str()``。
或者
如果
你
偏好
一
个
hexadecimal
的
conversion
用于
prefix
那么
call
``net_hostname_set_postfix()``。
例如
对于
Ethernet
networks
initialization
priority
由
:kconfig:option:`CONFIG_ETH_INIT_PRIORITY`
set
所以
你
需要
在
那
之前
set
postfix。
Postfix
只
能
被
set
一
次。
