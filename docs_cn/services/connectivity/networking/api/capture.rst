Network
Packet
Capture
######################

.. contents::
    :local:
    :depth:
    2

Overview
********

``net_capture``
API
允许
user
monitor
Zephyr
network
interfaces
中
一
个
的
network
traffic
并
将
那
个
traffic
send
到
external
system
用于
analysis。
Monitoring
可以
被
setup
要么
手动
用
``net
shell``
要么
自动
用
``net_capture``
API。

Cooked
Mode
Capture
*******************

如果
capturing
被
enabled
并
configured
系统
将
自动
capture
给定
network
interface
的
network
traffic。
如果
你
想
在
没有
network
interface
involved
时
capture
network
data
那么
你
需要
use
cooked
mode
capture
API。

在
cooked
mode
capture
中
任意
的
network
packets
可以
被
captured
并
不
需要
有
network
interface
involved。
例如
PPP
中
的
low
level
HDLC
packets
可以
被
captured
因为
当
use
normal
的
network
interface
based
capture
时
HDLC
L2
layer
的
data
被
stripped
away。
也
CANBUS
或
Bluetooth
network
data
可以
被
captured
尽管
当前
network
stack
中
没有
support
capture
那些。

Cooked
mode
capture
这样
work：

*
一
个
``any``
network
interface
被
created。
它
act
作为
一
个
sink
cooked
mode
captured
的
packets
被
cooked
mode
capture
API
write
到
它。
*
一
个
``cooked``
virtual
network
interface
被
attached
在
这
个
``any``
interface
上面。
*
``cooked``
interface
必须
被
configured
用
network
interface
configuration
API
capture
特定
的
L2
packet
types。
