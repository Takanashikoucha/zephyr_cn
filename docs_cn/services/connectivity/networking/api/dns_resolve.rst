Resolve

Overview
********

DNS
resolver
implement
一
个
basic
的
DNS
resolver
根据
:rfc:`1035`。
Supported
的
DNS
answers
是
IPv4/IPv6
addresses
和
CNAME。

如果
一
个
CNAME
被
received
DNS
resolver
将
create
另
一
个
DNS
query。
额外
queries
的
数量
由
:kconfig:option:`CONFIG_DNS_RESOLVER_ADDITIONAL_QUERIES`
Kconfig
variable
controlled。

Multicast
DNS
（mDNS）
client
resolver
support
可
通过
set
:kconfig:option:`CONFIG_MDNS_RESOLVER`
Kconfig
option
enable。
参考
:rfc:`6762`
获取
关于
mDNS
的
更多
details。

Link
local
multicast
name
resolution
（LLMNR）
client
resolver
support
可
通过
set
:kconfig:option:`CONFIG_LLMNR_RESOLVER`
Kconfig
variable
enable。
参考
:rfc:`4795`
获取
关于
LLMNR
的
更多
details。

关于
DNS
configuration
variables
的
更多
information
参考：
:zephyr_file:`subsys/net/lib/dns/Kconfig`。
DNS
resolver
API
可
在
:zephyr_file:`include/zephyr/net/dns_resolve.h`
找到。

在
:rfc:`6763`
中
described
的
DNS
based
service
discovery
queries
可
由
:c:func:`dns_resolve_service`
API
done。
Returned
的
service
descriptions
被
passed
到
user
supplied
的
callback
并
API
将
address
family
set
到
:c:macro:`AF_LOCAL`
以
indicate
该
value
不
是
一
个
IPv4
或
IPv6
address
而是
一
个
service
description。
