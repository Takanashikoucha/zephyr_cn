.. _net_if_interface:

Network
Interface
#################

.. contents::
    :local:
    :depth:
    2

Overview
********

Network
interface
是
一
个
nexus
它
ties
network
device
drivers
和
network
stack
的
upper
part
together。
所有
的
sent
和
received
的
data
通过
一
个
network
interface
transferred。
Network
interfaces
不
能
在
runtime
被
created。
一
个
special
的
linker
section
将
contain
关于
它们
的
information
那
个
section
在
linking
time
被
populated。

Network
interfaces
由
``NET_DEVICE_INIT()``
macro
created。
对于
Ethernet
network
应该
use
一
个
called
``ETH_NET_DEVICE_INIT()``
的
macro
因为
它
将
自动
create
VLAN
interfaces
如果
:kconfig:option:`CONFIG_NET_VLAN`
被
enabled。
这些
macros
通常
被
used
在
network
device
driver
的
source
code
中。

Network
interface
可以
通过
call
``net_if_up()``
被
turn
ON
通过
call
``net_if_down()``
被
turn
OFF。
当
device
被
powered
ON
时
network
interface
也
default
下
被
turn
ON。

Network
interfaces
可以
被
referenced
要么
用
``struct
net_if
*``
pointer
要么
用
network
interface
index。
Network
interface
可以
从
它
的
index
被
resolved
通过
call
``net_if_get_by_index()``
从
interface
pointer
被
resolved
通过
call
``net_if_get_by_iface()``。

.. _net_if_interface_ip_management:

Network
devices
的
IP
address
必须
被
set
它们
才能
被
connectable。
在
typical
的
dynamic
network
environment
中
IP
addresses
被
automatically
set
由
例如
DHCPv4。
不过
如果
需要
application
可以
手动
set
device
的
IP
address。
参考
下面
的
API
documentation
获取
``net_if_ipv4_addr_add()``
等
functions。
