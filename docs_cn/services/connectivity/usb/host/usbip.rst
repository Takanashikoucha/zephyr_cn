.. _usbip:

USB/IP
protocol
support
#######################

Overview
********

新
的
USB
support
包括
对
USB/IP
protocol
的
initial
support。
它
仍
在
under
development
并
当前
limited
于
只
support
一
个
device
connect
到
被
exported
的
host
controller。

USB/IP
use
TCP/IP。
两
个
underlying
的
connectivity
stacks
USB
和
networking
都
require
significant
的
memory
resources
在
选择
platform
时
必须
consider
这
些。

在
USB/IP
protocol
中
一
个
server
export
USB
devices
一
个
client
import
它们。
Zephyr
RTOS
中
的
USB/IP
support
implement
server
functionality
并
export
connect
到
host
controller
的
device
在
run
Zephyr
RTOS
的
device
上。
一
个
client
通常
run
Linux
kernel
import
这
个
device。
USB/IP
protocol
在
`USB/IP
protocol
documentation`_
中
described。

要
use
USB/IP
support
确保
client
side
required
的
modules
被
loaded。

.. code-block::
   console

   modprobe
   vhci_hcd
   modprobe
   usbip-core
   modprobe
   usbip-host

在
client
side
你
也
需要
**usbip**
user
tool。
它
可以
用
你
的
Linux
distribution
的
package
management
system
install
或
从
Linux
kernel
sources
built。

有
几
个
basic
的
commands
用于
everyday
use。
要
list
exported
的
USB
devices
run
以下
command：

.. code-block::
   console

   $
   usbip
   list
   -r
   192.0.2.1
