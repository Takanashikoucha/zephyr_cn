USB

stack

（deprecated）

API

*************

有

data

'low'

read/write

'high'
level

transfer

Low

API
   要

data
到
host
class

在

的
endpoint
callback
将
被
called。
在

另
一
个

应该

write

当
data
被
received
时
registered
的
endpoint
callback
被
called。
usb_read()
应该
被
used
用于
retrieve
received
的
data。
对于
CDC
ACM
sample
driver
这
通过
endpoint
array
（cdc_acm_ep_data）
中
mentioned
的
OUT
bulk
endpoint
handler
（cdc_acm_bulk_out）
done。

High
level
API
   Usb_transfer
method
可
被
used
用于
transfer
data
到/从
host。
Transfer
API
将
automatically
split
data
transmission
到
一
个
或
多
个
USB
transaction
s
根据
endpoint
max
packet
size。
Class
driver
不
需要
implement
endpoint
callback
并
应该
set
这
个
callback
到
generic
的
usb_transfer_ep_callback。
