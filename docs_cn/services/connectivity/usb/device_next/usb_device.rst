USB
device
support
##################

Overview
********

USB
device
support
consist
of
USB
device
controller
（UDC）
drivers
、
:ref:`udc_api`、
和
USB
device
stack
、
:ref:`usbd_api`。
:ref:`udc_api`
provide
一
个
generic
和
vendor
independent
的
interface
到
USB
device
controllers
虽然
这些
layers
之间
有
clear
的
separation
:ref:`udc_api`
的
purpose
是
exclusively
serve
Zephyr
的
USB
device
stack。

Device
stack
support
多
个
device
controllers
意味着
如果
SoC
有
多
个
controllers
它们
可以
被
simultaneously
used。
Full
和
high
speed
的
device
controllers
被
supported。
它
也
provide
support
用于
在
runtime
将
多
个
function
或
class
instances
registered
到
一
个
configuration
或
之后
change
configuration。
它
built
in
support
几
个
USB
classes
并
provide
一
个
API
用于
implement
custom
的
USB
functions。
