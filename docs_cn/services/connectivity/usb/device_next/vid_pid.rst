USB
Vendor
and
Product
identifiers
**********************************

Zephyr
project
的
USB
Vendor
ID
是
``0x2FE3``。
当
vendor
将
Zephyr
USB
device
support
integrate
到
它
自己
的
product
中
时
不
应该
use
Zephyr
USB
Vendor
ID。

每个
USB
:zephyr:code-sample-category:`sample<usb>`
有
它
自己
unique
的
Product
ID。
USB
maintainer
如果
被
assigned
或
否则
Zephyr
Technical
Steering
Committee
可以
根据
well
motivated
和
documented
的
requests
allocate
其他
的
USB
Product
IDs。
