USB
device
CDC
ACM
##################

CDC
ACM
function
由
USB
device
stack
provided
它
只
implement
Abstract
Control
Model
Serial
Emulation。
它
的
sole
purpose
是
emulate
serial
lines
如
它
的
name
所
suggest
的。
大多数
modern
的
operating
systems
应该
out
of
the
box
provide
对
它
的
support。

CDC
ACM
function
在
host
和
device
两
side
都
被
represented
作为
一
个
serial
interface
同时
user
或
application
interface
是
:ref:`uart_api`
driver
API。
这
允许
已经
use
UART
API
的
applications
use
CDC
ACM
function
provided
的
serial
interface
而
不
change
负责
data
communication
的
code。
只
需要
additional
的
configuration
和
USB
device
stack
initialization。

CDC
ACM
UART
configuration
==========================

与
真实
的
UART
controller
一样
virtual
的
CDC
ACM
UART
在
device
tree
中
被
described。
CDC
ACM
UART
的
devicetree
compatible
property
是
:dtcompatible:`zephyr,cdc-acm-uart`。

当
USB
device
support
被
enabled
且
devicetree
sources
中
有
compatible
的
node
时
CDC
ACM
support
被
automatically
selected。
如果
necessary
CDC
ACM
support
可以
被
:kconfig:option:`CONFIG_USBD_CDC_ACM_CLASS`
explicitly
disabled。
可能
的
CDC
ACM
instances
数量
取决于
USB
device
controller
上
supported
的
endpoints
数量。
每个
CDC
ACM
instance
需要
三
个
endpoints：
两
个
bulk
endpoints
（一
个
IN
一
个
OUT）
和
一
个
interrupt
IN
带
MaxPacketSize
为
16。
CDC
ACM
node
可以
use
``label``
property
distinguish
host
side
不同
的
interfaces。
下面
是
devicetree
overlay
file
的
一
个
example。

.. code-block::
   devicetree

   &zephyr_udc0
   {
       cdc_acm_uart0:
   cdc_acm_uart0
   {
           compatible
   =
   "zephyr,cdc-acm-uart";
           label
   =
   "CDC_ACM_0";
