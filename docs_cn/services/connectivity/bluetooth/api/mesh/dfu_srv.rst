Firmware
Update
Server
######################

Firmware
Update
Server
model
实现
:ref:`bluetooth_mesh_dfu`
subsystem
的
Target
node
functionality。
它
扩展
:ref:`bluetooth_mesh_blob_srv`
用
它
从
Distributor
node
接收
firmware
image
binary。

与
extended
的
BLOB
Transfer
Server
model
一起
Firmware
Update
Server
model
实现
通过
mesh
network
接收
firmware
updates
所需
的
所有
functionality
但
不
提供
任何
用于
storing、
applying
或
verifying
images
的
functionality。

Firmware
images
***************

Firmware
Update
Server
hold
device
上
所有
updatable
的
firmware
images
的
list。
完整
的
list
必须
通过
:c:macro:`BT_MESH_DFU_SRV_INIT`
中
的
``_imgs``
parameter
传递
给
server
并
必须
在
Bluetooth
Mesh
subsystem
被
started
之前
被
populated。
Image
list
中
的
每个
firmware
image
必须
能
被
independently
updated
并
应该
有
它
自己
的
firmware
ID。

例如
带
upgradable
的
bootloader、
一
个
application
和
带
firmware
update
capabilities
的
peripheral
chip
的
device
可能
在
firmware
image
list
中
有
三
个
entries
每个
带
它们
自己
的
separate
firmware
ID。
