操作码聚合器服务器
#########################

操作码聚合器服务器模型是蓝牙 Mesh 规范定义的基础模型。它是可选模型，通过
:kconfig:option:`CONFIG_BT_MESH_OP_AGG_SRV` 选项启用。

操作码聚合器服务器模型引入于蓝牙 Mesh 协议规范
版本 1.1，用于支持处理一系列访问层消息的功能。

操作码聚合器服务器模型接受使用节点设备密钥或应用密钥加密的消息。

如果存在，操作码聚合器服务器模型只能实例化在主元素上。

目标服务器模型应绑定到用于加密发送到操作码聚合器服务器的访问层消息序列的相同应用密钥。

操作码聚合器服务器处理聚合消息并将其分发给各自的模型及其消息处理器。当前实现假设
响应从与接收消息相同的执行上下文发送，
不允许发送延迟响应，例如从工作队列发送。
