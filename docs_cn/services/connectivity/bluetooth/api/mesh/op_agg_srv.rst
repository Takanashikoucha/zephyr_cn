Opcodes
Aggregator
Server
#########################

Opcodes
Aggregator
Server
model
是
Bluetooth
mesh
specification
定义
的
foundation
model。
它
是
一
个
optional
model
通过
:kconfig:option:`CONFIG_BT_MESH_OP_AGG_SRV`
option
启用。

Opcodes
Aggregator
Server
model
在
Bluetooth
Mesh
Protocol
Specification
version
1.1
中
被
引入
用
来
支持
处理
一
个
sequence
的
access
layer
messages
的
functionality。

Opcodes
Aggregator
Server
model
接受
用
node
的
device
key
或
application
keys
encrypted
的
messages。

如果
存在
Opcodes
Aggregator
Server
model
必须
只
在
primary
element
上
被
instantiated。

Targeted
的
server
models
应该
被
bound
到
与
用来
encrypt
发送
到
Opcodes
Aggregator
Server
的
access
layer
messages
sequence
相同
的
application
key。

Opcodes
Aggregator
Server
处理
aggregated
messages
并
将
它们
dispatch
到
相应
的
models
和
它们
的
message
handlers。
当前
implementation
假设
responses
从
与
收到
的
message
相同
的
execution
context
发送
并
不
允许
发送
postponed
的
response
例如
从
work
queue。

reference
