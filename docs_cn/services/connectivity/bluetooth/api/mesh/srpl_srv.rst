Solicitation
PDU
RPL
Configuration
Server
#########################################

Solicitation
PDU
RPL
Configuration
Server
model
是
Bluetooth
mesh
specification
定义
的
foundation
model。
该
model
在
node
启用
:ref:`bluetooth_mesh_od_srv`
时
被
启用。

Solicitation
PDU
RPL
Configuration
Server
model
在
Bluetooth
Mesh
Protocol
Specification
version
1.1
中
被
引入
管理
存储
在
device
上
的
Solicitation
Replay
Protection
List
（SRPL）。
SRPL
用
来
reject
已经
被
node
processed
的
Solicitation
PDUs。
当
有效
的
Solicitation
PDU
message
被
node
successfully
processed
时
message
的
SSRC
field
和
SSEQ
field
被
存储
在
node
的
SRPL
中。

Solicitation
PDU
RPL
Configuration
Server
没有
自己
的
API
依赖
:ref:`bluetooth_mesh_srpl_cli`
来
control
它。
该
model
只
接受
用
Configuration
Client
配置的
application
key
encrypted
的
messages。

如果
存在
Solicitation
PDU
RPL
Configuration
Server
model
必须
只
在
primary
element
上
被
instantiated。

Configurations
**************

对
Solicitation
PDU
RPL
Configuration
Server
model
:kconfig:option:`CONFIG_BT_MESH_PROXY_SRPL_SIZE`
option
可以
被
configured
设置
SRPL
的
size。

reference
