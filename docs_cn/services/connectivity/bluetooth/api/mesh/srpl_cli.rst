Solicitation
PDU
RPL
Configuration
Client
#########################################

Solicitation
PDU
RPL
Configuration
Client
model
是
Bluetooth
mesh
specification
定义
的
foundation
model。
该
model
是
optional
的
通过
:kconfig:option:`CONFIG_BT_MESH_SOL_PDU_RPL_CLI`
option
启用。

Solicitation
PDU
RPL
Configuration
Client
model
在
Bluetooth
Mesh
Protocol
Specification
version
1.1
中
被
引入
支持
从
支持
:ref:`bluetooth_mesh_srpl_srv`
model
的
node
的
solicitation
replay
protection
list
（SRPL）
中
remove
addresses
的
functionality。

Solicitation
PDU
RPL
Configuration
Client
model
用
Configuration
Client
配置的
application
keys
与
Solicitation
PDU
RPL
Configuration
Server
model
通信。

如果
存在
Solicitation
PDU
RPL
Configuration
Client
model
必须
只
在
primary
element
上
被
instantiated。

Configurations
**************

Solicitation
PDU
RPL
Configuration
Client
model
行为
可以
用
transmission
timeout
option
:kconfig:option:`CONFIG_BT_MESH_SOL_PDU_RPL_CLI_TIMEOUT`
配置。
:kconfig:option:`CONFIG_BT_MESH_SOL_PDU_RPL_CLI_TIMEOUT`
控制
Solicitation
PDU
RPL
Configuration
Client
等待
response
message
到达
多
长
时间
（毫秒）。
这
个
value
可以
在
runtime
用
:c:func:`bt_mesh_sol_pdu_rpl_cli_timeout_set`
change。

reference
