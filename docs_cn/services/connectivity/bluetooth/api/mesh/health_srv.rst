Health
Server
#############

Health
Server
model
为
:ref:`bluetooth_mesh_models_health_cli`
models
提供
attention
callbacks
和
node
diagnostics。
它
主要
用
来
report
mesh
node
中
的
faults
并
将
mesh
nodes
映射
到
它们
的
physical
location。

如果
存在
Health
Server
model
必须
在
primary
element
上
被
instantiated。

Faults
******

Health
Server
model
可能
report
在
device
lifetime
中
发生
的
faults
列表。
通常
faults
是
可能
alter
node
行为
的
events
或
conditions
如
power
outages
或
faulty
的
peripherals。
Faults
被
分成
warnings
和
errors。
Warnings
表示
接近
node
设计
承受
极限
但
不
一定
对
device
有害
的
conditions。
Errors
表示
超出
node
设计
极限
并
可能
已
导致
invalid
行为
或
对
device
造成
permanent
damage
的
conditions。

Fault
values
``0x01``
到
``0x7f``
为
Bluetooth
Mesh
specification
保留
specification
定义
的
faults
完整
列表
在
:ref:`bluetooth_mesh_health_faults`
中
可用。
Fault
values
``0x80``
到
``0xff``
是
vendor
特定
的。
Faults
列表
总是
带
company
ID
被
reported
以
帮助
interpreting
vendor
特定
的
faults。

.. _bluetooth_mesh_models_health_srv_attention:

Attention
state
***************

Attention
state
用
来
使
device
通过
某些
physical
behavior
如
blinking、
playing
a
sound
或
vibrating
引起
注意。
Attention
state
可以
在
provisioning
期间
用
来
让
user
知道
他们
正在
provision
哪
个
device
也
可以
在
runtime
通过
Health
models
使用。

Attention
state
总是
被
assign
一
个
一
到
255
