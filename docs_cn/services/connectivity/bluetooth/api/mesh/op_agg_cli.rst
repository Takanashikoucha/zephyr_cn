操作码聚合器客户端
#########################

操作码聚合器客户端模型是蓝牙 Mesh 规范定义的基础模型。它是可选模型，通过 :kconfig:option:`CONFIG_BT_MESH_OP_AGG_CLI` 选项启用。

操作码聚合器客户端模型引入于蓝牙 Mesh 协议规范
版本 1.1，用于支持将一系列访问层消息分发给支持 :ref:`bluetooth_mesh_models_op_agg_srv` 模型的节点的功能。

操作码聚合器客户端模型使用目标节点的设备密钥或配置客户端配置的应用密钥与操作码聚合器服务器模型通信。

如果存在，操作码聚合器客户端模型只能实例化在主元素上。

操作码聚合器客户端模型在初始化时隐式绑定到设备密钥。它应绑定到与用于生成消息序列的客户端模型相同的应用密钥。

要能够聚合来自客户端模型的消息，该模型应支持异步 API，例如通过回调。
