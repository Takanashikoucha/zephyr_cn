Opcodes
Aggregator
Client
#########################

Opcodes
Aggregator
Client
model
是
Bluetooth
Mesh
specification
定义
的
foundation
model。
它
是
一
个
optional
model
通过
:kconfig:option:`CONFIG_BT_MESH_OP_AGG_CLI`
option
启用。

Opcodes
Aggregator
Client
model
在
Bluetooth
Mesh
Protocol
Specification
version
1.1
中
被
引入
用
来
支持
将
一
个
sequence
的
access
layer
messages
dispatch
到
支持
:ref:`bluetooth_mesh_models_op_agg_srv`
model
的
nodes
的
functionality。

Opcodes
Aggregator
Client
model
用
target
node
的
device
key
或
Configuration
Client
配置的
application
keys
与
Opcodes
Aggregator
Server
model
通信。

如果
存在
Opcodes
Aggregator
Client
model
必须
只
在
primary
element
上
被
instantiated。

Opcodes
Aggregator
Client
model
在
initialization
时
被
implicitly
bound
到
device
key。
它
应该
被
bound
到
与
用来
produce
messages
sequence
的
client
models
相同
的
application
keys。

要
能
aggregate
来自
client
model
的
message
它
应该
支持
asynchronous
API
例如
通过
callbacks。

reference
