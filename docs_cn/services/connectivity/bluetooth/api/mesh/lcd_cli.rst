Large
Composition
Data
Client
#############################

Large
Composition
Data
Client
model
是
Bluetooth
Mesh
specification
定义
的
foundation
model。
该
model
是
optional
的
通过
:kconfig:option:`CONFIG_BT_MESH_LARGE_COMP_DATA_CLI`
option
启用。

Large
Composition
Data
Client
model
在
Bluetooth
Mesh
Protocol
Specification
version
1.1
中
被
引入
支持
read
不
fit
在
Config
Composition
Data
Status
message
中
的
Composition
Data
pages
的
functionality
并
read
支持
:ref:`bluetooth_mesh_lcd_srv`
model
的
node
上
model
instances
的
metadata。

Large
Composition
Data
Client
model
用
包含
target
Large
Composition
Data
Server
model
instance
的
node
的
device
key
与
Large
Composition
Data
Server
model
通信。

如果
存在
Large
Composition
Data
Client
model
必须
只
在
primary
element
上
被
instantiated。

reference
