Configuration
Client
####################

Configuration
Client
model
是
Bluetooth
Mesh
specification
定义
的
foundation
model。
它
提供
配置
mesh
node
大多数
parameters
的
functionality
包括
encryption
keys、
model
configuration
和
feature
enabling。

Configuration
Client
model
用
target
node
的
device
key
与
:ref:`bluetooth_mesh_models_cfg_srv`
model
通信。
Configuration
Client
model
可以
与
其他
nodes
上
的
servers
通信
或
通过
local
的
Configuration
Server
model
self
configure。

Configuration
Client
API
中
所有
configuration
functions
都有
``net_idx``
和
``addr``
作为
它们
的
first
parameters。
这些
应该
设置
为
target
node
被
provisioned
时
的
network
index
和
primary
unicast
address。

Configuration
Client
model
是
optional
的
如果
存在
于
Composition
Data
中
它
必须
只
在
primary
element
上
被
instantiated。

reference
