Health
Client
#############

Health
Client
model
与
Health
Server
model
交互
read
out
diagnostics
并
control
node
的
attention
state。

Health
Client
API
中
所有
message
passing
functions
都有
``cli``
作为
它们
的
first
parameter。
这
是
一
个
指向
client
model
instance
的
pointer
将
用
在
这
个
function
call
中。
第二
个
parameter
是
``ctx``
或
message
context。
Message
context
包含
target
node
使用
的
netkey
index、
appkey
index
和
unicast
address。

Health
Client
model
是
optional
的
可以
在
任何
element
上
被
instantiated。
然而
如果
Health
Client
model
在
primary
之外
的
element
上
被
instantiated
primary
element
上
必须
也
有
一
个
instance。

参考
:ref:`bluetooth_mesh_health_faults`
获取
specification
定义
的
fault
values
列表。

reference
