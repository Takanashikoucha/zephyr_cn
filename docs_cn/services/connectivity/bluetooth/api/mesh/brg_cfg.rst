Bluetooth

Subnet

- :ref:`bluetooth_mesh_models_brg_cfg_srv`
- :ref:`bluetooth_mesh_models_brg_cfg_cli`

Bridge

Subnet
Bridge
feature

Bridge

这些

Subnet

实现
Bridge
Configuration
Client
model

Subnet
Bridge
feature
的
*Configuration
Manager*。
