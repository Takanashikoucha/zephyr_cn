Mesh
Statistic
##############

Statistic
API
提供
Bluetooth
Mesh
communication
的
runtime
monitoring。

Frame
statistic
***************

Frame
statistic
API
允许
monitor
通过
不同
interfaces
收到
的
frames
数量
以及
planned
和
succeeded
的
transmission
和
relaying
attempts
数量。

该
API
帮助
user
estimate
advertiser
configuration
parameters
的
efficiency
和
device
的
scanning
ability。
Monitor
的
parameters
数量
可以
轻松
用
customer
values
扩展。

LPN
timing
measurement
**********************

当
:kconfig:option:`CONFIG_BT_MESH_LOW_POWER`
启用
时
statistic
module
通过
timestamp
protocol
events
测量
LPN
friendship
timing
parameters：

*
T1：
Poll
TX
complete
*
T2：
Scanner
enabled
（ReceiveDelay
elapsed）
*
T3：
Friend
response
received
或
ReceiveWindow
expired

从
这些
timestamps
module
计算
measured
的
ReceiveDelay
（T2
-
T1）
和
ReceiveWindow
（T3
-
T2）
（微秒）。
Application
可以
用
这些
values
evaluate
实际
的
on
air
timing
与
configured
的
friendship
parameters。

Application
可以
在
任何
时间
read
out
和
reset
statistics。

reference
