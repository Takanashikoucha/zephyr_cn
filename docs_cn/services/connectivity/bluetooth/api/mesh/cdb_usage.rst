Configuration
Database
（CDB）
############################

.. contents::
   :local:
   :depth:
   2

Overview
********

Configuration
Database
（CDB）
是
Bluetooth®
Mesh
provisioner
devices
的
subsystem。
它
存储
和
管理
关于
mesh
network
的
information
包括
provisioned
nodes、
network
keys、
和
application
keys。
CDB
使
provisioner
能
跟踪
network
topology、
assign
addresses、
并
systematically
配置
nodes。

.. note::

   CDB
   implementation
   有
   proprietary
   design
   不
   遵循
   Bluetooth
   SIG
   specification。

CDB
通过
:kconfig:option:`CONFIG_BT_MESH_CDB`
configuration
option
启用
通常
只
在
network
中
的
provisioner
device
上
使用。
Mesh
network
中
应该
只
有
一
个
device
启用
CDB
以
避免
conflicts。

Key
features
================

*
**Persistent
Storage**：
当
:kconfig:option:`CONFIG_BT_SETTINGS`
启用
时
所有
CDB
data
被
persistently
存储
允许
provisioner
在
reboots
之间
recover
network
state。
*
**Address
Management**：
自动
allocation
和
tracking
provisioned
nodes
的
unicast
addresses。
*
**Key
Management**：
存储
和
synchronization
network
keys
和
application
keys。
*
**Node
Tracking**：
维护
每个
provisioned
node
的
information
包括
UUID、
address、
element
count、
device
key、
和
configuration
status。
*
**IV
Index
Management**：
跟踪
network
的
IV
Index
和
IV
Update
state。

Configuration
options
*********************

以下
Kconfig
options
控制
CDB
capacity：

*
:kconfig:option:`CONFIG_BT_MESH_CDB_NODE_COUNT`
-
CDB
可以
处理
的
nodes
最大
数量。
*
:kconfig:option:`CONFIG_BT_MESH_CDB_SUBNET_COUNT`
-
CDB
可以
处理
的
subnets
最大
数量。
*
:kconfig:option:`CONFIG_BT_MESH_CDB_APP_KEY_COUNT`
-
CDB
可以
处理
的
application
keys
最大
数量。
