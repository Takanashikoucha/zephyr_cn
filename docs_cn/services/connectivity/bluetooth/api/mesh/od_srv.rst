On
Demand
Private
Proxy
Server
##############################

On
Demand
Private
Proxy
Server
model
是
Bluetooth
Mesh
specification
定义
的
foundation
model。
它
通过
:kconfig:option:`CONFIG_BT_MESH_OD_PRIV_PROXY_SRV`
option
启用。

The
On
Demand
Private
Proxy
Server
model
was
introduced
in
the
Bluetooth
Mesh
Protocol
Specification
version
1.1、
and
supports
the
configuration
of
advertising
with
Private
Network
Identity
type
of
a
node
that
is
a
recipient
of
Solicitation
PDUs
by
managing
its
On
Demand
Private
GATT
Proxy
state.

When
enabled、
the
:ref:`bluetooth_mesh_srpl_srv`
is
also
enabled.
The
On
Demand
Private
Proxy
Server
is
dependent
on
the
:ref:`bluetooth_mesh_models_priv_beacon_srv`
to
be
present
on
the
node.

The
On
Demand
Private
Proxy
Server
does
not
have
an
API
of
its
own、
and
relies
on
a
:ref:`bluetooth_mesh_od_cli`
to
control
it.
The
On
Demand
Private
Proxy
Server
model
only
accepts
messages
encrypted
with
the
node's
device
key.

If
present、
the
On
Demand
Private
Proxy
Server
model
must
only
be
instantiated
on
the
primary
element.
