On
Demand
Private
Proxy
Server
##############################

On
Demand
Private
Proxy
Server
model
是
Bluetooth
Mesh
specification
定义
的
foundation
model。
它
通过
:kconfig:option:`CONFIG_BT_MESH_OD_PRIV_PROXY_SRV`
option
启用。

On
Demand
Private
Proxy
Server
model
在
Bluetooth
Mesh
Protocol
Specification
version
1.1
中
被
引入
通过
管理
它
的
On
Demand
Private
GATT
Proxy
state
支持
配置
Solicitation
PDUs
的
recipient
node
的
带
Private
Network
Identity
type
的
advertising。

当
启用
时
:ref:`bluetooth_mesh_srpl_srv`
也
被
启用。
On
Demand
Private
Proxy
Server
依赖
:ref:`bluetooth_mesh_models_priv_beacon_srv`
在
node
上
存在。

On
Demand
Private
Proxy
Server
没有
自己
的
API
依赖
:ref:`bluetooth_mesh_od_cli`
来
control
它。
On
Demand
Private
Proxy
Server
model
只
接受
用
node
的
device
key
encrypted
的
messages。

如果
存在
On
Demand
Private
Proxy
Server
model
必须
只
在
primary
element
上
被
instantiated。

reference
