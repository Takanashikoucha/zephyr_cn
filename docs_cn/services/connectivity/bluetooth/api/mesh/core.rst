Low
Power

**************

Low
Power
Node
（LPN）

leaf
node

mesh
network。
LPN
通过
一

Friend

mesh
network
交互
该
node
负责
relay
任何
指向
LPN
的
messages。
LPN
通过
保持
radio
关闭
节省
power
只
在
发送
messages
或
poll
Friend
node
任何
incoming
messages
时
唤醒。

Radio
control
和
polling
由
mesh
stack
自动
管理
但
LPN
API
允许
application
在
任何
时间
通过
:c:func:`bt_mesh_lpn_poll`
触发
polling。
LPN
operation
parameters
包括
poll
interval、
poll
event
timing
和
Friend
requirements
通过
:kconfig:option:`CONFIG_BT_MESH_LOW_POWER`
option
和
相关
configuration
options
控制。

当
使用
logging
的
LPN
feature
时
强烈
推荐
只
使用
:kconfig:option:`CONFIG_LOG_MODE_DEFERRED`
option。
Deferred
之外
的
log
modes
可能
在
log
messages
处理
期间
导致
非预期
的
delays。
这
反过来
将
影响
receive
delay
和
receive
window
的
scheduling。
相同
的
limitation
也
适用于
:kconfig:option:`CONFIG_BT_MESH_FRIEND`
option。
