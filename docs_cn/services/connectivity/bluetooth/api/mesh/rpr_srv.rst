Remote
Provisioning
Server
##########################

Remote
Provisioning
Server
model
是
Bluetooth
mesh
specification
定义
的
foundation
model。
它
通过
:kconfig:option:`CONFIG_BT_MESH_RPR_SRV`
option
启用。

Remote
Provisioning
Server
model
在
Bluetooth
Mesh
Protocol
Specification
version
1.1
中
被
引入
用
来
支持
远程
provision
devices
到
mesh
network
的
functionality。

Remote
Provisioning
Server
没有
自己
的
API
依赖
:ref:`bluetooth_mesh_models_rpr_cli`
来
control
它。
Remote
Provisioning
Server
model
只
接受
用
node
的
device
key
encrypted
的
messages。

如果
存在
Remote
Provisioning
Server
model
必须
在
primary
element
上
被
instantiated。

注意
在
通过
Node
Provisioning
Protocol
Interface
（NPPI）
procedure
refresh
device
key、
node
address
或
Composition
Data
后
:c:member:`bt_mesh_prov.reprovisioned`
callback
被
triggered。
参考
:ref:`bluetooth_mesh_models_rpr_cli`
section
获取
更多
details。

How
to
integrate
the
model
into
an
application
-----------------------------------------------

要
在
application
中
添加
Remote
Provisioning
Server
model
做
以下
操作：

1.
在
project
configuration
中
启用
Kconfig：

   .. code-block:: cfg

      CONFIG_BT_MESH_RPR_SRV=y

2.
用
:c:macro:`BT_MESH_MODEL_RPR_SRV`
macro
将
model
instance
添加
到
primary
element
的
model
list
:c:member:`bt_mesh_elem.models`
例如：

   .. code-block:: c

      static
      const
      struct
      bt_mesh_model
      models[]
      =
      {
