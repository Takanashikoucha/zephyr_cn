On
Demand
Private
Proxy
Client
##############################

On
Demand
Private
Proxy
Client
model
是
Bluetooth
Mesh
specification
定义
的
foundation
model。
该
model
是
optional
的
通过
:kconfig:option:`CONFIG_BT_MESH_OD_PRIV_PROXY_CLI`
option
启用。

On
Demand
Private
Proxy
Client
model
在
Bluetooth
Mesh
Protocol
Specification
version
1.1
中
被
引入
用
来
set
和
retrieve
On
Demand
Private
GATT
Proxy
state。
该
state
定义
node
在
收到
Solicitation
PDU
后
会
advertise
带
Private
Network
Identity
type
的
Mesh
Proxy
Service
多
长
时间。

On
Demand
Private
Proxy
Client
model
用
包含
target
On
Demand
Private
Proxy
Server
model
instance
的
node
的
device
key
与
On
Demand
Private
Proxy
Server
model
通信。

如果
存在
On
Demand
Private
Proxy
Client
model
必须
只
在
primary
element
上
被
instantiated。

Configurations
**************

On
Demand
Private
Proxy
Client
model
行为
可以
用
transmission
timeout
option
:kconfig:option:`CONFIG_BT_MESH_OD_PRIV_PROXY_CLI_TIMEOUT`
配置。
:kconfig:option:`CONFIG_BT_MESH_OD_PRIV_PROXY_CLI_TIMEOUT`
控制
Client
等待
state
response
message
到达
多
长
时间
（毫秒）。
这
个
value
可以
在
runtime
用
:c:func:`bt_mesh_od_priv_proxy_cli_timeout_set`
change。

reference
