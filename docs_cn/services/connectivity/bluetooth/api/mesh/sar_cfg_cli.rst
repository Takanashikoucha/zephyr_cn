SAR
Configuration
Client
########################

SAR
Configuration
Client
model
是
Bluetooth
Mesh
specification
定义
的
foundation
model。
它
是
一
个
optional
model
通过
:kconfig:option:`CONFIG_BT_MESH_SAR_CFG_CLI`
configuration
option
启用。

SAR
Configuration
Client
model
在
Bluetooth
Mesh
Protocol
Specification
version
1.1
中
被
引入
支持
配置
支持
:ref:`bluetooth_mesh_sar_cfg_srv`
model
的
node
的
lower
transport
layer
行为。

该
model
可以
发送
messages
用
SAR
Configuration
messages
query
或
change
SAR
Configuration
Server
（SAR
Transmitter
和
SAR
Receiver）
支持
的
states。

SAR
Transmitter
procedure
用
来
determine
和
configure
SAR
Configuration
Server
的
SAR
Transmitter
state。
Function
calls
:c:func:`bt_mesh_sar_cfg_cli_transmitter_get`
和
:c:func:`bt_mesh_sar_cfg_cli_transmitter_set`
分别
用
来
get
和
set
Target
node
的
SAR
Transmitter
state。

SAR
Receiver
procedure
用
来
determine
和
configure
SAR
Configuration
Server
的
SAR
Receiver
state。
Function
calls
:c:func:`bt_mesh_sar_cfg_cli_receiver_get`
和
:c:func:`bt_mesh_sar_cfg_cli_receiver_set`
分别
用
来
get
和
set
Target
node
的
SAR
Receiver
state。

关于
两
个
states
的
更多
信息
参考
:ref:`bt_mesh_sar_cfg_states`。

一
个
element
可以
在
任何
时间
发送
任何
SAR
Configuration
Client
message
query
或
change
peer
node
的
SAR
Configuration
Server
model
支持
的
states。
SAR
Configuration
Client
model
只
接受
用
支持
SAR
Configuration
Server
model
的
node
的
device
key
encrypted
的
messages。

如果
存在
SAR
Configuration
Client
model
必须
只
在
primary
element
上
被
instantiated。

reference
