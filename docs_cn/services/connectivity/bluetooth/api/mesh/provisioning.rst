Provisioning
############

Provisioning
是
将
devices
添加
到
mesh
network
的
process。
它
需要
两
个
在
以下
roles
中
工作
的
devices：

*
*provisioner*
代表
network
owner
负责
将
新
的
nodes
添加
到
mesh
network。
*
*provisionee*
是
通过
Provisioning
process
被
添加
到
network
的
device。
在
provisioning
process
开始
之前
provisionee
是
*unprovisioned
device*。

Zephyr
Bluetooth
Mesh
stack
中
的
Provisioning
module
支持
provisionee
role
的
Advertising
和
GATT
Provisioning
bearers
以及
provisioner
role
的
Advertising
Provisioning
bearer。

The
Provisioning
process
************************

所有
Bluetooth
Mesh
nodes
必须
在
参与
Bluetooth
Mesh
network
之前
被
provisioned。
Provisioning
API
提供
device
成为
provisioned
mesh
node
所需
的
所有
functionality。
Provisioning
是
一
个
五
步
process
涉及
以下
steps：

*
Beaconing
*
Invitation
*
Public
key
exchange
*
Authentication
*
Provisioning
data
transfer

Beaconing
=========

要
开始
provisioning
process
unprovisioned
device
必须
首先
开始
broadcast
Unprovisioned
Beacon。
这
使
它
对
附近
的
provisioners
可见
它们
可以
initiate
provisioning。
要
indicate
device
需要
被
provisioned
调用
:c:func:`bt_mesh_prov_enable`。
Device
开始
broadcast
带
device
UUID
和
的
Unprovisioned
Beacon
