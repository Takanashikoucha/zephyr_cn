Private
Beacon
Client
#####################

Private
Beacon
Client
model
是
Bluetooth
mesh
specification
定义
的
foundation
model。
它
通过
:kconfig:option:`CONFIG_BT_MESH_PRIV_BEACON_CLI`
option
启用。

Private
Beacon
Client
model
在
Bluetooth
Mesh
Protocol
Specification
version
1.1
中
被
引入
提供
配置
:ref:`bluetooth_mesh_models_priv_beacon_srv`
models
的
functionality。

Private
Beacons
feature
通过
periodically
randomize
beacon
input
data
为
不同
的
Bluetooth
Mesh
beacons
添加
privacy。
这
保护
mesh
node
不
被
mesh
network
外
的
devices
tracked
并
隐藏
network
的
IV
index、
IV
update
和
Key
Refresh
state。

Private
Beacon
Client
model
用
target
node
的
device
key
与
:ref:`bluetooth_mesh_models_priv_beacon_srv`
model
通信。
Private
Beacon
Client
model
可以
与
其他
nodes
上
的
servers
通信
或
通过
local
的
Private
Beacon
Server
model
self
configure。

Private
Beacon
Client
API
中
所有
configuration
functions
都有
``net_idx``
和
``addr``
作为
它们
的
first
parameters。
这些
应该
设置
为
target
node
被
provisioned
时
的
network
index
和
primary
unicast
address。

如果
存在
Private
Beacon
Client
model
必须
只
在
primary
element
上
被
instantiated。

reference
