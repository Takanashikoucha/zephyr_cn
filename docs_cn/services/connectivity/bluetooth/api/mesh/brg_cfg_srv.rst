Bridge
Configuration
Server
###########################

Bridge
Configuration
Server
model
是
Bluetooth
Mesh
specification
定义
的
foundation
model。
它
是
一
个
optional
model
通过
:kconfig:option:`CONFIG_BT_MESH_BRG_CFG_SRV`
configuration
option
启用。
这
个
model
扩展
:ref:`bluetooth_mesh_models_cfg_srv`
model。

Bridge
Configuration
Server
model
在
Bluetooth
Mesh
Protocol
Specification
version
1.1
中
被
引入
用于
支持
和
配置
Subnet
Bridge
feature。

Bridge
Configuration
Server
model
依赖
:ref:`bluetooth_mesh_models_brg_cfg_cli`
来
配置
它。
Bridge
Configuration
Server
model
只
接受
用
node
的
device
key
encrypted
的
messages。

如果
存在
Bridge
Configuration
Server
model
必须
在
primary
element
上
被
instantiated。

Bridge
Configuration
Server
model
提供
对
以下
三
个
states
的
access：

*
Subnet
Bridge
*
Bridging
Table
*
Bridging
Table
Size

关于
states
的
更多
信息
参考
:ref:`bluetooth_mesh_brg_cfg_states`。

reference
