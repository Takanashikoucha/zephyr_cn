BLOB

BLOB

:ref:`flash
map
<flash_map_api>`

的
flash

BLOB

BLOB
Flash

*****************

BLOB
Flash
Reader
与
BLOB
Transfer

直接
从
flash
read
BLOB
data。
它
必须
在
被
传递
给
BLOB
Transfer
Client
之前
通过
调用
:c:func:`bt_mesh_blob_flash_rd_init`
初始化。
每个
BLOB
Flash
Reader
只
支持
一
次
一
个
transfer。


BLOB
Flash
Writer
*****************

BLOB
Flash
Writer
与
BLOB
Transfer
Server
交互
直接
向
flash
write
BLOB
data。
它
必须
在
被
传递
给
BLOB
Transfer
Server
之前
通过
调用
:c:func:`bt_mesh_blob_flash_rd_init`
初始化。
每个
BLOB
Flash
Writer
只
支持
一
次
一
个
transfer
并
需要
flash
page
size
的
倍数
的
block
size。
如果
transfer
用
低于
flash
page
size
的
block
size
开始
transfer
将
被
rejected。

BLOB
Flash
Writer
将
chunk
data
复制
到
buffer
中
以
适应
与
flash
write
block
size
不
对齐
的
chunks。
如果
chunk
的
start
或
length
不
对齐
buffer
data
用
``0xff``
padding。
