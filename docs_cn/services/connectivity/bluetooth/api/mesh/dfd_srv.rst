固件分发服务器
############################

固件分发服务器模型实现 :ref:`bluetooth_mesh_dfu` 子系统中的 Distributor 角色。它扩展 :ref:`bluetooth_mesh_blob_srv`，用于从 Initiator 节点接收固件镜像二进制文件。它还实例化一个 :ref:`bluetooth_mesh_dfu_cli`，用于在整个 Mesh 网络中分发固件更新。

.. note::

   目前，固件分发服务器仅支持通过 SMP 服务以带外（OOB）方式获取固件镜像。

固件分发服务器没有自己的 API，而是依赖另一台设备上的固件分发客户端模型来获取信息并触发镜像分发和上传。

固件槽
**************

固件分发服务器能够存储多个固件镜像用于分发。每个槽包含一个独立的固件镜像及其元数据，可以按任意顺序分发给网络中的其他 Mesh 节点。固件镜像的内容、格式和大小是厂商特定的，可能包含来自其他厂商的数据。应用永远不应尝试执行或修改它们。

这些槽由固件分发客户端远程管理，客户端既可以上传新槽，也可以删除旧槽。应用通过固件分发服务器的回调（:cpp:type:`bt_mesh_fd_srv_cb`）获知槽的变化。虽然每个固件槽的元数据存储在内部，但应用必须提供 :ref:`bluetooth_mesh_blob_stream` 用于读写固件镜像。
