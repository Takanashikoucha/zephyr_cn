Segmentation
and
reassembly
（SAR）
#################################

Segmentation
and
reassembly
（SAR）
提供
在
mesh
network
中
处理
更大
的
upper
transport
layer
messages
的
方式
目的
是
enhance
Bluetooth
Mesh
throughput。
Segmentation
and
reassembly
mechanism
由
lower
transport
layer
使用。

Lower
transport
layer
定义
upper
transport
layer
PDUs
如何
被
segmented
和
reassembled
到
多
个
Lower
Transport
PDUs
并
将
它们
发送
到
peer
device
上
的
lower
transport
layer。
如果
Upper
Transport
PDU
fit
它
在
单
个
Lower
Transport
PDU
中
发送。
对
不
fit
在
单
个
Lower
Transport
PDU
中
的
更长
的
packets
lower
transport
layer
执行
segmentation
将
Upper
Transport
PDU
split
成
多
个
segments。

接收
device
上
的
lower
transport
layer
在
将
segments
pass
up
the
stack
之前
将
它们
reassembled
成
单
个
Upper
Transport
PDU。
Segmented
message
的
delivery
由
接收
node
的
lower
transport
layer
acknowledged
而
unsegmented
message
的
delivery
不
被
acknowledged。
然而
fit
在
单
个
Lower
Transport
PDU
中
的
Upper
Transport
PDU
也
可以
作为
single
segment
的
segmented
message
发送
当
需要
lower
transport
layer
的
acknowledgment
时。
Set
``send
rel``
flag
（参考
:c:struct:`bt_mesh_msg_ctx`）
用
reliable
的
message
transmission
并
acknowledge
single
segment
的
segmented
messages。

Transport
layer
能
用
它
的
SAR
mechanism
transport
最多
32
个
segments
最大
message
（PDU）
size
为
384
octets。
要
为
Bluetooth
Mesh
stack
配置
message
size
用
以下
Kconfig
options：

*
:kconfig:option:`CONFIG_BT_MESH_RX_SEG_MAX`
设置
incoming
message
中
segments
的
最大
数量。
*
:kconfig:option:`CONFIG_BT_MESH_TX_SEG_MAX`
设置
outgoing
message
中
segments
的
最大
数量。

Kconfig
options
:kconfig:option:`CONFIG_BT_MESH_TX_SEG_MSG_COUNT`
和
:kconfig:option:`CONFIG_BT_MESH_RX_SEG_MSG_COUNT`
定义
多
少
outgoing
和
incoming
的
segmented
messages
可以
被
simultaneously
processed。
当
多
个
segmented
messages
被
发送
到
相同
的
destination
时
messages
被
queued
并
一
次
一
个
发送。

Incoming
和
outgoing
的
segmented
messages
共享
相同
的
pool
用于
allocate
它们
的
segments。
这
个
pool
size
通过
:kconfig:option:`CONFIG_BT_MESH_SEG_BUFS`
Kconfig
option
配置。
两
个
incoming
和
outgoing
的
messages
在
transaction
开始
时
allocate
segments。
Outgoing
的
segmented
message
在
segments
被
receiver
acknowledged
后
一
次
一
个
释放
它们
