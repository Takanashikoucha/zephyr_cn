Large
Composition
Data
Server
#############################

Large
Composition
Data
Server
model
是
Bluetooth
Mesh
specification
定义
的
foundation
model。
该
model
是
optional
的
通过
:kconfig:option:`CONFIG_BT_MESH_LARGE_COMP_DATA_SRV`
option
启用。

Large
Composition
Data
Server
model
在
Bluetooth
Mesh
Protocol
Specification
version
1.1
中
被
引入
用
来
支持
expose
不
fit
在
Config
Composition
Data
Status
message
中
的
Composition
Data
pages
的
functionality
并
expose
model
instances
的
metadata。

Large
Composition
Data
Server
没有
自己
的
API
依赖
:ref:`bluetooth_mesh_lcd_cli`
来
control
它。
该
model
只
接受
用
node
的
device
key
encrypted
的
messages。

如果
存在
Large
Composition
Data
Server
model
必须
只
在
primary
element
上
被
instantiated。

Models
metadata
=================

Large
Composition
Data
Server
model
允许
每个
model
有
一
个
model
特定
的
metadata
列表
可以
被
Large
Composition
Data
Client
model
read。
Metadata
列表
可以
通过
:c:member:`bt_mesh_model.metadata`
field
与
:c:struct:`bt_mesh_model`
关联。
Metadata
列表
由
一
个
或
多
个
:c:struct:`bt_mesh_models_metadata_entry`
structure
定义
的
entries
组成。
每个
entry
包含
metadata
的
length
和
ID
以及
指向
raw
data
的
pointer。
Entries
可以
用
:c:macro:`BT_MESH_MODELS_METADATA_ENTRY`
macro
创建。
:c:macro:`BT_MESH_MODELS_METADATA_END`
macro
标记
metadata
列表
的
end
必须
总是
存在。
如果
model
没有
metadata
可以
改用
helper
macro
:c:macro:`BT_MESH_MODELS_METADATA_NONE`。

reference
