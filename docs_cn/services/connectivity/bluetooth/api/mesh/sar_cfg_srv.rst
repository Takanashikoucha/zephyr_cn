SAR
Configuration
Server
########################

SAR
Configuration
Server
model
是
Bluetooth
Mesh
specification
定义
的
foundation
model。
它
是
一
个
optional
model
通过
:kconfig:option:`CONFIG_BT_MESH_SAR_CFG_SRV`
configuration
option
启用。

SAR
Configuration
Server
model
在
Bluetooth
Mesh
Protocol
Specification
version
1.1
中
被
引入
支持
配置
Bluetooth
Mesh
node
的
:ref:`segmentation
and
reassembly
（SAR）
<bluetooth_mesh_sar_cfg>`
行为。
该
model
为
SAR
configuration
定义
一
组
states
和
messages。

SAR
Configuration
Server
model
定义
两
个
states
SAR
Transmitter
state
和
SAR
Receiver
state。
关于
两
个
states
的
更多
信息
参考
:ref:`bt_mesh_sar_cfg_states`。

该
model
也
支持
SAR
Transmitter
和
SAR
Receiver
的
get
和
set
messages。

SAR
Configuration
Server
model
没有
自己
的
API
依赖
:ref:`bluetooth_mesh_sar_cfg_cli`
来
control
它。
SAR
Configuration
Server
model
只
接受
用
node
的
device
key
encrypted
的
messages。

如果
存在
SAR
Configuration
Server
model
必须
只
在
primary
element
上
被
instantiated。

reference
