Private
Beacon
Server
#####################

Private
Beacon
Server
model
是
Bluetooth
mesh
specification
定义
的
foundation
model。
它
通过
:kconfig:option:`CONFIG_BT_MESH_PRIV_BEACON_SRV`
option
启用。

Private
Beacon
Server
model
在
Bluetooth
Mesh
Protocol
Specification
version
1.1
中
被
引入
控制
mesh
node
的
Private
Beacon
state、
Private
GATT
Proxy
state
和
Private
Node
Identity
state。

Private
Beacons
feature
通过
periodically
randomize
beacon
input
data
为
不同
的
Bluetooth
Mesh
beacons
添加
privacy。
这
保护
mesh
node
不
被
mesh
network
外
的
devices
tracked
并
隐藏
network
的
IV
index、
IV
update
和
Key
Refresh
state。
Private
Beacon
Server
必须
被
instantiated
device
才能
支持
发送
private
beacons
但
node
没有
它
也
会
处理
收到
的
private
beacons。

Private
Beacon
Server
没有
自己
的
API
依赖
:ref:`bluetooth_mesh_models_priv_beacon_cli`
来
control
它。
Private
Beacon
Server
model
只
接受
用
node
的
device
key
encrypted
的
messages。

Application
可以
通过
传递
给
:c:macro:`BT_MESH_MODEL_PRIV_BEACON_SRV`
的
:c:struct:`bt_mesh_priv_beacon_srv`
instance
配置
Private
Beacon
Server
model
的
initial
parameters。
注意
如果
mesh
node
在
settings
subsystem
中
存储
了
这
个
configuration
的
changes
initial
values
可能
在
loading
时
被
overwritten。

如果
存在
Private
Beacon
Server
model
必须
只
在
primary
element
上
被
instantiated。

reference
