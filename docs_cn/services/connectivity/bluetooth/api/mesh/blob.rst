BLOB
Transfer
models
####################

Binary
Large
Object
（BLOB）
Transfer
models
实现
Bluetooth
Mesh
Binary
Large
Object
Transfer
Model
specification
version
1.0
并
提供
从
单
个
source
向
多
个
Target
nodes
通过
Bluetooth
Mesh
network
发送
large
binary
objects
的
functionality。
它
是
:ref:`bluetooth_mesh_dfu`
的
底层
transport
method
但
也
可以
用
于
其他
object
transfer
目的。
Implementation
处于
experimental
state。

BLOB
Transfer
models
支持
最多
4
GB
（2
\
:sup:`32`
bytes）
的
continuous
binary
objects
的
transfers。
BLOB
transfer
protocol
有
内置
的
recovery
procedures
用于
packet
losses
并
设置
checkpoints
确保
所有
targets
在
继续
之前
都
收到
了
所有
data。
Data
transfer
order
不
被
guaranteed。

BLOB
transfers
受
底层
mesh
network
的
transfer
speed
和
reliability
限制。
在
ideal
条件
下
BLOBs
可以
以
最多
1
kbps
的
rate
被
transferred
允许
100
kB
的
BLOB
在
10
15
分钟
内
被
transferred。
然而
network
条件、
transfer
capabilities
和
其他
limiting
factors
可以
轻松
将
data
rate
degrade
多
个
orders
of
magnitude。
根据
application
和
network
configuration
调整
transfer
的
parameters
以及
在
network
traffic
低
的
periods
schedule
它
将
在
protocol
的
speed
和
reliability
上
提供
显著
的
improvements。
然而
在
实际
deployments
中
达到
接近
ideal
rate
的
transfer
rates
不太
可能。

有
两
个
BLOB
Transfer
models：

.. toctree::
   :maxdepth:
   1

   blob_srv
   blob_cli

BLOB
Transfer
Client
在
sender
node
上
被
instantiated
BLOB
Transfer
Server
在
receiver
nodes
上
被
instantiated。

Concepts
********

BLOB
transfer
protocol
引入
多
个
新
concepts
用于
实现
BLOB
transfer。
