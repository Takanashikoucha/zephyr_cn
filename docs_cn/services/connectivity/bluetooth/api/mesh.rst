.. _bluetooth_mesh:

Bluetooth Mesh Profile
######################

Bluetooth Mesh profile 为 Bluetooth Low Energy 添加安全的无线 multi-hop 通信。此 module 实现 `Bluetooth Mesh Protocol Specification v1.1.1 <https://www.bluetooth.com/specifications/specs/mesh-protocol-1-1-1/>`_。

在 `Bluetooth SIG Website <https://www.bluetooth.com/bluetooth-resources/?tags=mesh>`_ 上阅读更多关于 Bluetooth Mesh 的内容。
