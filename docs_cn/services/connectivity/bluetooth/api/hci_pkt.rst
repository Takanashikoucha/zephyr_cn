HCI
Packet
Helpers
##################

用于
framing
HCI
command
packets
和
parsing
command
responses
的
helpers
在
:c:struct:`net_buf_simple`
buffers
和
packet
bytes
中
独立
于
Bluetooth
Host
和
HCI
driver
interface
同时
带
一
个
lockstep
helper
用于
通过
自己
的
transport
与
controller
交换
HCI
commands
的
HCI
drivers
例如
用于
vendor
特定
的
controller
initialization。

两
个
helpers
都
是
启用
:kconfig:option:`CONFIG_BT`
的
每个
build
的
部分。
Lockstep
helper
的
header
与
HCI
driver
API
一起
位于
:file:`include/zephyr/drivers/bluetooth/`
下。

这些
不
是
general
application
APIs：
预期
的
users
是
HCI
drivers
和
Bluetooth
stack
internals。
需要
在
运行
的
Host
旁边
发送
HCI
commands
的
applications
使用
更高
level
的
:c:func:`bt_hci_cmd_alloc`、
:c:func:`bt_hci_cmd_send`
和
:c:func:`bt_hci_cmd_send_sync`
APIs
它们
与
Host
的
command
flow
control
协同
工作。
