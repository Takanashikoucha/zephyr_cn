Bluetooth:
GAP

GAP

是
Bluetooth
的
"main"

Identities
**********

Identities
是
Zephyr
host
concept
允许
单
个
physical
device
表现
像
多
个
logical
的
Bluetooth
devices。

Shell
允许
创建
多
个
identities
到
由
Kconfig
symbol
:kconfig:option:`CONFIG_BT_ID_MAX`
设置
的
maximum。
要
创建
新
的
identity
用
:code:`bt
id-create`
command。
你
然后
可以
用
它
通过
用
它
的
ID
select
它
:code:`bt
id-select
<id>`。
最后
你
可以
用
:code:`id-show`
list
所有
可用
的
identities。
