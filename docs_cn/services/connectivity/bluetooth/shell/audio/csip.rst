Set

************************

Client

Client

当

要

这

到
set
的
所有
members

因此
如果

3

:code:`BT_MAX_CONN`

3。

如果
set
members
上
的
locks
应该

通过
disconnects
必须
与
set
members

如果
你

与
多
个
set
members
bond
确保
:code:`BT_MAX_PAIRED`
被
correctly

当

Client

剩余

当
所有

它

必须

:kconfig:option:`CONFIG_BT_CSIP_SET_COORDINATOR_LOG_LEVEL_DBG`
