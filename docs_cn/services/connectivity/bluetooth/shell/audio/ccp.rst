Call
Control
Server
*******************

Call
Control
Server
是
一
个
role
通常
reside
在
能
make
calls
的
devices
上
包括
从
Skype
等
apps
的
calls
例如
（smart）phones
和
PCs
它们
通常
是
GAP
Central
devices。

Using
the
Call
Control
Server
=============================

The
Server
can
be
controlled
locally、
or
by
a
remote
device
（when
in
a
call）.
For
example
a
remote
device
may
initiate
a
call
to
the
server、
or
the
Server
may
initiate
a
call
to
remote
device、
without
a
client.

For
all
commands
that
take
an
optional
:code:`index`、
if
the
index
is
not
supplied
then
it
defaults
to
:code:`0`
which
is
the
GTBS
bearer.

code
block::
console
ccp
call
control
server

Call
Control
Client
*******************

The
Call
Control
Client
is
a
role
that
typically
resides
on
resource
constrained
devices
such
as
earbuds
or
headsets.

Using
the
Call
Control
Client
=============================

The
Client
can
control
a
remote
CCP
server
device.
For
example
a
remote
device
may
have
an
incoming
call
that
can
be
accepted
by
the
Client.

..
code
block::
console
uart:~$
ccp
call
control
client
--help
ccp
call
control
client
Bluetooth
CCP
Call
Control
Client

commands

:

and

on
