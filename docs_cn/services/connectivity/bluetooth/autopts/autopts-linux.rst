这

Linux
上

AutoPTS

server

Windows
10
virtual
machine

在
Ubuntu
20.4

Linux

上

你
必须
已

Zephyr
development

参考
:ref:`getting_started`

支持
的
测试
zephyr

host

-
Testing
Zephyr
Host
Stack
on
QEMU

-
Testing
Zephyr
Host

:zephyr:board:`native_sim
<native_sim>`

-
Testing
Zephyr
combined
（controller
+
host）
build

hardware
（such

nRF52）

运行
QEMU
或
:zephyr:board:`native_sim
<native_sim>`
参考
:ref:`bluetooth_qemu_native`。

10/11

***********************************

选择
并
install
你
的
hypervisor
如
VMWare
Workstation
（preferred）
或
VirtualBox。
在
VirtualBox
上
可能
有
一些
issues
如果
你
的
host
有
少于
6
个
CPU。

创建
Windows
virtual
machine
instance。
确保
它
有
至少
2
个
cores
并
install
了
guest
extensions。

Setup
在
VirtualBox
7.2.4
和
VMWare
Workstation
16.1.1
Pro
上
tested。
