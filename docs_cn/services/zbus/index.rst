Concepts

Threads

用
zbus

一

多
个
observers。
这

many

many
的
communication

Bus

的

或
asynchronously

通过
zbus

Threads
（或

Additionally

当

个

一
个
channel
上

一
个
message

bus
将
make
该
message
available
到
published
的
channel
的
所有
observers。
根据
observer
的
type
它
可以
directly
access
message、
receive
它
的
copy、
或
甚至
只
receive
published
的
channel
的
reference。

下面
的
figure
show
一
个
typical
的

的
example
它
use
zbus

logic
（hardware
independent）

software
bus
与
其他
threads

Note
threads
彼此
decoupled
因为
它们
只
use
zbus
channels
且
不
需要
know
彼此
来
talk。
