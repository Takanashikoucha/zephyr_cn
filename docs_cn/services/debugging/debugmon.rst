Cortex
M
Debug
Monitor

Monitor
mode

是
Cortex
M
的
一
个
feature
它
provide
一
个
non
halting
的
approach
用于
debugging。
用
它
可以
continue
high
priority
interrupts
的
execution
即使
在
wait
一
个
breakpoint
时。
这
个
strategy
使
debug
time
sensitive
的
software
成为
possible
否则
当
core
halt
时
它
会
crash
（例如
需要
keep
communication
links
alive
的
applications）。

Zephyr
provide
support
用于
enable
和
configure
Debug
Monitor
exception。
它
也
contain
一
个
ready
的
interrupt
implementation
它
可以
与
SEGGER
J
Link
debuggers
used。

Configuration
*************

用
以下
options
configure
这
个
module。

*
:kconfig:option:`CONFIG_CORTEX_M_DEBUG_MONITOR_HOOK`：
enable
这
个
module。
这
个

require
一
个
debug
monitor
interrupt
的
implementation
它
将
在
program
每次
enter
一
个
breakpoint
时
被
executed。

与
SEGGER
debug
probe
一起
可以
use
一
个
ready
的
SEGGER
provided
的
interrupt
implementation。

*
:kconfig:option:`CONFIG_SEGGER_DEBUGMON`：
enable
SEGGER
debug
monitor
interrupt。
可以
与
SEGGER
JLinkGDBServer
和
SEGGER
debug
probe
used。


Usage
*****

当
monitor
mode
debugging
被
enabled
enter
一
个
breakpoint
将
不
halt
processor
而是
generate
一
个
interrupt
其
ISR
在
``z_arm_debug_monitor``
symbol
下

:kconfig:option:`CONFIG_CORTEX_M_DEBUG_MONITOR_HOOK`
config
configure
这
个
interrupt
为
lowest
available
的
priority
这
将
允许
其他
interrupts
在
processor
spin
在
breakpoint
上
时
