Overview
********

Gdbstub
feature
provide
GDB
Remote
Serial
Protocol
（RSP）
的
一
个
implementation
它
允许
你
用
GDB
remotely
debug
Zephyr。

Protocol
support
不同
的
connection
types：
serial、
UDP/IP
和
TCP/IP。
Zephyr
当前
只
support
serial
device
communication。

GDB
program
作为
client
同时
Zephyr
gdbstub
作为
server。
当
这
个
feature
被
enabled
时
Zephyr
在
:c:func:`gdb_init`
start
gdbstub
service
后
stop
它
的
execution
并
wait
一
个
GDB
connection。
一
旦
connection
被
established
可以
synchronously
与
Zephyr
interact。
注意
当前
不
可以
asynchronously
send
commands
到
target。

Features
********

以下
features
被
supported：

*
Add
和
remove
breakpoints
*
Continue
和
step
target
*
Print
backtrace
*
Read
或
write
general
registers
*
Read
或
write
memory
