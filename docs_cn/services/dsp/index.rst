Digital
Signal
Processing
（DSP）
###############################

.. contents::
    :local:
    :depth:
    2

DSP
API
provide
一
个
architecture
agnostic
的
way
用于
signal
processing。
当前
这
个
API
在
任何
architecture
上
work
但
可能
不
被
optimized。
各种
architectures
的
status
可以在
下面
找到：

============
=============
Architecture
Status
============
=============
ARC
Optimized
ARM
Optimized
ARM64
Optimized
MIPS
Unoptimized
POSIX
Unoptimized
RISCV
Unoptimized
RISCV64
Unoptimized
SPARC
Unoptimized
X86
Unoptimized
XTENSA
Unoptimized
============
=============

Use
zDSP
**********

zDSP
provide
各种
backend
options
它们
被
automatically
selected
用于
application。
Default
下
include
CMSIS
module
将
enable
所有
architectures
use
zDSP
APIs。
这
可以
通过
set::

   CONFIG_CMSIS_DSP=y
done。

如果
你
的
application
require
某些
additional
的
customization
可以
enable
:kconfig:option:`CONFIG_DSP_BACKEND_CUSTOM`
它
means
application
负责
provide
zDSP
的
implementation
