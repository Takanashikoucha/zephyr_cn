有

这些

power

在

的

manage
device
的
多
个

的

特别是
当
transitions
可能

时

一
个
shared
的
implementation
是
desirable

Zephyr
provide
managers
用于

的
coordination

这些
managers
被
embedded
到
use
它们
用于
specific
functions
的
services
中。

*

Supporting

Service
根据

operations
的
functions
manage

*
当

service
从

到
