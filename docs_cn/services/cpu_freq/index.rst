Overview
********

Zephyr
中
的
CPU
Frequency
Scaling
subsystem
提供
一
个
framework
用于
SoC
s
dynamically
adjust
它们
的
processor
frequency
基于
monitored
的
metric
和
performance
state
（P-state）
policy

Design
Goals
************

CPU
Frequency
Scaling
subsystem
aim
提供
一
个
framework
它
允许
任何
policy
algorithm
与
任何
P-state
driver
work
并
允许
每个
policy
use
一
个
或
多
个
metrics
determine
optimal
的
CPU
frequency。
Subsystem
应该
sufficiently
flexible
允许
SoC
vendors
define
custom
的
P-states、
thresholds
和
metrics。

P-state

****************

一
个

是
一
个
algorithm
它
根据
它
consumes
的
metrics
和
per
P-state
defined
的
thresholds
determine
什么
是
optimal
的
P-state
用于
CPU。
一
个
policy
可以
consume
一
个
或
多
个
metrics
根据
system
的
desired
statistics
determine
optimal
的
CPU
frequency。

参考
:ref:`policies
<cpu_freq_policies>`
获取
standard
policies
的
list。

Metrics
*******

一
个
P-state
policy
应该
include
一
个
或
多
个
metrics
用于
base
decisions。
Metrics
的
examples
可以
include
percent
CPU
load、
SoC
temperature
等。
