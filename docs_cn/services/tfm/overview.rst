Trusted
Firmware
M
Overview
###########################

`Trusted
Firmware
M
（TF
M）
<https://tf-m.docs.trustedfirmware.org/en/latest/>`__
是
Platform
Security
Architecture
（PSA）
`IoT
Security
Framework
<https://www.psacertified.org/what-is-psa-certified/>`__
的
一
个
reference
implementation。
它
define
并
implement
一
个
architecture
和
一
set
的
software
components
它们
aim
address
IoT
products
中
some
main
的
security
concerns。

Zephyr
RTOS
从
Zephyr
2.0.0
带
TF
M
1.0
起
被
PSA
Certified
当前
与
TF
M
2.1.0
integrated。

What
Does
TF
M
Offer?
*********************

通过
一
set
的
secure
services
和
by
design
TF
M
provide：

*
Secure
和
non
secure
的
resources
的
isolation
*
Embedded
appropriate
的
crypto
*
Device
secrets
（keys
等）
的
management
*
Firmware
verification
（和
encryption）
*
Protected
的
off
chip
data
storage
和
retrieval
*
Device
identity
的
proof
（device
attestation）
*
Audit
logging

System
Integration
************************

当
用
supported
的
platform
use
TF
M
时
TF
M
将
automatically
被
built
并
在
background
linked
作为
standard
的
Zephyr
build
process
的
一
part。
这
个
build
process
对
TF
M
如何
被
used
make
many
assumptions
且
对
Zephyr
application
image
可以
和
不
可以
做
什么
有
certain
的
implications：

*
Secure
的
processing
environment
（secure
boot
和
TF
M）
first
start
*
Zephyr
的
resource
allocation
rely
于
在
secure
image
中
made
的
choices。
