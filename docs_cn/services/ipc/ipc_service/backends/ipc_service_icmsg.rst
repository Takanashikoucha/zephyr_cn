ICMsg
backend
#############

Inter
core
messaging
backend
（ICMsg）
是
更
heavy
的
RPMsg
static
vrings
backend
的
更
light
的
alternative。
它
在
small
的
memory
footprint
中
offer
一
个
minimal
的
feature
set。
ICMsg
backend
在
:ref:`spsc_pbuf`
上面
build。

Overview
========

ICMsg
backend
use
shared
memory
和
MBOX
devices
用于
exchange
data。
Shared
memory
被
used
用于
store
data
MBOX
devices
被
used
用于
signal
data
已
被
written。

Backend
support
在
单
个
instance
上
register
单
个
endpoint。
如果
application
require
多
于
一
个
communication
channel
你
必须
define
多
个
instances
每个
有
它
自己
dedicated
的
endpoint。

Configuration
=============

Backend
通过
Kconfig
和
devicetree
configured。
在
configure
backend
时
做
以下
操作：

*
如果
至少
一
个
core
在
shared
memory
上
use
data
cache
set
``dcache-alignment``
value。
这
必须
是
communication
两
side
的
invalidation
或
write
back
size
的
largest
value。
如果
communication
的
side
都
不
在
shared
memory
上
use
data
cache
可以
skip
它。
*
Define
两
个
memory
regions
并
assign
它们
到
instance
的
``tx-region``
和
``rx-region``。
Ensure
用于
data
exchange
的
memory
regions
是
unique
的
（不
overlapping
任何
其他
region）
且
两
个
domains
（或
CPUs）
都
可以
access。
*
Define
MBOX
devices
它们
被
used
用于
send
signal
inform
另
一
个
domain
（或
CPU）
data
已
被
written。
Ensure
另
一
个
domain
（或
CPU）
可以
receive
该
signal。

.. caution::

    Ensure
    你
    set
    了
    正确
    的
    ``dcache-alignment``
    value。
