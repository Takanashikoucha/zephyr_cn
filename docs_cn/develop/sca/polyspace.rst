.. _polyspace:

Polyspace
支持
#################

`Polyspace®
<https://mathworks.com/products/polyspace.html>`__
是
MathWorks
的
一
个
商业
静态
代码
分析
工具，
获得
认证
用于
最高
安全
上下文。
它
可以
检查
对
MISRA
C
和
CERT
C
等
编码
指南
的
合规性，
发现
CWE，
检测
bug
并
计算
代码
复杂度
指标。
可选
地，
它
可以
运行
形式
证明
验证
运行
时
错误
（如
数组
越界
访问、
溢出、
竞争
条件
等）
的
缺失，
从而
帮助
实现
内存
安全。

安装
**********

Polyspace
工具
必须
安装
并
在
操作系统
或
容器
的
PATH
变量
中
可用。
特别
是，
路径
``<polyspace_root>/polyspace/bin``
必须
在
列表
中。

安装
说明
见
`这里
<https://mathworks.com/help/bugfinder/install-polyspace.html>`__。
要
使用
形式
验证
（证明
缺陷
的
*缺失*），
你
还
需要
安装
`这个
<https://mathworks.com/help/codeprover/install-polyspace.html>`__。

许可
文件
必须
在
安装
文件夹
中
可用。
要
申请
试用
许可，
访问
`这
页
<https://www.mathworks.com/campaigns/products/trials.html>`__。

运行
*******

代码
分析
可以
通过
``west``
命令
触发，
在
构建
中
追加
选项
``-DZEPHYR_SCA_VARIANT=polyspace``，
例如：

.. code-block:: shell

   west
   build
   -b
   qemu_x86
   samples/hello_world
   --
   -DZEPHYR_SCA_VARIANT=polyspace

审查
结果
*****************

识别
的
问题
在
构建
末尾
汇总
并
打印
在
控制台
窗口
中，
连同
包含
详细
结果
的
文件夹
路径。

要
高效
审查，
应该
在
`Polyspace
user
interface
<https://mathworks.com/help/bugfinder/review-results-1.html>`__
中
打开
文件夹。
