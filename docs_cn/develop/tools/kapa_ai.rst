Kapa.ai
文档
助手
###############################

Zephyr
文档
网站
用
Kapa.ai
驱动
的
AI
助手
增强。
助手
在
Zephyr
自己
的
文档、
源
代码
和
GitHub
活动
上
训练
（参考
`Data
sources`_
下面）
并
能
用
自然
语言
回答
自由
格式
的
问题，
引用
它
用
来
构建
每
个
答案
的
文档
页面
和
资源。

同一
知识库
也
通过
`Model
Context
Protocol
<https://modelcontextprotocol.io/>`_
（MCP）
服务器
暴露，
所以
外部
AI
助手
和
IDEs
可以
直接
查询
Zephyr
知识
（参考
`Using
the
MCP
server`_）。

.. note::

   答案
   是
   AI
   生成
   的
   并
   可能
   包含
   不
   准确
   之处。
   始终
   对
   官方
   文档
   验证
   重要
   信息，
   并
   将
   助手
   视为
   起点
   而
   非
   权威
   来源。

使用
chatbot
*****************

chatbot
从
文档
的
每个
页面
可
用：

* 点击
  页面
  底部
  显示
  的
  chatbot
  按钮，
  或
* 按
  :kbd:`Ctrl+K`
  （macOS
  上
  :kbd:`Cmd+K`）
  从
  任何
  地方
  打开
  它。

助手
在
侧边栏
中
打开
你
可以
用
纯
语言
问
问题，
例如
*"How
do
I
configure
a
UART
device
in
the
devicetree?"*
或
*"What
is
the
difference
between
a
workqueue
and
a
thread?"*。
答案
包括
链接
回
相关
的
文档
页面、
GitHub
issues
或
源
文件
所以
你
可以
深入
挖掘。

第一
次
使用
助手
时，
一
次
性
同意
屏幕
解释
功能
如何
工作
和
收集
什么
数据。
参考
`Privacy`_
节
下面。
