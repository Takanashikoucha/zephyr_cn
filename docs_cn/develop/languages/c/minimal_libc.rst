.. _c_library_minimal:

最小
libc
############

最
基础
的
C
库，
名为
"minimal
libc"，
是
Zephyr
代码
库
的
一部分，
提供
满足
Zephyr
及其
子系统
需求
所需
的
标准
C
库
最小
子集，
主要
在
字符串
操作
和
显示
领域。

它
非常
低
占用
空间，
适合
不
依赖
ISO
C
标准
库
较少
使用
部分
的
项目。
它
也
可以
与
多种
不同
工具链
一起
使用。

最小
libc
实现
可以
在
主
Zephyr
树
的
:file:`lib/libc/minimal`
中
找到。

函数
*********

最小
libc
实现
满足
Zephyr
内核
需求
所需
的
ISO/IEC
9899:2011
标准
C
库
函数
最小
子集，
由
:ref:`编码
指南
规则
A.4
<coding_guideline_libc_usage_restrictions_in_zephyr_kernel>`
定义。

格式化
输出
****************

最小
libc
不
实现
自己
的
格式化
输出
处理器；
相反，
它
将
C
标准
格式化
输出
函数
如
``printf``
和
``sprintf``
映射
到
:c:func:`cbprintf`
函数，
这是
Zephyr
自己
的
C99
兼容
格式化
输出
实现。

更多
细节，
参考
:ref:`格式化
输出
<formatted_output>`
OS
服务
文档。

动态
内存
管理
*************************

最小
libc
使用
:ref:`通用
C
库
<c_library_common>`
提供
的
malloc
api
家族
实现，
其
本身
构建
在
:ref:`内核
内存
堆
API
<heap_v2>`
之上。

错误
号
*************

错误
号
在
Zephyr
API
中
广泛
使用
于
作为
函数
返回
值
信号
错误
条件。
它们
通常
作为
本
节
定义
的
整数
字面量
的
负值
返回，
并
在
:file:`errno.h`
头
文件
中
定义。

`POSIX
errno.h
规范`_
和
其他
事实
标准
来源
定义
的
错误
号
子集
已
被
添加
到
最小
libc。

Zephyr
中
有
意识
地
努力
保持
最小
libc
错误
号
的
值
与
Zephyr
支持
的
不同
C
标准
库
实现
一致。
最小
libc
的
:file:`errno.h`
对照
:ref:`Newlib
<c_library_newlib>`
的
检查
以
确保
错误
号
保持
对齐。

下面
是
错误
号
定义
列表。
实际
数值
请
参考
`errno.h`_。
