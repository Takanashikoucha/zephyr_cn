.. _language_c:

C
语言
支持
##################

C
是
一种
通用
低
层
编程
语言，
广泛
使用
于
编写
嵌入式
系统
代码。

Zephyr
主要
用
C
编写
并
本地
支持
用
C
语言
编写
的
应用。
所有
Zephyr
API
函数
和
宏
用
C
实现
并
作为
:file:`include`
目录
下
的
C
头
文件
的
部分
可用，
因此
用
C
编写
Zephyr
应用
给
开发者
访问
最多
功能
的
能力。

``main()``
函数
必须
有
``int``
返回
类型，
因为
Zephyr
应用
运行
在
C
标准
定义
的
"hosted"
环境
中。
应用
必须
从
main
返回
零
（0）。
所有
非
零
返回
值
保留。

.. _c_standards:

语言
标准
******************

Zephyr
不
目标
特定
版本
的
C
标准；
不过，
Zephyr
代码
库
广泛
使用
ISO
C
标准
1999
发布
版本
（ISO/IEC
9899:1999，
以下
简称
C99）
新
引入
的
功能，
如
以下
列出
的，
实际
上
要求
使用
支持
C99
标准
及
之后
的
编译器
工具链：

* 内联
  函数
* 标准
  布尔
  类型
  （``<stdbool.h>``
  中
  的
  ``bool``）
* 固定
  宽度
  整数
  类型
  （``<stdint.h>``
  中
  的
  ``[u]intN_t``）
* 指定
  初始化器
* 可变
  参数
  宏
* ``restrict``
  限定

此外，
某些
组件
或
其
部分
使用
标准
C11
和
C17
版本
（分别
ISO/IEC
9899:2011
和
9899:2018）
引入
的
功能：

* _Generic
  关键字
* _Static_assert
  关键字

总结
来说，
推荐
使用
至少
支持
C17
标准
的
编译器
工具链
来
用
Zephyr
开发。
不过，
重要
的
是
注意
某些
可选
Zephyr
组件
和
外部
模块
可能
使用
标准
更
新
版本
引入
的
C
语言
功能，
这种
情况
下
将
需要
使用
更
新
的
支持
这些
标准
的
编译器
工具链。

库
****************

`C
标准
库`_
是
任何
C
程序
的
不可
分割
部分，
Zephyr
提供
对
多个
不同
C
库
的
支持
供
应用
选择，
取决于
用于
构建
应用
的
编译器
工具链。

.. _c_library_formatted_output:

格式化
输出
****************

C
定义
标准
格式化
输出
函数
如
``printf``
和
``sprintf``，
这些
函数
由
C
标准
库
实现。

每个
C
标准
库
有
其
自己
的
要求
和
配置
集合
用于
选择
格式化
输出
模式
和
能力。
更多
细节
参考
每个
C
标准
库
文档。

.. _c_library_dynamic_mem:

动态
内存
管理
*************************

C
定义
标准
动态
内存
管理
接口
（例如
:c:func:`malloc`
和
:c:func:`free`），
这些
函数
由
C
标准
库
实现。

尽管
动态
内存
管理
实现
的
细节
在
不同
C
标准
库
之间
变化，
所有
受
支持
库
必须
符合
以下
约定。
每个
受
支持
C
标准
库
应该：

* 管理
  其
  自己
  的
  内存
  堆，
  内部
  或
  通过
  调用
  在
  :file:`libc-hooks.c`
  中
  实现
  的
  钩子
  函数
  （例如
  :c:func:`sbrk`）。

* 保持
  架构
  和
  内存
  区域
  特定
  的
  对齐
  要求
  用于
  标准
  动态
  内存
  分配
  接口
  （例如
  :c:func:`malloc`）
  分配
  的
  内存
  块。

* 在
  启用
  用户
  空间
  时
  在
  ``z_malloc_partition``
  内存
  分区
  内
  分配
  内存
  块。
  见
  :ref:`memory_domain_predefined_partitions`。

关于
C
标准
库
特定
内存
管理
实现
的
更多
细节，
参考
每个
C
标准
库
文档。

.. note::
   本地
   Zephyr
   应用
   应该
   使用
   Zephyr
   内核
   支持
   的
   :ref:`内存
   管理
   API
   <memory_management_api>`
   如
   :c:func:`k_malloc`
   以
   利用
   它们
   提供
   的
   高级
   功能。

   C
   标准
   动态
   内存
   管理
   接口
   函数
   如
   :c:func:`malloc`
   应该
   只
   被
   目标
   多个
   操作
   系统
   的
   可
   移植
   应用
   和
   库
   使用。
