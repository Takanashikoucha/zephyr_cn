Twister
Status
##############

什么
是
Twister
Status？
=========================

Twister
Status
用
综合
和
容易
理解
的
方式
表述
当前
状态
of

- ``Harness``
- ``TestCase``
- ``TestSuite``
- ``TestInstance``

在
实践
中，
大多数
用户
将
对
他们
的
Twister
运行
结束
后
的
Instances
和
Cases
的
Statuses
感兴趣。

.. tip::

   Nomenclature
   reminder:

   .. tabs::

      .. tab::
         ``Harness``

         ``Harness``
         是
         Twister
         内部
         的
         Python
         class
         允许
         我们
         捕获
         和
         分析
         Twister
         外部
         程序
         的
         输出。
         它
         被
         从
         这
         页
         移除
         以
         清晰，
         因为
         它
         不
         出现
         在
         最终
         报告
         中。

      .. tab::
         ``TestCase``

         ``TestCase``，
         也
         称为
         Case，
         是
         一
         段
         旨在
         验证
         某
         个
         assertion
         的
         代码。
         它
         是
         Zephyr
         中
         测试
         的
         最小
         细分。

      .. tab::
         ``TestSuite``

         ``TestSuite``，
         也
         称为
         Suite，
         是
         Cases
         的
         分组。
