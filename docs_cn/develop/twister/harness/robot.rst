Robot
#####
Zephyr
支持
`Robot
Framework
<https://robotframework.org/>`_
作为
自动化
测试
的
一
个
解决方案。

Robot
文件
允许
你
用
人
可读
的
文本
格式
表达
交互式
测试
scenario
并
在
模拟
中
或
对
硬件
执行
它们。
在
这
个
时刻
Zephyr
集成
支持
在
`Renode
<https://renode.io/>`_
模拟
框架、
QEMU
和
Native
Simulator
中
运行
Robot
测试。

要
用
twister
执行
一
个
Robot
测试
套件，
运行
以下
命令：

.. code-block:: console

   $
   west
   twister
   --platform
   hifive1
   --test
   samples/subsys/shell/shell_module/sample.shell.shell_module.robot

编写
Robot
测试
==================

对
Robot
Framework
本身
提供
的
keywords
列表，
参考
`the
official
Robot
documentation
<https://robotframework.org/robotframework/>`_。

在
Renode
中
编写
和
运行
Robot
Framework
测试
的
信息
可以
找到
在
Renode
文档
的
`the
testing
section
<https://renode.readthedocs.io/en/latest/introduction/testing.html>`_。
它
提供
最
常
用
的
keywords
列表
连同
链接
到
源
代码
那些
在
那里
定义。

可以
通过
添加
新
的
keywords
扩展
框架
直接
表达
在
Robot
测试
套件
文件
中、
作为
外部
Python
库
或
像
Renode
做
的
那样
动态
通过
XML-RPC。
细节
参考
官方
Robot
文档
中
的
`extending
Robot
Framework
<https://robotframework.org/robotframework/latest/RobotFrameworkUserGuide.html#extending-robot-framework>`_
节。
