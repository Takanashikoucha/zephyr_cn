Overview
========

Zephyr

一

简单
的
emulator

支持
测试
外部
peripheral

而
不
需要
真实
hardware。

Emulators
用
来
emulate
外部
hardware
devices，
支持
测试
不同
的
subsystems。
例如，
可以
为
一
个
I2C
compass

一
个
emulator

在
I2C
bus
上
并
可以
像
真实
hardware
device
一样

Emulators
通常

特殊
的
功能
用于
测试。
例如
一
个
compass
可能
支持
在
I2C
bus
速度
太
高
时
返回
bogus
data，
或
在
calibration
尚未
完成
时
返回
invalid
measurements。
这
允许
测试
高层
代码
可以
正确
处理
这些
情况。
因此
如果
所有
failure
conditions
都
被
emulated，
test
coverage
可以
接近
100%。
