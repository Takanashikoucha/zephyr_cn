Display

  Motorola
  6800

  C:
  SPI
  Type
  serial
  bit

  有

  个

  #. 每
     byte
     9
     write
     clocks，
     最后
     bit

     command/data

  #. 与
     上面
     相同，
     但
     每
     byte
     16
     write

  #. 每
     byte
     8
     write
     clocks。
     Command/data

     GPIO

当前，
