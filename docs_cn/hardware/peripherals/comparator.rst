.. _comparator_api:

Comparator
##########

Overview
********

Analog
comparator
比较
连接
到
其
negative
和
positive
inputs
的
两
个
analog
signals
的
voltages。
如果
positive
input
的
voltage
高
于
negative
input，
comparator
的
output
将
是
high
否则
将
是
low。

Comparators
通常
可以
设置
一
个
在
output
变化
时
触发
的
trigger。
这
个
trigger
可以
调用
一
个
callback
或
其
status
可以
被
polled。

相关
配置
选项：

* :kconfig:option:`CONFIG_COMPARATOR`

Configuration
*************

Embedded
comparators
通常
可以
在
runtime
配置。
当
启用
时
必须
用
devicetree
提供
初始
configuration。
在
runtime，
comparators
可以
用
device
driver
特定
APIs
更新
其
configuration。
Configuration
在
comparator
被
resumed
时
被
应用。

Power
management
****************

Comparators
用
power
management
启用。
当
resumed
时
comparator
将
主动
比较
其
inputs，
产生
output
并
检测
edges。
当
suspended
时
comparator
将
是
inactive
的。

Comparator
shell
****************

Comparator
shell
为
:ref:`shell
<shell_api>`
模块
提供
一
个
带
一
组
subcommands
的
``comp``
命令。
