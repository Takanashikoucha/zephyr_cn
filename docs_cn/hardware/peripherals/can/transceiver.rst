Overview
********

CAN
transceiver
是
一
个
外部
device
将
CAN
controller
的
logic
level
signals
转换
为
bus-levels。
Bus
lines
被
称为
CAN
High
（CAN
H）
和
CAN
Low
（CAN
L）。
从
controller
到
transceiver
的
transmit
wire
被
称为
CAN
TX，
receive
wire
被
称为
CAN
RX。
这些
wires
使用
logic
levels
而
bus-level
在
CAN
H
和
CAN
L
之间
被
differential
解释。
Bus
可以
处于
recessive
（logical
one）
或
dominant
（logical
zero）
state。
Recessive
state
是
两
条
lines
CAN
H
和
CAN
L
大致
在
同一
voltage
level
时
的
状态。
这
个
state
也
是
idle
state。
要
向
bus
写
一
个
dominant
bit，
open-drain
transistors
将
CAN
H
连接
到
Vdd
将
CAN
L
连接
到
ground。
第一
和
最后
的
node
用
CAN
H
和
CAN
L
之间
的
120-ohm
resistor
terminate
bus。
Dominant
state
始终
override
recessive
state。
这
个
structure
被
称为
wired-AND。
