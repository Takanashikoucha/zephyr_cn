.. _crc_api:

循环冗余校验（CRC）
#####################

概述
********

Cyclic Redundancy Check（CRC）API 提供用于在硬件上配置和计算 CRC 值的函数。

配置选项
*********************

相关配置选项：

* :kconfig:option:`CONFIG_CRC_DRIVER`
* :kconfig:option:`CONFIG_CRC_DRIVER_INIT_PRIORITY`
