.. _w1_api:

1-Wire 总线
##########

概述
********

1-Wire 是一种低速半双工串行总线，仅使用一根信号线加地线（GND），同时用于数据传输和设备供电。与 I2C 类似，1-Wire 使用双向开集电极（open-collector）数据线，并且是单主多从（multidrop）总线。这意味着由一个主设备发起与所有从设备的数据交换。1-Wire 总线支持的总线线长度比 I2C 更长，标准模式下速率最高可达 15.4 kbps，过驱（overdrive）模式下最高可达 125 kbps。在标准速率配置下，100 米总线长度上挂接 10 个节点可以可靠通信；使用过驱速率时，10 米总线上挂接 3 个节点预期可稳定工作。优化时序参数并减少总线上的节点数量，可能允许支持更长的总线。

实现细节在 `BOOK OF IBUTTON STANDARDS`_ 中有规定。

W1 主设备接口
=================

Zephyr 的 1-Wire 主设备接口用于与 1-Wire 从设备（如温度传感器和串行存储器）交互。

在 Zephyr 中，该接口分为以下层次。

* 链路层（link layer）处理基本通信功能，例如总线复位（bus reset）、在位检测（presence detect）和位传输操作。
  它是 Zephyr 中唯一的硬件相关层。
  该层由使用 Zephyr :ref:`uart_api` 接口的驱动程序支持，
  应能在大多数 Zephyr 平台上工作。
  未来可能添加基于 GPIO/Timer 的驱动程序以及硬件特定的驱动程序。
* 1-Wire 网络层处理所有从设备识别和总线仲裁手段，
  包括 ROM 命令，例如 Match ROM 或 Search ROM。

   * 所有从设备都有一个唯一的 64 位识别号，其中包含 8 位 `1-Wire Family Code`_ 和 8 位 CRC。
   * 为了在总线上找到从设备，标准规定了一种搜索算法，该算法依次检测总线上所有从设备。
     该算法在 `1-Wire Search Algorithm Application Note`_ 中有描述。

* 传输层和表示层（Presentation layer）功能未在通用 1-Wire 驱动程序中实现，
  因此必须在各个从设备驱动程序中处理。

1-Wire 接口被视为实验性的。

W1 串行驱动程序
****************

``zephyr,w1-serial`` 驱动程序使用 UART 外设实现 1-Wire 接口。各个 1-Wire 位被编码为通过 UART 发送的字节。标准速率下，数据传输使用 115200 波特率，复位/在位检测使用 9600 波特率。过驱速率下使用可配置的波特率，默认数据传输为 1000000 波特率，复位/在位检测为 115200 波特率。
