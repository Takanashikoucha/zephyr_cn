（I2C）

Overview

.. note::

   Zephyr
   I2C
   APIs

   的
   术语

   `NXP
   I2C
   Bus
   Specification
   Rev
   7.0
   <i2c-specification_>`_。
   这些
   从
   之前
   的
   revisions

   其
   2021
   年
   10
   月
   1
   日

`I2C`_
（Inter-Integrated

许多

Bus

两

作为
"controller"

"target"
响应
transaction

给定
SoC
上
的
I2C
controller
通常
支持
controller
role
一些
也
支持
target
mode。
Zephyr
有
两
个
roles
的
API。

.. _i2c-controller-api:

I2C
Controller

Zephyr
的
I2C
controller
API
在
I2C
peripheral
控制
bus
时
使用
特别
是
start
和
stop
conditions
和
clock。
这
是
最
常见
的
mode
用
于
与
I2C
devices
如
sensors
和
serial
memory
交互。

这

API
在
所有
in-tree
I2C
peripheral
drivers
中
被
支持
并
被
考虑
为
stable。
