Chargers
########

Charger
subsystem
暴露
一
个
API
统一
访问
battery
charger
devices。

Charger
device，
或
charger
peripheral，
是
一
个
用
于
将
提供
给
system
的
外部
power
作为
input
并
向
battery
pack(s)
和
system
下游
提供
power
作为
output
的
device。
Charger
device
可以
存在
为
module、
integrated
circuit、
或
power
management
integrated
circuit
（PMIC）
中
的
functional
block。

充电
battery
pack
的
操作
被
称为
charge
cycle。
当
charge
cycle
被
执行
时
battery
pack
根据
配置
在
charger
device
上
的
charge
profile
被
充电。
Charge
profile
在
manufacturer
提供
的
battery
pack
specification
中
定义。
在
有
control
port
的
charger
devices
上，
charge
profile
可以
由
host
controller
通过
设置
相关
properties
配置，
并
可以
在
runtime
调整
以
响应
environmental
changes。

Basic
Operation
***************

开始
Charge
Cycle
=========================

Charge
cycle
用
:c:func:`charger_charge_enable`
开始
或
终止。

Properties
==========

根本
上，
property
是
charger
device
可以
测量
的
可
配置
setting、
state、
或
quantity。

Chargers
通常
支持
多
个
properties，
如
battery-pack
的
temperature
readings
或
present-time
current/voltage。

Properties
由
client
用
:c:func:`charger_get_prop`
一
个
一
个
获取。
Properties
由
client
用
:c:func:`charger_set_prop`
一
个
一
个
设置。
