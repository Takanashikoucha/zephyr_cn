Video
#####

Video
driver
API
为
video
devices
提供
一
个
generic
interface。

Basic
Operation
***************

Video
Device
=============

一
个
video
device
是
hardware
或
software
video
function
的
abstraction
它
可以
produce、
process、
consume
或
transform
video
data。
Video
API
被
设计
为
提供
flexible
的
方式
创建、
处理
和
组合
各种
video
devices。

Endpoint
========

每个
video
device
可以
有
一
个
或
多
个
endpoints。
Output
endpoints
配置
video
output
function
并
generate
data。
Input
endpoints
配置
video
input
function
并
consume
data。

Video
Buffer
=============

一
个
video
buffer
为
data
提供
transport
mechanism。
对
content
没有
特定
的
requirement。
Content
的
requirement
由
endpoint
format
定义。
一
个
video
buffer
可以
被
queued
到
device
endpoint
用于
filling
（input
ep）
或
consuming
（output
ep）
operation
一旦
operation
被
achieved
buffer
可以
被
dequeued
用于
post
processing、
release
或
reuse。

Controls
========

一
个
video
control
用
CID
（control
identifier）
访问
和
识别。
它
代表
一
个
video
control
property。
不同
的
devices
将
有
不同
的
