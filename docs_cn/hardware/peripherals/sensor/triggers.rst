Sensor
Triggers
###############

:dfn:`Triggers`
在
:c:enum:`sensor_trigger_type`
中
enumerated
是
sensor
generated
events。
通常
sensors
允许
设置
这些
events
导致
digital
line
signaling
以
便
于
microcontroller
轻松
capture。
Events
然后
通常
可以
通过
read
registers
被
inspected
以
确定
哪个
event
导致
了
digital
line
signaling
发生。

有
许多
种
triggers
sensors
提供
从
informative
的
如
data
ready
到
physical
events
如
taps
或
steps。
