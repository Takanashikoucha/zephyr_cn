Sensor
Channels
###############

:dfn:`Channels`
在
:c:enum:`sensor_channel`
中
enumerated
是
一
个
sensor
device
可以
测量
的
quantities。

Sensors
可以
有
多
个
channels
要么
代表
同一
physical
property
的
不同
axes
（例如
acceleration）
要么
因为
它们
可以
测量
完全不同
的
properties
（ambient
temperature、
pressure
和
humidity）。
Sensors
可以
有
多
个
同一
measurement
type
的
channels
以
启用
测量
多
个
readings
也许
是
temperature、
light
intensity、
amperage、
voltage、
或
capacitance
例如。

一
个
channel
在
Zephyr
中
用
:c:struct:`sensor_chan_spec`
指定
它
是
一
个
pair
包含
channel
type
（:c:enum:`sensor_channel`）
和
channel
index
两
者。
有时
只
使用
:c:enum:`sensor_channel`
但
这
应该
被
考虑
为
historical
的
自
:c:struct:`sensor_chan_spec`
在
Zephyr
3.7
中
引入
以来。
