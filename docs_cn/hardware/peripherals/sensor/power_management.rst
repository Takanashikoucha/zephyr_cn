电源管理
================

传感器的电源管理通常是一项非平凡的任务，因为传感器可能针对各种通道拥有多个电源状态。某些传感器可能允许低噪声、低功耗或挂起通道，
从而以噪声或采样速度性能为代价节省相当多的功耗。在极低的电源状态下，传感器可能丢失其状态，甚至关闭设备的数字逻辑部分。

总而言之，传感器的电源管理通常是应用特定的！通常通道状态可以通过 :ref:`sensor-attribute` 进行修改。如果设备实现了必要的功能，
整个设备的挂起和恢复可以通过电源管理引用计数 API 完成。

传感器用于其完全挂起/恢复电源状态时，最可能应使用的 API 是 :ref:`pm-device-runtime`，在应用层面通过显式调用
:c:func:`pm_device_runtime_get` 和 :c:func:`pm_device_runtime_put`。

在未来，借助 :ref:`sensor-read-and-decode`，在流式场景下设备电源管理的自动管理可能成为现实，因为应用通过针对给定事件的
读取请求始终向驱动通告使用情况。
