Inter-IC

Overview

I2S
（Inter-IC
Sound）
API

对
标准
I2S
接口
的
支持
以及
常见
的
非
标准
extensions
如
PCM
Short/Long
Frame
Sync
和
Left/Right
Justified
Data

Shell
*****

当
:kconfig:option:`CONFIG_I2S_SHELL`
被
启用
时，
``i2s``
shell

可用
于
通过
任何
I2S
controller
stream
一
个
生成
的
sine
test
tone
而
不
写
应用
代码。
它
只
是
transport；
与
``codec``
shell
配对
将
audio
通过
codec

Tone

在
``i2s

* ``i2s
  tone
  start
  <device>
  [frequency_hz]
  [sample_rate]
  [bits]``
  在
  给出
  的
  I2S
  device
  上
  开始
  一
  个
  stereo
  test
  tone。
  ``frequency_hz``
  默认
  440
  Hz，
  ``sample_rate``
  默认
  48000
  Hz，
  ``bits``
  默认
  16
  （有效
  值
  是
  16、
  24
  和
  32）。
* ``i2s
  tone
  stop``
  停止
  运行
  的
  tone。
* ``i2s
  tone
  info``
  显示
  当前
  tone
  stream
  状态。
