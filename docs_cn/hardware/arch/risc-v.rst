Zephyr
在
RISC-V
处理器
上
的
支持
状态
##########################################

Overview
********

本
页
描述
Zephyr
对
RISC-V
处理器
的
当前
状态。
当前，
有
对
一些
boards
的
支持，
以及
Qemu
支持
和
对
一些
FPGA
implementations
的
支持
如
neorv32
和
litex_vexriscv。

Zephyr
支持
包括
PMP、
:ref:`user
mode<usermode_api>`、
多
个
ISA
extensions
以及
:ref:`semihosting<semihost_guide>`。

User
mode
和
PMP
支持
**************************

当
platform
有
Physical
Memory
Protection
（PMP）
支持
时，
在
Zephyr
上
启用
它
允许
user
space
支持
和
stack
保护
被
选择。

ISA
extensions
**************

在
Zephyr
中
可以
设置
哪些
ISA
extensions
（RV32/64I(E)MAFD(G)QC）
在
给定
的
platform
上
可用，
通过
设置
适当
的
``CONFIG_RISCV_ISA_*``
kconfig。
参考
:file:`arch/riscv/Kconfig.isa`
获取
更多
信息。

注意
Zephyr
SDK
工具链
支持
可能
不
为
所有
组合
定义。

Supervisor
mode
（S-mode）
************************

当
:kconfig:option:`CONFIG_RISCV_S_MODE`
被
启用
时，
Zephyr
kernel
运行
在
RISC-V
Supervisor
mode
（S-mode）
而
非
Machine
mode
（M-mode）。
这
遵循
application
类
operating
systems
使用
的
标准
RISC-V
privilege
architecture
并
是
MMU
支持
所
必需
的。

的
in-tree
M-mode
runtime
（``arch/riscv/core/sbi.S``）
充当
