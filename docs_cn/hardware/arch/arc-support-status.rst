Zephyr 在 ARC 处理器上的支持状态
#######################################

概述
********

本页面介绍 Zephyr 在 ARC 处理器上的当前状态以及部分未来计划。请注意：

 * 计划未给出确切截止日期
 * 软件功能需要对应的硬件存在并以正确方式配置
 * 并非所有功能可以同时启用

备注
*****

.. [#f1] 在 SMP 系统上 CCM 的使用受到限制
.. [#f2] 由于硬件限制，带安全功能（SecureShield）的系统除外
.. [#f3] 我们仅支持在任务上下文中保存/恢复 ACCL/ACCH 寄存器。
         其余 DSP/AGU 寄存器的保存/恢复尚未实现，但内核本身不使用这些寄存器。
         这使得每个核上的单个任务可以安全地使用 DSP/AGU。
.. [#f4] QEMU 不支持所有 ARC 处理器的硬件功能。详细信息请查阅 ARC QEMU 文档
.. [#f5] 单线程内核仅支持单核目标
.. [#f6] 目前仅支持 ARC VPX 标量移植。VPX 向量流水线、VCCM、
         STU 的支持未包含在此移植中，需要额外的开发和/或其他运行时
         集成。

VPX 向量寄存器
--------------------
Zephyr 支持一种有限形式的 VPX 向量寄存器共享，称为协作共享。
使用这些寄存器的线程必须在相关代码段前后调用 :c:func:`arc_vpx_lock`
和 :c:func:`arc_vpx_unlock` 来控制对该资源的访问。

.. note::
    如果系统有多个 CPU，则应用程序开发人员有责任在尝试获取协作锁
    之前将线程绑定到单个 CPU，并且在等待或持有该协作锁期间
    不修改 CPU 亲和性。

配置选项
=====================

当配置选项 :kconfig:option:`CONFIG_ARC_VPX_COOPERATIVE_SHARING`
启用时，即选择 VPX 向量寄存器的协作共享。
