Xtensa

本

HiFi

*********************

kernel
允许

Engine
DSP

kernel
只

.. note::
   当前，
   只
   有
   Intel
   ADSP
   ACE
   hardware
   platforms
   默认
   配置

   HiFi
   支持。

Concepts
========

kernel
可以
为
应用

以

Xtensa
HiFi
Audio
Engine
DSP

支持

No

这

mode
用
于
应用
没有
使用
HiFi
registers
的

的

它
是
kernel
的
默认
HiFi
services
mode。

Unshared
HiFi
registers

----------------------------

这
个
mode
用
于
应用
只有
单一
使用
HiFi
registers
的
thread
的
情况。
HiFi
registers
在
任何
context
切换
时
保持
不变
