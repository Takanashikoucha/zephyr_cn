Virtual

**************

在
非常
早期
的
boot

page

被

所以
技术

在
virtual
address
space
中

默认

和

identity

给出
执行

在
physical
address
space
中

physical
address
space
由
dts
:c:macro:`DT_CHOSEN_SRAM_ADDR`
和
:c:macro:`DT_CHOSEN_SRAM_SIZE`
标记
而
virtual
address
space
由
:kconfig:option:`CONFIG_KERNEL_VM_BASE`
和
:kconfig:option:`CONFIG_KERNEL_VM_SIZE`
标记。
注意
:kconfig:option:`CONFIG_SRAM_OFFSET`
控制
Zephyr
kernel
被
放置
在
memory
中
的
哪里，
以及
其
对应
的
:kconfig:option:`CONFIG_KERNEL_VM_OFFSET`。
