.. _guide:

源码阅读指南
############

本指南带你系统性地阅读 Zephyr RTOS 源代码，
从整体架构到关键子系统，逐步深入。

.. note::

   完整的源码阅读指南以 Markdown 格式发布在
   GitHub Pages 的 ``/guide/`` 路径下。
   本页面提供指南的 RST 版本索引。

指南目录
********

- **01-快速入门**：如何开始读 Zephyr 源码（★）
- **02-内核架构**：``kernel/`` 目录导读（★★）
- **03-调度器**：线程调度源码走读（★★★）
- **04-内存管理**：内存子系统导读（★★★）
- **05-设备驱动模型**：驱动框架导读（★★★）
- **06-构建系统**：CMake + Kconfig 导读（★★）
- **07-子系统**：``subsys/`` 目录导读（★★）

.. tip::

   建议按顺序阅读：入门 → 内核架构 → 调度器 → 内存管理 → 驱动模型 → 构建系统 → 子系统。
   每篇指南包含目录结构说明、关键文件列表、核心代码走读和扩展阅读建议。
